# 附录：历史资料与运维补充

## 为什么这页存在

JavaWeb 目录里有一部分内容不是现代主线开发方式，但它们对理解历史架构和部署方式仍然有参考价值。

这类内容更适合：

- 维护老项目时回看
- 面试中补齐 Servlet/JSP 时代的背景
- 理解 Tomcat 和单体项目的传统部署形态

## JavaWeb 技术演进对照

| 时期 | 技术栈 | 特点 | 当前状态 |
|------|--------|------|---------|
| 早期 | Servlet + JSP | 手写底层、JSP 混合 Java 代码 | 已过时 |
| 中期 | Struts / WebWork | MVC 思想、配置文件驱动 | 已淘汰 |
| 主流 | Spring MVC + Spring Boot | 注解驱动、自动配置、嵌入式容器 | √ 当前推荐 |
| 现代 | Spring Boot 3.x + 前后端分离 | AOT、GraalVM、云原生 | √ 前沿 |

## 二、阅读顺序建议

```text
入门(必读):  00 → 01 → 02 → 03
进阶通信:    04 → 05 → 06
服务端主线:  07 → 08 → 14 → 15 → 16 → 17 → 18 → 19
会话与客户端: 09 → 10 → 11 → 12 → 13
应用实战:    20 → 21 → 22 → 23 → 24 → 25 → 26 → 27
协议深潜:    28 → 29 → 30 → 31 → 32 → 33
```

| 阶段 | 篇目 | 说明 |
|------|------|------|
| 1. 快速入门 | 00-03 | 先建立数据模型、Watch、ACL 三个核心概念,即可上手基本操作 |
| 2. 通信基础 | 04-06 | 理解序列化与网络协议,为读源码做准备;赶时间可跳过 05 |
| 3. 服务端与集群 | 07、08、14-19 | 主线:启动 → 选举 → 数据同步 → 三种角色协作,是本专题的核心 |
| 4. 会话与客户端 | 09-13 | 补全客户端视角:会话创建、ClientCnxn、分桶管理与 Curator |
| 5. 应用实战 | 20-27 | 分布式锁、ID 生成器、负载均衡、生产部署与监控运维,贴近工作 |
| 6. 协议深潜 | 28-33 | 2PC/3PC → ZAB → Paxos 的理论闭环,面试深挖与架构设计必读 |

> 提示:时间有限时,可按"阶段 1 → 3 → 5"的最小路径走;若为面试准备,阶段 3 与 6 的高频考点(选举流程、ZAB 与 Paxos 对比、分布式锁实现)优先。

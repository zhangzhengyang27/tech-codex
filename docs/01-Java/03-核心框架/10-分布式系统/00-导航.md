# 分布式系统 导航

本专题共 7 篇,回答一个核心问题:**系统从单体拆成多个服务后,一致性、并发控制、故障处理这些"单机里理所当然"的事情,如何在不可靠的网络上重新建立**。本页是专题的权威入口。

| 02 | [分布式锁与幂等设计](02-分布式锁与幂等设计.md) | 两件容易混用的事:何时该用锁保护关键资源、何时该用幂等兜底重复请求,及各自实现方案。 |

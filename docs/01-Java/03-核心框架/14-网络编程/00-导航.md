# 网络编程 导航

本专题共 4 篇,从操作系统网络模型讲到 Java 的 NIO 与 Netty,再到长连接工程实践,回答"请求到底是怎么到达你的代码的"这一问题。本页是专题的权威入口。

## 一、篇目索引

| 序 | 篇目 | 内容概括 |
|----|------|----------|
| 00 | [TCP-UDP 与 NIO 基础](00-TCP-UDP与NIO基础.md) | 基础篇:TCP/UDP 的核心特性、BIO/NIO/AIO 三种 I/O 模型、Reactor 模式与 NIO 三大组件(Channel/Buffer/Selector)。 |
| 01 | [Netty 核心](01-Netty核心.md) | Netty 的线程模型(EventLoop)、核心组件栈(Channel/Pipeline/Handler/ByteBuf)与粘包半包的协议设计,核心教学篇。 |
| 02 | [HTTP 长连接与心跳机制](02-HTTP长连接与心跳机制.md) | 连接复用的动机与失效场景,Keep-Alive、HTTP/2、WebSocket 的心跳保活设计。 |
| 03 | [Netty 面试要点与实战补充](03-Netty面试要点与实战补充.md) | 高频面试问答、常见误区、生产参数调优与 IM/文件服务器/WebSocket 实战案例。 |

## 二、阅读顺序建议

| 阶段 | 篇目 | 说明 |
|------|------|------|
| 1. 模型打底 | 00 | 必读:不理解 BIO→NIO 的演进,就无法理解 Netty 为什么快 |
| 2. 框架实践 | 01 | 在 00 的模型基础上理解 Netty 的组件与线程模型 |
| 3. 工程收尾 | 02 | 长连接保活是 IM/推送/网关类系统的必修课,可与 01 并行读 |
| 4. 面试与实战 | 03 | 汇总面试问答与生产调优、实战案例,作为 01 的补充篇 |

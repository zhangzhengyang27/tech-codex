# 安装宝塔面板

在 CentOS 7.9 上安装宝塔面板非常简单，以下是完整的安装步骤和注意事项：

## 1. 确认系统版本

```bash
# 确认系统版本
cat /etc/redhat-release
# 应该显示：CentOS Linux release 7.9.2009 (Core)

# 查看内核版本
uname -r
```

## 2. 安装面板

```bash
# 更新所有包到最新版本
sudo yum update -y

# 安装常用工具
sudo yum install -y wget curl vim net-tools epel-release

# 安装宝塔 Linux 面板（脚本会自动拉取最新版）
sudo curl -sSO http://download.bt.cn/install/install_panel.sh && bash install_panel.sh
```

## 3. 安装过程确认

安装过程中会询问：输入 `y`继续。

```
Do you want to install Bt-Panel to the /www directory now?(y/n): y
```

## 5. 防火墙配置

### 开放宝塔所需端口

```
# 如果使用 firewalld
sudo firewall-cmd --permanent --add-port=8888/tcp
sudo firewall-cmd --permanent --add-port=888/tcp
sudo firewall-cmd --permanent --add-port=80/tcp
sudo firewall-cmd --permanent --add-port=443/tcp
sudo firewall-cmd --permanent --add-port=20/tcp
sudo firewall-cmd --permanent --add-port=21/tcp
sudo firewall-cmd --reload

# 查看已开放的端口
sudo firewall-cmd --list-ports
```

### 或者临时关闭防火墙（仅用于测试）

```
# 临时关闭防火墙
sudo systemctl stop firewalld

# 永久关闭（不推荐）
sudo systemctl disable firewalld
```

## 6. SELinux 配置

CentOS 7 默认启用 SELinux，可能需要调整：

```
# 查看 SELinux 状态
sudo getenforce
# 如果是 Enforcing，需要调整

# 临时关闭 SELinux
sudo setenforce 0

# 永久关闭（重启后生效）
sudo sed -i 's/SELINUX=enforcing/SELINUX=disabled/g' /etc/selinux/config

# 或者只针对宝塔相关目录放行
sudo semanage fcontext -a -t httpd_sys_rw_content_t "/www/wwwroot(/.*)?"
sudo restorecon -Rv /www/wwwroot
```

## 7. 访问宝塔面板

### 获取登录信息

如果忘记安装完成时显示的地址和密码：

```
# 查看宝塔面板地址和账号密码
sudo bt default
```

### 访问面板

1. 打开浏览器访问：`http://your_server_ip:8888/xxxxxxxx`
2. 输入用户名和密码登录
3. 首次登录会要求绑定宝塔账号（如果没有，可以免费注册）

## 8. 初始化配置

登录后按照向导完成：

### 1. 绑定宝塔账号

- 如果没有账号，访问 [https://www.bt.cn](https://www.bt.cn/)注册
- 或者点击"跳过"（但部分高级功能需要绑定）

### 2. 选择LNMP/LAMP运行环境

建议选择：

- **LNMP**：Nginx + MySQL + PHP（适合大多数网站）
- 版本推荐：
  - Nginx 1.20+
  - MySQL 5.7（或 8.0）
  - PHP 7.4 或 8.0

### 3. 等待环境安装

根据选择的软件，安装可能需要20-60分钟。

## 10. 安全加固建议

### 1. 修改默认端口

```
sudo bt
# 选择 6，修改为其他端口，如 8889
```

### 2. 修改面板入口

```
sudo bt
# 选择 8，设置一个访问路径，如 /btadmin
```

### 3. 设置面板SSL

在宝塔面板中：

- 面板设置 → 面板SSL → 使用Let's Encrypt申请SSL

### 4. 定期修改密码

```
sudo bt 5
```

### 5. 开启面板IP访问限制

在面板设置中限制只能从特定IP访问。

## 11. 常见问题解决

### 问题1：无法访问面板

```
# 检查面板服务状态
sudo systemctl status bt

# 重启面板
sudo systemctl restart bt

# 检查端口监听
sudo netstat -tlnp | grep 8888

# 检查防火墙
sudo firewall-cmd --list-ports | grep 8888
```

### 问题2：安装环境失败

```
# 查看安装日志
tail -f /tmp/panelExec.log

# 清理缓存重新安装
sudo rm -rf /www/server/panel/pyenv
sudo bt restart
```

### 问题3：磁盘空间不足

```
# 查看磁盘使用情况
df -h

# 清理宝塔缓存
sudo bt 11
```

### 问题4：内存不足

```
# 添加Swap交换分区
wget https://download.bt.cn/tools/auto_swap.sh && bash auto_swap.sh
```

## 12. 宝塔面板目录结构

```
/www
├── wwwroot           # 网站根目录
│   ├── default       # 默认站点
│   └── your_site.com # 您的网站
├── server            # 服务器软件
│   ├── 11-Nginx基础概述        # Nginx
│   ├── mysql        # MySQL
│   ├── php          # PHP
│   └── panel        # 宝塔面板
├── backup            # 备份文件
├── logs              # 日志文件
└── wwwlogs           # 网站日志
```

## 13. 卸载宝塔面板

```
# 使用宝塔卸载脚本
wget http://download.bt.cn/install/bt-uninstall.sh
sh bt-uninstall.sh

# 或者直接使用命令
sudo bt 12
```

## 14. 宝塔面板的优势

1. **可视化操作**：无需记忆命令，图形界面管理
2. **一键部署**：WordPress、Discuz等一键安装
3. **安全管理**：防火墙、防篡改、监控
4. **备份恢复**：定时备份，一键恢复
5. **多版本支持**：PHP多版本共存，MySQL多版本切换
6. **专业版功能**：网站监控、负载均衡、安全防护

## 15. 注意事项

1. 

   **系统要求**：至少1GB内存，推荐2GB以上

2. 

   **纯净系统**：建议在全新系统安装，避免冲突

3. 

   **数据备份**：安装前备份重要数据

4. 

   **合规性**：确保符合相关法律法规要求

5. 
   
   **定期更新**：保持面板和软件最新版本

总体而言，宝塔面板把服务器管理、网站部署、SSL 证书配置等常用运维操作图形化，能显著降低日常运维成本；建议结合上文的端口、入口、SSL 与 IP 白名单设置做好安全基线。

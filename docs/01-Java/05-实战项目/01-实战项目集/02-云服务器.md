## 版本差异(云服务器课程 → 2026)

| 特性 | 旧版（2023） | 当前 |
|------|--------------|------|
| 选购 | 阿里云/腾讯云 ECS | 不变；轻量应用服务器更划算（2C2G 入门） |
| 系统 | CentOS 7.x | AlmaLinux 9 / Ubuntu 22.04+（CentOS 7 已 EOL） |
| 容器 | Docker 单机 | Docker + 云厂商容器服务（ACK/TKE）或 K8s |
| 成本 | 包年 | 新用户低价 + 按量付费组合 |

> 云服务器购买、SSH 连接、域名解析、Docker 部署等流程不变；重点是系统镜像选型避免 CentOS 7。

## 使用建议

1. **按模块复习**:面试前按上方十大主题各过一遍"典型回答",再点进正文看追问与源码细节。
2. **串联主线**:与 [Java 后端面试主线](00-Java后端面试主线.md) 的六大模块对应,本索引覆盖其中 Java 核心、并发与内存、数据库与 ORM、分布式与中间件四块的高频问答。
3. **原理深入**:面试问答只给"怎么答";要知其所以然,按各篇正文里的指向进入对应专题(JVM/并发/数据库/MQ)系统学习。

# 爬虫最小实战：构建电视剧评分数据集

> 前置知识：本篇是 [爬虫概览与 HTTP 基础](01-爬虫概览与HTTP基础)、[数据解析全攻略](02-数据解析全攻略)、[数据存储方案全解](10-数据存储方案全解) 的综合实战——下载（urllib3）、提取（BeautifulSoup）、保存（CSV）三项技能的语法细节不再重复，需要时点击对应链接回看。

## 一、数据从哪里来

做数据分析首先要有数据，获取路径有两条：

### 路径一：现成的公开数据集

| 渠道 | 特点 | 适合场景 |
|------|------|----------|
| Kaggle | 全球最大数据分析比赛平台；全英文、国内访问慢 | 进阶练手 |
| 天池 | 国内影响力最大，有新手赛系列 | 入门首选 |
| 比赛数据集 | 多为脱敏数据，只能挖掘隐藏关系 | 测试算法 |
| 行业公开数据集 | 多为网页/PDF 展示，难以下载复用 | 参考借鉴 |

### 路径二：从互联网构建自己的数据集

互联网数据真实、规模大，但以网页形式呈现——要变成可分析的表格（CSV/Excel），就需要爬虫技术，核心分三步：

1. **数据请求**：像浏览器一样按 URL 下载网页
2. **网页分析**：按规则从网页中筛选感兴趣的内容
3. **数据保存**：把提取内容存入 CSV/Excel

> ⚠️ **合规两条底线**：适当降低抓取频率，不给对方服务器造成负担；抓取数据仅作分析使用，切忌传播或销售，否则可能有违法风险。

本文走路径二，完整实战一遍。

## 二、任务：构建国产电视剧评分数据集

**业务背景**：为策划国产口碑电视剧的周边活动，需要分析电视剧的名称、演员与评分，预判评分走向。分析之前先收集数据。

**任务定义**：收集国产电视剧数据，至少包含评分、名称、主演三项，存为 `tv_rating.csv`，表头为 `title`（剧名）、`rating`（评分）、`stars`（主演）。

## 三、选型：分析目标网站

选网站看三点：**是否包含所需字段**、**是否容易抓取**、**能否翻页获取全量数据**。以两个候选为例：

**豆瓣电视剧主页**：有剧名和评分，但缺乏主演信息；且"加载更多"按钮动态生成内容，无法通过修改 URL 翻页——动态渲染的页面需要 [Playwright](09-Playwright深度实战) 等模拟浏览器方案，成本高。

**电视剧网**：弹窗广告多，但标题、评分、主演三字段都在页面上；且是**传统 URL 翻页**——第一页与第二页的 URL 仅 `page` 参数不同：

```
...search.php?page=1&searchtype=5&order=commend&tid=1...
...search.php?page=2&searchtype=5&order=commend&tid=1...
```

这说明只要循环替换 `page` 参数即可抓取全部页面——**URL 可翻页的静态网站是爬虫的最优目标**。选定电视剧网。

## 四、下载网页

### 准备下载与保存函数

先测试目标网页是否为静态内容（可直接用 urllib3 下载）。准备两个工具函数：

```python
import urllib3

def download_content(url):
    """下载网页，返回解码后的文本内容"""
    http = urllib3.PoolManager()
    response = http.request("GET", url)
    return response.data.decode()

def save_to_file(filename, content):
    """把字符串内容保存到文件"""
    with open(filename, "w", encoding="utf-8") as fo:
        fo.write(content)
```

下载第一页并落盘验证：

```python
url = "http://dianshiju.tv/search.php?page=1&searchtype=5&order=commend&tid=1&area=&year=&letter=&state=&money=&ver=&jq=&yuyan=%E5%9B%BD%E8%AF%AD"
html_content = download_content(url)
save_to_file("htmls/tv1.html", html_content)
```

打开 `tv1.html` 搜索第一部的剧名（如"决胜法庭"），能搜到就说明内容是静态的，urllib3 方案可行。

### 批量下载

需要前 100 页。循环替换 URL 的 `page` 参数，每次下载后 `sleep` 一秒，减轻对方服务器压力：

```python
import time

for i in range(2, 101):
    a_url = url.replace("page=1", f"page={i}")
    print("begin download:", a_url)
    html_content = download_content(a_url)
    save_to_file(f"htmls/tv{i}.html", html_content)
    time.sleep(1)
```

执行约 100 秒后，`htmls/` 下有 100 个 HTML 文件。抽验最后一页（`tv100.html`）：在浏览器打开第 100 页，比对第一部剧名能否在文件中搜到——确认下载完整后进入提取阶段。

## 五、提取数据

### 分析标签结构

用 BeautifulSoup 提取的第一步永远是**分析目标内容周围的标签结构**。打开 `tv1.html` 搜索第一部剧名，定位到它的标签：每个电视剧都在一个 `class="myui-vodlist__box"` 的 `div` 内，其中：

- `h4` 标签 → 电视剧名称
- `class="pic-tag pic-tag-top"` 的 `span` → 评分
- `p` 标签 → 主演信息

```python
from bs4 import BeautifulSoup

def create_doc_from_filename(filename):
    """从 HTML 文件创建 BeautifulSoup 对象"""
    with open(filename, "r", encoding="utf-8") as fo:
        html_content = fo.read()
    return BeautifulSoup(html_content, "html.parser")

doc = create_doc_from_filename("htmls/tv1.html")
box_list = doc.find_all("div", class_="myui-vodlist__box")

for box in box_list:
    title = box.find_all("h4")[0].text.strip()
    rating = box.find_all("span", class_="pic-tag pic-tag-top")[0].text.strip()
    stars = box.find_all("p")[0].text.strip()
    print(title, rating, stars)
```

输出示例：

```
决胜法庭 3.7分 主演于和伟,张佳宁,韩栋,王耀庆,连奕名,胡静,杜源,王艺禅,王全有
刘老根第三部 4.0分 主演赵本山,范伟,李静,闫学晶,王小宝
我的僵尸王爷 4.6分 主演内详
新世界2020 3.4分 主演孙红雷,张鲁一,尹昉,万茜,李纯,胡静,秦汉,赵峥,张瑶,张晔子
```

标签内部的原始文本常带多余空格（HTML 排版残留），`.strip()` 去掉首尾空白后即可得到干净数据。

### 函数化：处理全部 100 个文件

100 个文件标签结构一致，把单文件处理封装成函数、返回字典列表，循环调用即可：

```python
def get_tv_from_html(html_file_name):
    """从一个 html 文件提取全部电视剧信息，返回字典列表"""
    doc = create_doc_from_filename(html_file_name)
    box_list = doc.find_all("div", class_="myui-vodlist__box")
    tv_list = []
    for box in box_list:
        tv_list.append({
            "title": box.find_all("h4")[0].text.strip(),
            "rating": box.find_all("span", class_="pic-tag pic-tag-top")[0].text.strip(),
            "stars": box.find_all("p")[0].text.strip(),
        })
    return tv_list
```

## 六、保存为 CSV

用 `csv.DictWriter` 把字典列表写入 CSV；`encoding="utf_8_sig"` 能让 Excel 正确识别 UTF-8 编码（BOM 头），`newline=''` 避免写入空行：

```python
import csv
import glob

def write_dict_list_to_csv(dict_list, filename, headers):
    with open(filename, "w", newline="", encoding="utf_8_sig") as fo:
        writer = csv.DictWriter(fo, headers)
        writer.writeheader()
        writer.writerows(dict_list)

# 汇总 100 个文件的数据并保存
all_tv_dict = []
for i in range(1, 101):
    all_tv_dict.extend(get_tv_from_html(f"htmls/tv{i}.html"))

write_dict_list_to_csv(all_tv_dict, "tv_rating.csv", ["title", "rating", "stars"])
print(f"共保存 {len(all_tv_dict)} 条电视剧数据")
```

至此 `tv_rating.csv` 构建完成，可直接用 Pandas 做后续分析（见 [数据分析概览](/docs/python/05-数据科学/02-数据处理与分析/01-数据分析全流程) 与 [爬取数据的分析与可视化](/docs/python/05-数据科学/03-可视化实战/05-爬取数据的分析与可视化)）。

## 七、小结

本篇把爬虫三步（请求 → 解析 → 保存）串成一个真实数据集项目，关键的工程判断有三个：

1. **选站比写码重要**：字段齐全 + URL 可翻页的静态网站能省掉动态渲染的全部成本
2. **先验证再批量化**：先确认第一页内容是静态的，再循环批量下载
3. **礼貌抓取**：`sleep` 控频 + 数据仅作分析，是爬虫的合规底线

对更复杂的场景（登录态、动态渲染、大规模调度），按需进入 [Cookie 管理与模拟登录](05-Cookie管理与模拟登录)、[Playwright 深度实战](09-Playwright深度实战)、[Scrapy 框架全解](07-Scrapy框架全解)。

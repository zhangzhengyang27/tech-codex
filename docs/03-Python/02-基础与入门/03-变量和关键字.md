# 变量和关键字

## 变量概念：标签，而非容器

在 Python 中，**变量**是用来绑定对象的名称。这是理解 Python 变量机制最关键的一点：C/Java 等语言中变量是**容器**——`int x = 42` 会分配一个"盒子"把 42 装进去；而 Python 中变量是**标签**（名字贴纸）——`x = 42` 先在内存中创建整数对象 `42`，再把标签 `x` 贴上去。`x = 99` 不是修改原对象，而是把标签撕下来贴到新对象 `99` 上。

```python
# Python 变量是"标签"的直观证明
x = 42       # 创建整数对象 42，把标签 x 贴上去
y = x        # 把标签 y 也贴到同一个对象 42 上
print(id(x) == id(y))  # True —— x 和 y 指向同一个对象

x = 99       # 把标签 x 撕下来，贴到新对象 99 上
print(y)     # 42 —— y 仍然指向原来的对象，不受影响
```

这种"标签"模型意味着：**Python 中没有值传递 vs 引用传递的区分**，一切赋值都是"让变量名指向某个对象"。

### 对象模型：id、type、value

Python 中一切皆对象，每个对象有三个核心属性：

- **id**：唯一标识（本质是内存地址），用 `id()` 获取
- **type**：类型，决定支持的操作，用 `type()` 获取
- **value**：存储的数据

```python
x = 42
print(id(x))       # 例如 4306174848
print(type(x))     # <class 'int'>
print(x)           # 42
```

## 变量命名规则

Python 遵循 PEP 8 规范，变量名只能包含**字母、数字和下划线**，不能以数字开头，**区分大小写**，且**不能是关键字**：

```python
# 合法的变量名
name = "Alice"
user_id = 12345
total_amount = 100.50

# 以下均会引发错误
# 1st_name = "Bob"      # 以数字开头
# if = 10               # 关键字
# user@name = "Charlie" # 特殊字符
```

命名风格速查：

| 场景 | 推荐风格 | 示例 | 说明 |
| ---- | -------- | ---- | ---- |
| 普通变量/函数 | `snake_case` | `total_amount` | Python 主力风格（`camelCase` 不推荐） |
| 常量 | `UPPER_SNAKE` | `MAX_RETRY` | 约定俗成，提醒不要修改 |
| 类名 | `CapWords` | `UserProfile` | 也叫 `PascalCase` |
| 私有属性（约定） | `_prefix` | `_cache` | 单下划线提示"内部使用" |
| 特殊方法 | `__dunder__` | `__init__` | 为解释器保留，避免自定义 |
| 模块/包 | snake_case | `user_manager.py` | 短小写名称，避免连字符 |

::: warning 命名一致性
同一个项目中保持命名风格统一，不要混用 `snake_case` 和 `camelCase`。接手已有项目时，遵循项目现有风格比"纠正"更重要。PEP 8 可用 `flake8`、`pylint` 等工具检查。
:::

## 变量的赋值

使用等号 `=` 赋值。Python 支持多种赋值形式：

```python
# 1. 基本赋值
name = "Alice"

# 2. 链式赋值：多个变量绑定同一对象
x = y = z = 100

# 3. 多重赋值（解包赋值）：本质是元组解包
a, b, c = 1, "hello", True

# 4. 增强赋值
count = 5
count += 2  # 等价于 count = count + 2

# 5. 星号解包：收集不定数量的元素
first, *middle, last = [1, 2, 3, 4, 5]
print(first, middle, last)  # 1 [2, 3, 4] 5

# 6. 海象赋值（Python 3.8+）：赋值 + 表达式
data = [1, 2, 3]
if (n := len(data)) > 0:
    print(f"有 {n} 个元素")

# 7. 占位符 _：忽略不需要的值
x, _, z = (10, 20, 30)

# 8. 字典解包
person = {'name': 'Alice', 'age': 30}
name, age = person.values()
```

| 赋值方式 | 语法 | 特点 | 适用场景 |
| -------- | ---- | ---- | -------- |
| 基本赋值 | `x = 42` | 最常用 | 日常使用 |
| 链式赋值 | `x = y = z = 0` | 多个变量绑定同一对象 | 初始化相同值 |
| 多重赋值 | `a, b = 1, 2` | 同时赋不同值，元组解包 | 交换变量、多返回值 |
| 增强赋值 | `x += 1` | 就地运算 | 计数器、累加 |
| 星号解包 | `first, *rest = seq` | 收集剩余元素 | 不定长序列 |
| 海象赋值 | `(n := len(data))` | 赋值+表达式，3.8+ | 条件/循环中赋值 |

::: tip 链式赋值的陷阱
`x = y = []` 会让 `x` 和 `y` 指向**同一个**空列表对象，修改其中一个会影响另一个。需要两个独立的列表应使用 `x, y = [], []`。
:::

**变量交换**最 Pythonic 的写法是元组解包（右侧先打包成元组再解包）：

```python
a, b = 10, 20
a, b = b, a   # 一行完成交换
```

### 动态类型与类型注解

Python 是动态类型语言：变量类型在运行时确定，无需事先声明，同一变量可以先后绑定不同类型的对象。但大型项目中建议使用**类型注解**提示类型，配合 IDE 或静态检查工具（`mypy`、`pyright`）提前发现错误——注解不会在运行期强制校验：

```python
name: str = "Alice"
age: int = 30
```

## 小整数池与字符串驻留

Python 为常用值做了缓存，这是理解 `is` 行为的基础：

- **小整数池**：启动时预创建 [-5, 256] 的所有整数对象，该范围内的赋值直接引用缓存对象
- **字符串驻留**：符合标识符规则的短字符串会被缓存，相同内容只保留一份

```python
a = 256
b = 256
print(a is b)  # True —— 都指向缓存中的同一对象

c = int("257")
d = int("257")
print(c is d)  # False —— 超出小整数池，运行时各自创建新对象
```

::: warning 实现细节
小整数池范围和字符串驻留规则是 CPython 的**实现细节**，不属于语言规范，不同实现（PyPy 等）行为可能不同，**不应在业务逻辑中依赖**。
:::

## `is` vs `==`

| 操作符 | 含义 | 比较内容 |
| ------ | ---- | -------- |
| `is` | 是否同一对象 | `id()` 是否相同（同一内存对象） |
| `==` | 值是否相等 | 调用 `__eq__` 方法比较值 |

```python
list1 = [1, 2, 3]
list2 = [1, 2, 3]
print(list1 == list2)  # True —— 值相等
print(list1 is list2)  # False —— 不同对象
```

**经验法则**（PEP 8 明确规定）：与 `None`、`True`、`False` 的比较始终用 `is` / `is not`——它们是单例对象，`is` 检查身份，不会被自定义 `__eq__` 干扰；比较值一律用 `==`。

## 可变 vs 不可变类型的赋值行为

| 类型分类 | 常见类型 | 修改行为 |
| -------- | -------- | -------- |
| 不可变 | `int`, `float`, `str`, `tuple`, `frozenset`, `bool` | 不支持原地修改，"修改"其实是创建新对象 |
| 可变 | `list`, `dict`, `set`, `bytearray` | 原地修改会影响所有引用同一对象的变量 |

```python
# 不可变类型：重新赋值后互不影响
a = 100
b = a
a = 200
print(b)  # 100 —— 不受影响

# 可变类型：共享对象，一处修改处处生效
list_a = [1, 2, 3]
list_b = list_a       # 两个变量指向同一个列表
list_a.append(4)
print(list_b)         # [1, 2, 3, 4] —— 也"看到"了修改

# 需要独立副本时使用拷贝
list_c = list_a.copy()
```

## 变量的作用域

变量的**作用域**（Scope）决定其在程序中的可见性和生命周期。Python 遵循 **LEGB**（Local - Enclosing - Global - Built-in）查找顺序：

- **局部变量（Local）**：函数内部定义，仅函数内可见
- **全局变量（Global）**：模块级定义，函数内修改需 `global` 声明
- **非局部变量（Nonlocal）**：嵌套函数中引用外层函数变量，需 `nonlocal` 声明

```python
count = 0

def increment():
    global count
    count += 1

def outer():
    x = "local"
    def inner():
        nonlocal x
        x = "nonlocal"
    inner()
```

> 📚 LEGB 规则详解、闭包、参数传递见 [函数](10-函数)。

## 变量的内存管理与 del

Python 使用**垃圾回收**自动管理内存：主要依赖引用计数，循环引用由垃圾回收器处理。`del` 删除的是**变量名到对象的引用**，不是对象本身——只有对象的全部引用都被删除，内存才会被回收：

```python
import sys

my_list = [10, 20, 30]
another_ref = my_list          # 第二个引用
del my_list                    # 删除变量 my_list，引用计数 -1
print(another_ref)             # [10, 20, 30] —— 对象还在（another_ref 仍引用它）

# del 也可删除列表元素、字典键
nums = [1, 2, 3, 4, 5]
del nums[2]                    # [1, 2, 4, 5]
```

调试技巧：`sys.getrefcount(obj)` 查看引用数量（结果会比直觉多 1，含其自身的临时引用）；避免在长生命周期的全局容器中意外持有大对象导致内存泄漏。

## 常量

Python 没有内置常量类型，惯例用**全大写**命名提示"不要修改"（只是约定，无法真正阻止修改）：

```python
PI = 3.14159
GRAVITY = 9.81
```

## 关键字

关键字是 Python 的保留字，有特定语法功能，不能用作标识符（`class = "Math"` 直接语法错误）。截至 Python 3.12 共 **35** 个（不同版本会有增减，以 `keyword.kwlist` 输出为准）：

```python
import keyword

print(keyword.kwlist)                   # 所有关键字列表
print(keyword.iskeyword("if"))          # True
print(len(keyword.kwlist))              # 35
```

分类速记：

| 分类 | 关键词 | 说明 |
| ---- | ------ | ---- |
| **值** | `True`, `False`, `None` | 布尔值和空值 |
| **逻辑运算** | `and`, `or`, `not`, `is`, `in` | 布尔和成员测试 |
| **控制流** | `if`, `elif`, `else`, `match`, `case` | 条件分支（`match`/`case` 为 3.10+） |
| **循环** | `for`, `while`, `break`, `continue` | 迭代与循环控制 |
| **函数/类** | `def`, `class`, `lambda`, `return`, `yield` | 定义与返回值 |
| **异步** | `async`, `await` | 协程（3.5+） |
| **作用域** | `global`, `nonlocal` | 修改变量作用域 |
| **异常处理** | `try`, `except`, `finally`, `raise`, `assert` | 错误处理与断言 |
| **模块导入** | `import`, `from`, `as` | 引入代码模块 |
| **上下文管理** | `with` | 自动资源管理 |
| **变量操作** | `del`, `pass` | 删除引用和空操作 |

注意：`list = []` 这类**与内置类型同名**的赋值虽然合法，但会覆盖内置名称，应避免。

## 常见陷阱

### 陷阱 1：可变默认参数

Python 最经典的陷阱。默认参数在函数**定义时**求值（只求值一次），所有调用共享同一个对象：

```python
# ---- 错误写法 ----
def append_item(item, lst=[]):
    lst.append(item)
    return lst

print(append_item(1))   # [1]
print(append_item(2))   # [1, 2] —— 意料之外！前一次调用的结果被保留了

# ---- 正确写法：用 None 作为哨兵 ----
def append_item_fixed(item, lst=None):
    if lst is None:
        lst = []         # 每次调用都创建新列表
    lst.append(item)
    return lst
```

**原因**：默认值存储在函数对象的 `__defaults__` 中，所有调用共享。不可变类型（`int`、`str`）不会出问题，可变类型（`list`、`dict`、`set`）会导致状态在调用间泄漏。

### 陷阱 2：for 循环变量泄漏

`for` 循环不创建新作用域，循环结束后变量仍然存在，还会覆盖同名变量：

```python
i = "我是原来的值"
for i in range(3):
    pass
print(i)  # 2 —— 原来的字符串被覆盖了

# 列表推导式 + lambda 的经典坑
funcs = [lambda: i for i in range(3)]
print([f() for f in funcs])  # [2, 2, 2] —— 都是 2！

# 修复：用默认参数捕获当前值
funcs = [lambda i=i: i for i in range(3)]
print([f() for f in funcs])  # [0, 1, 2]
```

### 陷阱 3：`is` 与 `==` 混用

小整数池会让 `is` 比较"碰巧"正确，但这依赖实现细节：

```python
a = 256; b = 256
print(a is b)            # True（小整数池）—— 别被误导！

a = int("257"); b = int("257")
print(a is b)            # False（超出缓存范围）

# 正确姿势
x = 0
if x is None:  pass      # ✓ 判断 None 用 is
if a == 257:   pass      # ✓ 比较值用 ==
```

### 陷阱 4：UnboundLocalError

函数体内只要出现赋值语句，Python 在**编译时**就把该名称标记为局部变量——赋值前读取会报错：

```python
x = 10  # 全局变量

def trouble():
    # print(x)   # 若先读后写：UnboundLocalError！x 已被视为局部变量
    x += 1        # 赋值操作触发局部变量标记
    return x

def fixed():
    global x      # 显式声明使用全局变量
    x += 1
    return x

# 类似问题：items += [...] 也会触发（+= 隐含赋值）
# 不涉及赋值的方法调用则没问题：items.append("new") ✓
```

## FAQ

**Q: 变量名能用中文吗？**
可以（Python 3 标识符支持 Unicode），但不建议在生产代码中使用，保持英文命名利于协作与工具兼容。

**Q: 为什么小整数 `is` 比较有时 True 有时 False？**
小整数池 [-5, 256] 内是缓存对象，`is` 恒为 True；超出范围运行时各自创建新对象，为 False。这是实现细节，比较值请用 `==`（见上文「小整数池与字符串驻留」）。

**Q: 关键字数量为什么在不同资料里不一样？**
关键字集合随版本演进变化（如 3.10 新增 `match`/`case` 软关键字），以 `keyword.kwlist` 输出为准。

**Q: 如何快速检查变量类型？**
`type()` 查确切类型，`isinstance()` 做兼容继承的类型检查，`id()` 判断是否同一对象；复杂结构可用 `pprint` 美化输出便于排查。

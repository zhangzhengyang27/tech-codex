# 客观严谨：事实+论证过程+观点，打造高水准分析

> 本篇给出高水准分析的基本公式:客观严谨的分析 = 事实 + 论证过程 + 观点,并逐一说明如何陈述事实、如何陈述论证过程、为什么观点不能预设立场。适合希望摆脱"我觉得……"式不专业表达、提升分析可信度的数据分析师。相关主题:[指标思维](04-指标思维：如何搞清楚各种不同的指标类型.md)、[逻辑推理](05-逻辑推理：招聘要求里的逻辑思维能力到底指什么？.md)。

在没有数据分析的时代,企业的决策往往依靠领导的智慧和经验。这种决策太依赖个人能力,不仅不容易复制,很多时候只是靠直觉,许多员工心里也未必接受决策结果。

数据分析则是用数据作为事实,用严密的逻辑分析,揭示业务现状和发展趋势,得出科学的结论。这样既可以避免"拍脑袋"决策,还能让所有人了解决策的事实依据和逻辑链条,从而认可决策的结果。

但很多新人分析师学会了很多分析方法,客观严谨的思维却没有跟上,在平时的分析和沟通中容易给人留下"不专业"的印象。比如在业务方案讨论会议上,新人分析师发言时不自觉就会说"我觉得应该怎样怎样……"。日常沟通这样说不算大问题,但在有领导在场的严肃会议上,这瞬间暴露出不够专业的底色:提出想法全凭主观感受,数据呢?分析呢?**本质上没有用数据和逻辑思考问题。**

## 为什么客观严谨那么难

人脑有两种思考方式:直觉思维和理性思维。要做到客观严谨,就必须用理性思维思考问题。

但人是**优先使用直觉思维的**,因为直觉思维可以快速做出判断,节省大量能量。例如辨别两个柱形图的长短,直觉思维一眼就能看出来;而计算第二个柱形图的提升比例,则必须集中注意力,使用理性思维。

![Drawing 1.png](/data-law-images/i/image/M00/7C/86/Ciqc1F_Np8iAMym0AAAjsiFdN8I335.png)

直觉思维的缺点同样明显:**非常容易出错**。

比如,当有人问"新产品的表现还可以吧?"直觉思维会马上想起新产品多种好的表现;而当问题变成"新产品表现是不是不太好?"就会马上想起新产品那些不太好的表现,进而倾向于得出"表现不太好"的结论。

新产品表现到底好不好,不应该被问法所影响。如果理性思考过这个问题,那么不管对方怎么问,答案应该是一样的。

基因让人天生倾向于使用不怎么可靠的直觉思维,不经过专门的训练,没法克服这种天性。

## 什么是客观严谨的分析

客观严谨的分析 = 事实 + 论证过程 + 观点。首先要区分什么是事实,什么是观点。

**事实**:记录的客观存在,不以人的意志为转移。
**观点**:思想的主观判断,可以"仁者见仁、智者见智"。

一个简单的例子:

- 某平台上的《数据分析思维》课程是一门关于数据分析思维的课程。

- 某平台上的《数据分析思维》课程是最好的数据分析思维课程。

第一句是事实:这门课程是否讲数据分析思维,是客观存在的。第二句是观点:哪门课程最好,是非常主观的事情,不同的人有不同的标准。

事实和观点看起来容易区分,但如果表达不够精准,看起来像事实的话,在别人理解中却成了观点。

![Drawing 2.png](/data-law-images/i/image/M00/7C/91/CgqCHl_Np9SABoesAACcST5dWY4672.png)

比如上图所示,小白说"本月的销量大幅下降",这看起来很像一个事实。

但小黑觉得这是小白的观点:明明销量值只下降了 10%,跟历史同期相比完全正常,算不上"大幅下降",只能算"正常范围的波动"。小灰也觉得这是观点:本月销量虽然相比上月下降,但整体趋势依然是提升的,"大幅下降"把问题说得太严重了。

要说出**精准的事实**,应该表述为:本月的销量环比上月下降 10%。

同一份数据事实,不同的人会得出不同的观点。所以为了统一意见,在事实和观点中间,还需要增加一个论证过程。

比如:

> 落地页转化率是 1%,转化率较低。

绝大部分新人分析师的分析报告都会这么写。"落地页转化率是 1%"是事实,"转化率较低"是观点。虽然有事实支撑,但这个观点明显有问题:凭什么 1% 就是低?很多新人评判高低完全看数字大小,觉得 1% 这么少肯定算低。但业务人员一看,觉得这个转化率很高,因为平时的转化率只有 0.5%。这就是论证过程不同导致的观点不同。

所以,客观严谨的分析 = 事实 + 论证过程 + 观点。

## 如何陈述事实

陈述事实有三个要点,逐一说明。

### 1. 避免模糊的名词

数据分析工作中像"活动效果""满意度""流畅度"等名词,每个人都有不同的理解。比如"活动效果",有人认为是活动带来的销售额,有人认为是活动带来的销售人数。每个人对同一个名词的理解完全不同,沟通中就会带来许多麻烦。

要明确具体的、可衡量的指标或名称,常见的指标类型见[《指标思维》](04-指标思维：如何搞清楚各种不同的指标类型.md)。

### 2. 用具体数据代替形容词副词

通常人们喜欢用模糊的形容词或副词描述某种程度,比如"很多""很好""可能""大幅""一部分"等。这类词每个人的理解不同,想当然地以为其他人和自己的理解一样,就会出问题。

在向老板汇报时说"本月业绩表现不错",即使当月业绩真的不错,也会被老板一顿批评——老板永远都觉得还能做得更好,而汇报者的标准和老板的标准肯定不在一条水平线上。

### 3. 专业名词不要搞错

有时候不是分析师主观上不说事实,而是专业名词搞错了,说出来自然也就错了。

比如:上一次活动的转化率是 10%,本次活动的转化率是 15%,本次活动转化率提升了 5%。

这个表述有问题:百分比和百分点在统计学中有区分。

> **百分比**:一种相对数,表示一个数是另一个数的百分之几。从 1% 提升到 2%,就是提升了 100%。
>
> **百分点**:以百分数绝对值的形式表示变动幅度。从 1% 提升到 2%,就是提升了 1 个百分点。

所以正确表述是:原转化率 10%,现在的转化率 15%,提升了 50%,或者说提升了 5 个百分点。

日常工作中还有一些容易搞错的名词,比如"比例""比率""倍数""番数"等。尤其在各种业务汇报中,每个人理解的不同,可能导致重大的决策失误。可以把"数据分析专业名词""统计学专业名词"作为关键词检索补习,搞清楚这些概念后再向业务方宣贯,沟通起来会方便很多。

## 如何陈述论证过程

陈述论证过程,就是必须说清楚分析方法是什么、如何得出结论。

没有接受过理性思维训练的人在得出结论时,很容易陷入直觉思维,说不清楚自己是怎么想的,别人质疑结论时只会说"这还不明显吗?"。

说清分析方法,就必须了解有哪些分析方法。常见的逻辑推理方法有演绎法、归纳法、类比法等,详见[《逻辑推理》](05-逻辑推理：招聘要求里的逻辑思维能力到底指什么？.md)。

::: warning 分析结论的边界
数据分析师要保证结论在逻辑上是正确的,但**不能保证在业务上也正确**。能拿到的信息是有限的,不可能知道每个人每时每刻的想法,结论必然只是在不完整的数据基础上得出的片面理解。分析能力的提升只能降低这种情况的发生,但不能完全避免。
:::

虽然分析出的结果对业务来说不一定正确,但只要结论是逻辑严谨的,就有复盘的可能:业务结果错了,复盘推导逻辑就能知道问题错在哪,很快纠正回来;结果对了,这次的论证方法又可以复用到其他类似场景。

这就像学生时代:不知道知识点,就算知道了这次考试的答案也没用,下一次考试还是会错;而如果依靠自己对知识点的理解答题,考试成绩不好时也知道哪一块需要加强,长此以往就能不断成长。

评估一个数据分析师的潜力,一个常用观察点就是其思考过程是否清楚——**思考过程清楚,就有持续进步的可能性**。新人不了解业务很正常,只要逻辑清楚,熟悉业务后自然能输出好的结论;思考过程不清楚,哪怕得出过很多好结论,也很难总结出经验,成长空间有限。

因此:**结论可以错,但过程一定不能错**。

## 观点不要预设立场

有了事实和论证过程,引出最后的观点就顺理成章。观点论证最重要的注意点是:**千万不要预设立场再做论证**。

比如转化率下降了,业务方(运营)的第一反应往往觉得不是自己的问题:感觉自己的运营活动明明做得很成功,转化率下降一定是行业因素、用户质量或其他外部因素导致的。然后为了证明这个观点,顺着预设的前提,找到一些相关的证据来解释转化率下降的事实。

只要想证明一个观点,不管观点多么荒谬,总能找到支持的理由。

**例如,数据口径差异**。想证明一个错误的结论,最简单的办法就是用不同口径的数据作对比。今年受新冠肺炎疫情等因素影响,印度 4 月至 6 月的季度 GDP 暴跌 23.9%,印度媒体称印度在这一季度的经济表现是全球倒数第二、美国倒数第一。

![Drawing 3.png](/data-law-images/i/image/M00/7C/86/Ciqc1F_Np_eAVleTAARjQngfdjg158.png)

"倒数第二"是刻意混淆数据口径的结果:美国的 GDP 算法是年化环比算法,是单季度比上季度比值的四次方,也就是假设整一年都受新冠疫情影响并且隔离在家才是下降 32%;而印度是实打实地下降了 23.9%。

**再如,刻意挑选的数据**。通过刻意挑选的数据,可以证明一件看起来非常荒诞的事情——"中国男足是世界强队":

> 1. 哥斯达黎加是世界杯史上为数不多能够战胜中国队的国家。
>
> 2. 即使是巴西队这样的世界强队也仅战胜过中国队一次。
>
> 3. 自 2002 年韩日世界杯后,中国队在世界杯正赛上不败纪录已经延续 18 年。
>
> 4. 纵观漫长的世界杯史,中国队也仅输过三次。
>
> 5. 中国队从未在世界杯点球大战中失利过。
>
> 6. 中国队在领先的情况下从未丢过球。

上面每一条都是真实的数据,但结论却是非常可笑的。只要想证明一件事,总能找出一些证据,所以预设立场再去找证据是相当不靠谱的事。

::: tip 假设检验 ≠ 预设立场
数据分析确实需要假设检验,但**假设检验≠预设立场**:

- **预设立场**:找证据证明猜想,一个数据不行就换另一个,直到能证明这个观点为止。不管结果怎么样,立场都不会变。

- **验证假设**:事先规划验证这个假设需要的数据,如果数据最终不符合假设,就抛弃这个假设。

好的数据分析师能够根据客观数据,随时抛弃旧的假设,并建立新的假设。抛弃固有的思维定式非常反人性,这也是为什么数据分析需要专业训练。
:::

# 用户增长：找出快速提升用户数的关键行为

> 增长黑客以试验和数据驱动业务，用户增长是其中最受关注的领域。本篇说明提升总活跃用户数的三条路径及其优先级，并重点展开"关键行为分析"——找出让新用户感知产品价值、从而留下来的具体行为，为增长团队提供运营抓手。

## 提升用户数的三条路径

用户增长的目的是提升总的活跃用户数，有三条路径：

1. **提升新用户的数量**；
2. **提升老用户的留存率**；
3. **召回已经流失的用户**。

三条路径的优先级并不相同：

- **提升老用户留存**主要通过产品优化、运营活动等方式实现，产品分析和运营分析在其他篇目已有案例。
- **召回流失用户**优先级靠后，效果往往不好：用户已经流失说明对产品失去了兴趣，扭转看法比较困难，不如直接找对产品还一无所知的新用户。而且优化老用户留存本身也会降低流失，所以流失召回一般等到新用户和老用户留存都优化得差不多时再考虑。
- **提升新用户数**最终目的是留住他们成为忠实用户，可再分为两部分：获取更多的新用户、留住更多的新用户。前者通过渠道分析或裂变活动实现，渠道分析有两种核心方法：归纳法——分析目前渠道流量情况，优化渠道资源分配结构；演绎法——分析优质用户的用户属性，找到匹配该属性的新渠道。

本篇重点讨论如何通过关键行为分析留住更多新用户。

## 关键行为是什么

要让新用户留下来成为忠实用户，必须让用户感受到产品的价值。只靠签到、发红包等运营活动维持新用户留存绝对不能持久；用户感受到产品价值时，才会自发地继续使用，成为忠实用户的概率大大上升。

为了让用户感受产品价值，希望用户完成一些**能让用户认识到产品价值**的特定行为，这些行为就是"关键行为"。它的一般形式是："谁、在多长时间内、完成多少次、什么行为"。比如社区类 App 的关键行为可能是：用户在 3 天内添加超过 10 个好友。

只加了 3 个好友的用户，能聊的朋友不多、能看的信息很少，感受不到这个社区 App 的价值，离开也没有什么损失。而添加超过 10 个好友的用户，能看到更多好玩的信息、好友关系链更稳固，会觉得这款 App 还挺有意思，离开就需要思考一下了。

找到关键行为，提升新用户留存率就有了具体抓手——整个团队只需要思考如何让用户完成关键行为。这也是现在的产品交互越来越"傻瓜式"的原因：像短视频 App 几乎已经不需要新手引导，看到界面就知道如何操作。

## 关键行为分析怎么做

### 第一步：列出可能的关键行为

列出可能让用户感受到产品价值的行为，思路类似[《系统结构》](06-系统结构：跳出问题看问题，让你的分析直击关键.md)中构建议题树的两种方法：

- **归纳法**：列出所有可能性，再分类汇总。适合对业务不了解、或业务模式本身还不够清晰的时候。最简单的做法是把所有功能全部列出来，逐一分析哪一个功能对新用户留存率有提升作用。增长黑客有个著名案例：Instagram 的前身是一个基于位置的社交网络 App，功能特别杂乱，分析后发现大多数功能无人问津，只有图片分享功能特别受欢迎，于是砍掉其他功能专注做好图片社区，很快获得成功。
- **演绎法**：从业务的角度出发思考。大多数产品有明确的产品定位，这类产品用演绎法——先看业务属于什么类型、产品定位满足什么需求，再制定对应的关键行为。

关键行为一般有两种类型：

**1. 使用了某个核心功能。** 核心功能就是产品要解决的问题本身。音乐类 App 的核心功能是听歌，关键行为可以定义为"播放歌曲"。其他类型的产品也类似：

| 产品类型 | 核心功能类关键行为 |
|---|---|
| 社区类 | 浏览社区内容 |
| 投资类 | 投资交易 |
| 资讯类 | 查看资讯 |
| 购物类 | 完成交易 |

**2. 和其他用户或内容建立了联系。** 用户与其他用户或内容建立联系。还是以音乐类 App 为例，这类关键行为有关注用户、收藏歌曲。一个用户关注了很多人、收藏了很多歌曲，就很难流失。这也是几乎所有产品都想做社交的原因——社交可以沉淀关系价值，增加用户留存率。

| 产品类型 | 建立联系类关键行为 |
|---|---|
| 社区类 | 关注用户、点赞内容 |
| 投资类 | 收藏某投资品种 |
| 购物类 | 收藏商品 |

### 第二步：数据筛选

数据筛选要做两件事。

**第一件事：定义更清晰的关键行为，确定"魔法数字"。** 第一步找出的只是"播放歌曲"这类行为，还要确定在多少时间周期内、行动多少次才算数，比如"半小时内播放 5 首歌"。"半小时""5 首歌"这两个数字就是常说的"魔法数字"——满足这两个条件的用户，留存率会有明显提升。

确定这两个数字一般用**拐点法**：列出不同数字对应的用户留存率，找出拐点所在。

比如播放歌曲的数量越多，用户留存率越高，其中 3 首是比较明显的拐点——播放超过 3 首歌，留存率继续增长但幅度逐渐变小、趋于稳定。这种情况就选择"播放 3 首歌"作为关键行为。

**第二件事：对比不同关键行为的留存效果。** 对比不同关键行为的用户在之后一段时间的留存率曲线，找出留存率更高的行为。

如果第一步选出了 3 个关键行为，最终留存对比显示 A 行为的长期留存更好，那么 A 行为比 B 和 C 更好。

::: warning 单看留存率有陷阱
这种方法没有考虑 A 行为的覆盖人群：A 行为可能只适合一小部分群体，虽然留存率高但使用人数非常少，属于小众强需求，很难推广。
:::

解决办法是用"功能的使用率"和"功能用户的 App 留存率"两个指标画矩阵图，找出更合适的关键行为：

如果矩阵显示 A 行为的用户留存率更高但功能使用率较低、覆盖人数少，而 B 行为在使用率和留存率上表现更均衡，那么 B 行为相比 A 更适合做关键行为。

### 第三步：主观筛选

数据筛选的结果不能直接使用——数据只能说明这个行为和留存提升相关，但功能本身也许不是用户的真实需求，甚至可能只是其他行为的必经环节。

**必经环节不能作为关键行为。** 比如产品首页起到功能分发效果的宫格，是跳转各个功能的快捷入口。宫格点击本身不能满足用户需求，宫格跳转后的具体功能才可以，所以宫格点击不能作为关键行为。

**相关不等于因果，要区分用户类型。** 比如数据发现看了新用户引导视频的用户留存率更高，但看视频本身并不能给用户带来价值，可能是两种情况：

1. 能耐心看完引导视频的用户，本身就是对这个 App 有较强需求的用户，留存率天然更高——这批人不需要做什么改动；
2. 视频中某个产品价值的介绍打动了用户，用户看完后体验了该功能，所以留存较高——这种情况要找到用户看完后使用了哪个具体功能、该功能对留存提升有多大，再优化使用链路和引导内容，让用户更容易使用那个功能。

经过这三步，最终确定提升新用户留存率应该采用的关键行为。

## 小结

关键行为分析在增长黑客领域已经非常成熟，它的框架依然符合前面提到的分析主线：

| 分析框架 | 对应内容 |
|---|---|
| 业务问题 | 如何提升新用户的留存率 |
| 为什么要分析这个问题 | 可以提升整体日活用户数 |
| 问题的表面原因 | 用户喜欢用哪些功能 |
| 问题的根本原因 | 用户用这些功能是为了满足什么样的需求 |
| 怎么办 | 找到关键行为作为运营抓手 |

很多高手能记住各种模型和方法，是因为理解了方法的本质——抓住事物最本质的内容，用到时自然能从本质中回忆起相关内容。关键行为分析本质上还是 2W1H 模型，理解了这一点，不用刻意记步骤，自己就能推导出来。

# 深入业务，持续学习

> 掌握业务数据分析的思维和分析方法之后，本篇总结三个成长要点：分析思维要靠反复练习内化、业务理解决定分析师的层级、持续学习保持职业竞争力。

## 分析思维需要反复练习

分析思维的学习方法和知识的学习方法并不相同。知识的学习是"知道了就能用"——知道了 SQL 中一个函数的用法，下次读到别人的代码就能看懂，学一遍记住即可。

思维的学习仅仅"知道了"没有用，必须真正理解。否则学到的思维能力只能在面对相同场景时派上用场，换个场景就完全不知道怎么办。比如结构化思维，记住定义和应用方法很容易，但真要分析一个问题时，实际操作起来很不熟练。

::: tip 思维能力的获取没有捷径
掌握分析思维只能依靠反复练习，而且练习不必局限于数据分析项目，生活中随时随地可以进行：去超市前用结构化思维思考要买哪些东西；看到房价调控的新闻时，用逻辑推理思考调控措施会如何影响房价。
:::

练习一段时间后，面对问题时会条件反射地应用这些思维方式——这才是真正掌握了"数据分析思维"。

## 提升业务理解

分析问题的 2W1H 思维框架变化不会特别大，但业务思维和用户思维在当前的市场环境下变化非常快。掌握分析思维之后，要进阶成为更高级的数据分析师，需要提升业务理解，**深入了解业务模式和用户需求**。

深入了解业务模式，除了知道公司如何赚钱之外，还要了解团队的人员架构、运作方式等。因此业务数据分析师不要和业务人员坐得太远，最好能坐在一个办公室里甚至就坐在业务人员边上——这样可以全天候观察业务人员每天和谁对接、关心什么问题，遇到分析不下去的时候，沟通也更方便。

深入了解用户需求，可以多读用户调研报告，也可以采访身边用户朋友的真实感受。很多数据分析师忽视对用户需求的了解，习惯用数字反映用户需求，但用户不是冷冰冰的数字，而是一个个鲜活的人。从数字中解读出的用户需求只是问题的表象，未必能代表用户真实的想法，只有真正理解用户，才能提供有价值的分析结论。

**数据分析师的岗位竞争，初级拼技术，中级拼思维，高级拼业务。** 技术和思维有比较成熟的方法论可以学习，而业务理解每个行业、每家公司都不同，只能依靠分析师在公司里摸爬滚打出来的实战经验，培养一个精通业务的数据分析师只能靠时间，没办法速成。一旦具备这样的实力，分析师将成为驱动业务发展的强大引擎，成为公司不可或缺的人才。

## 持续学习

互联网行业迭代速度很快，各岗位都要经常学习最新的知识以保证职业竞争力。数据分析师作为交叉岗位，技术和业务的知识都需要经常学习，学习压力比其他岗位更大。

- **技术上**：关注业内前沿的数据技术应用。这几年大数据技术层出不穷，从 Hadoop 衍生出来的技术就有很多。数据分析师不必特别精通，但要适当了解各自解决什么问题——这样在有数据需求、和数据开发团队沟通时，就能很好地描述问题和希望的解决方案，发挥数据分析师作为技术和业务之间桥梁的作用。
- **业务上**：关注最新的业务模式和运营手段，比如增长黑客、各种裂变玩法等。了解最新的业务趋势，才能更贴近业务、找出有价值的分析方向。
- **职场通用能力**：管理、沟通、演讲等知识也值得学习，它们决定职场天花板。

数据分析师这个岗位总体处于快速发展期，对知识和能力的要求变化很快，只有持续学习才能保持自身的竞争力。

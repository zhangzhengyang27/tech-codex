# 怎样才更好地转型或成功跳槽？

> 本篇面向中小企业的数据分析师：先解答三个大厂面试高频问题（流量波动分析、常用 App 评估、商业化变现），再分析中小企业分析师"事情杂、单点分析"的日常工作现状，最后给出进入大厂的转型四步法——规划方向、评估自己、优化自己、实践面试。相关主题：[BAT 大厂的数据分析项目](./26-如何搞定 BAT 大厂的数据分析项目？.md)、[多元思维模型：数据分析需要具备的四大能力](./29-多元思维模型：数据分析需要具备的四大能力？.md)。

## 面试三大高频问题解答

### Q1：流量波动，数据突然涨了怎么分析——考察经验

这个问题非常经典，能够很好地考察分析师的经验。很多分析师工作了很长时间，依然解答不好。

**例题**：美团外卖近期的订单量突然下降 5%，需要分析师给出解释并提供下一步建议。

经验不足的分析师遇到这个问题时可能会盲目检查原因：口径问题？数据存储问题？产品变化问题？这样的回答都是单点分析，缺少全面性。

参考答案的思路是**先对命题进行解析**：订单量下降 5% 属于什么水位、影响范围有多大。如果发现对收入有重大影响，CEO 都可能会关注这件事，所以要更全面地分析原因。具体的分析模块包括：

| 分析模块 | 检查内容 |
|---|---|
| 常识判断 | 最近是否有重大节日，用户外出度假旅游导致订单量下降 |
| 竞品数据 | 竞品最近的数据有没有大涨，有没有做营销活动导致订单量下降 |
| 外部事件 | 社会上有没有针对外卖的负面事件，是否对品牌本身造成影响 |
| 产品变化 | 用户订单下降是否因为产品发布新版本，部分功能有缺陷导致用户无法下单 |
| 用户行为 | 整体订单量下降是全国普降，还是部分区域订单量下降 |
| 数据问题 | 是否因为采集数据的统计口径发生变化 |

从这六大模块去分析，面试官会觉得回答具有条理性、有架构，最重要的是能很快定位到问题。所以一定要有组织、有架构地回答问题，而不是单点分析。（六大类原因归类的完整方法论见 [BAT 大厂的数据异常排查](./26-如何搞定 BAT 大厂的数据分析项目？.md)。）

### Q2：常用三个 App——考察思考深度

建议回答与应聘岗位相关的 App。例如应聘公司的产品是 QQ 音乐，可以说常用的三款 App 是网易云音乐、微信读书、知乎。特意提到微信读书和知乎，是为了衬托亮点——网易云音乐。

面试官进一步问："就以网易云来说，能不能说下你对这个产品最喜欢的点，以及最想吐槽的点。"这个问题考察的是**是否高于普通用户**。

可以回答："最喜欢网易云的每日推荐；最想吐槽的是很多时候通过搜索来选择听某歌，但搜索栏没有语音输入，同时下面的热门搜索跟我的画像非常不准，都不是我喜欢的，那些歌、明星可能我都没听过。"这个回答代表**已经有了自己的见解，不只是简单使用产品**。

面试官再问："如果你是产品经理，你会怎么解决这个问题？"

回答："先看热门搜索的点击率多少，如果较低说明确实有问题，可以把热门搜索功能与用户的画像匹配，实现千人千面，同时在搜索栏增加语音输入功能。"

面试官再问："怎么评估这样做能带来指标的提升？"

回答："先开始小流量 A/B 测试，然后慢慢放量，如果效果还不错，就全量。"

面试官再问："能不能说下你对 A/B 测试的理解，如正交性、A/B 测试的设计……"问到这一步，表示面试官已经非常感兴趣了。

如果回答微信、淘宝、B 站之类的通用 App，就无法衬托亮点，也无法让面试官接着往下问。（A/B 测试的系统讲解见 [AB 测试：AB 测试的效果监控](./43-AB 测试：AB 测试的效果监控.md)。）

### Q3：商业化变现——考察对商业目的的敏感度

分析师日常所有的 PV、UV、MAU、DAU 等指标，最终都是围绕商业变现这一本质目的。

**例题**：举例一款工具类产品，说说如何商业化。

参考回答（以墨迹天气 App 为例）："首页'天气'Button 是主流量入口，进行底部下拉时会出现资讯，资讯里有较多广告 App 下载链接，所以这是一个 App 带量商业化的时景 Button，内部有较多旅游景点、住宿类 App 下载推荐，这里也是自身 App 高相关商业化推荐。'Me'这个 Button 分生活、娱乐、休闲、游戏四大板块，每个模块都有自己的商业化坑位。"

面试官问："目前产品的主要商业化收入来自哪里，各自的 CPM 大概多少？"

回答："主要来自'时景'Button 的旅游景点推荐，CPM 大概在 6 元。"

面试官又问："当前产品商业化提升的痛点是什么，之前做过哪些优化方案，效果如何？"

回答："作为工具类产品，用户停留时长短是最大的痛点。作为一款天气 App，我发现用户周末效应非常明显——周五晚上、周末用户很多，所以当时我猜想是否存在一批用户群会在周末出去游玩，加上后来的调研，发现果然是这样。于是我们跟这类旅游景点合作，做线下场景推荐，果然现在效果也是最好的。"

这段话的意义在于：所有的商业化都是找到一个合理的切入点，而不是无脑商业化。通过数据分析落地了实际动作，面试官的印象就会完全不同。

## 中小企业的日常工作

相对国企以及 BAT，中小型私企的数据分析师在公司中可能没有那么重要，做的事情比较杂：

- **技术**：Java、Python、R 都比较熟练，机器学习的书也看了几本，觉得自身技术还可以，但实际上却没有真正落地过。
- **研发埋点**：字段格式、字段名、字段取值、打点日志、文档沉淀，都需要分析师日常梳理。
- **口径和指标体系梳理**：包括梳理口径和指标体系的定义与计算方法，还有产品的核心指标和一些业务性指标。
- **报表统计**：所有报表的增加、修改。
- **专题分析**：偶尔做一些专题分析，但整体质量都不高——偏单点分析，缺乏逻辑的连贯性及全面性。
- **平台研发**：有些企业的分析师还要参与平台研发，比如做数仓、底层数据清洗，甚至类"友盟"大数据平台的开发。

无论横向还是纵向，数据分析师都像救火员一样忙。有些分析师自己也知道当前做的事情对能力提升意义不大，于是可能出现两种现象：

1. 在数据分析专业性上略显自卑，觉得当前做的事情很杂，于是拼命学习充电，但落不了地，学得快忘得快。
2. 在专业性上过于自信，很多东西都玩过，觉得自己什么都知道，想跳槽，但发现不容易，也不知道问题出在哪里。

这两种现象至少说明足够积极努力，只是当前没有遇到适合的 leader 或指路人。真正的解法是主动转型。

## 转型四步法

中小企业的数据分析师需要转型——转型不是换一个行业，而是立更宏伟的目标：去 BAT 这样的大企业做数据分析。一旦经历这个过程，看问题的角度就会不一样。

**转型者画像（A）**：

- 学历：普通本科毕业，数学或其他理工科专业；
- 目前岗位：某中型企业（500 人）的数据分析师；
- 日常工作：以写 SQL 提数为主，在公司的存在感不高，正在学习 Python；
- 未来目标：学好 Python 后换一份薪水高的工作，进一家更好的公司；
- 当前困惑：不知道这条路行不行，反正先学着。

独角兽企业招人会看重两方面：一是学校是否名校、专业是否对口，A 不具备；二是工作经历——是否在行业内知名公司待过、有没有特别大的项目产出，A 也没有。但仍有机会，机会来自"机缘巧合"：非常用心地准备几家中意公司的面试，最终总会有一家因为各种机缘巧合录取——比如该企业招了很久一直没招到合适的，业务老大急着要干活，刚好面试表现很好。周围有太多与 A 处境类似的人最后进了独角兽企业。用心准备分为四步。

### 第一步：规划方向

分析师有三个发展方向：

- **业务线**：适合对事物感到好奇并深入研究、思维发散并且能收敛、喜欢展示自我、逻辑思维较强的人。
- **研发线**：适合喜欢写代码、喜欢安静独处、计算机功底好的人。
- **算法线**：适合做研究、数学功底好的人（很多时候要看各种国外论文）。

### 第二步：评估自己

业务型数据分析师的考量标准有以下几种：

- **产品理解能力**：各种数据熟悉度、用户从哪里来、进来后做了什么、用户反馈最多的问题是什么、竞品数据怎么样。注意所有结论都要用数据说话，而不是"大概"。例如"50% 的用户从微信渠道进来，使用某产品，其中又有多少用户因为什么问题离开"，这才是产品理解能力。
- **分析方法论**：常见分析方法有哪些，A/B 测试、最大概率法则、二八定律、幸存者偏差的理解程度。
- **可视化能力**：PPT 功底、专题报告逻辑性、金字塔原理、审美。
- **演讲能力**：表达能力、讲故事能力、形象化能力、抗压能力。
- **协作能力**：跟产品、业务、研发沟通时的软技能；如何在团队中定义好自己的位置并让其他人舒服。针对同样一个问题，为什么 A 可以完成而 B 不行，这就是软技能的差距。
- **逻辑思维**：分析推导过程的全面性、合理性、价值性。
- **技术**：Excel 常见操作、SQL 熟练度，R 能否搭建模型并知道有哪些坑，Python 是否能用上。很多人会搭建模型但不会调试、修正模型，实际上就是没有真正实践过。如果当前 Python 并不能很好地用于未来几个月的工作，暂时了解即可，不用花很多时间。

评估后在可视化演讲、协作方面还可以，但产品理解、数据分析方法论偏弱，就明确了要弥补的短板。

### 第三步：优化自己

以产品理解为例：先以当前公司业务的产品为切入点，熟悉最核心的数据，了解功能渗透率和关键路径，以这些数据为切入点思考当前产品有哪些问题；并与产品经理沟通如何优化；同时要看竞品数据和行业数据。最重要的是深入了解而不是略懂。

例如当前公司产品是视频类 App，就要深入研究行业前三甲：爱奇艺、腾讯、优酷。

- **什么是略懂**：在网上搜集了一些数据，知道这几个 App 的大概用户数及核心功能，了解行业整体规模。这些没有意义，因为这些信息其他人也能搜到。
- **什么是深入了解**：知道整个视频行业各个不同阶段的领头羊是谁、他们依靠什么成为领头羊、又因为什么出现增长瓶颈、当前各自的打法侧重什么、对自身 App 有什么借鉴、后续要监控哪些数据。

只有到这一步才是自己的见解，面试时才能说服面试官。

第二个优化是数据分析方法论。**方法论是能快速从一个较全面、逻辑性、价值性的角度去分析，而不是单点无架构性分析；所有方法论都是通过不断提炼、总结、实践得出来的。**这是评估分析师水平的重要标准。常见的方法论包括指标体系方法论、流量分析方法论、路径分析方法论、产品分析方法论、营销活动分析方法论、用户流失分析方法论——本系列后续篇章会逐个展开。

### 第四步：寻找对象并实践

面试建议按三个梯队挑选公司：

- 挑选三家一般性的公司作为面试训练，锻炼口才以及场景感，尝试临时发挥；
- 挑选两家规模较大、知名度较高的公司作为保底要进的公司；
- 再挑两家业内领头羊公司来尝试，能进更好，没进就当开拓视野。

最重要的是设定一个跳槽时间段（比如三个月），这三个月瞄准两家保底公司。这两家是职业生涯的转折点，所以简历要单独写、花几天时间打磨；每一次面试后都要总结不足、多加训练。

面试环节最重要的还是表达。真正的面试准备可能要花几个月时间，只有经过这种训练，跳槽才有意义，才能越跳越好，而不是在原地跳槽。

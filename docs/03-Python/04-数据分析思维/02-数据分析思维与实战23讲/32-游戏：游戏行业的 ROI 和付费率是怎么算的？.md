# 游戏：游戏行业的 ROI 和付费率是怎么算的？

> 本篇以欢乐斗地主游戏为例介绍游戏行业的数据分析：先定义常规指标（DAU、留存率、渗透率、转化率）与商业化指标（ARPU、CPM、CPC、ROI）的口径，再讲解流失用户周期如何用回流率确定、流失分析的套路与差异点，最后以付费分布数据说明付费分析的思路与优化建议。相关主题：[电商数据分析](./30-电商数据分析：京东 App 的详细产品分析.md)、[传统行业交易额提升](./33-销售：传统行业如何做好交易额提升？.md)。

## 背景

游戏行业兼具互联网与金融的数据思维。游戏行业用户两极分化比较严重：要么快速流失，要么玩的时间很长。因此本篇重点围绕两个目标：

- 尽量让用户晚点流失——**流失分析**；
- 让花时间的用户多变现——**商业分析**。

## 指标口径

指标口径包括常规指标和商业化指标两类。

### 常规指标

**1. DAU、WAU、MAU**：分别指产品的日活、周活以及月活。对于任何产品，首先要看用户规模——用户规模是一个亿还是五千万，要有具体的数值。

**2. 留存率**：一般看次留、7 留、30 留存率。留存率是一个比例，反映产品的黏性程度。以次留率为例：

```
次留率 = 第一天打开 App 且第二天也打开 App 的人数 / 第一天打开 App 的人数
```

例如第一天打开欢乐斗地主 App 的有 1000 人，第二天这 1000 人里又有 800 人打开了 App，次留率为 800/1000*100 = **80%**。

**3. 渗透率**：每个子功能的渗透率 = 该模块的使用人数 / 该产品的日活。

例如欢乐斗地主昨日 DAU 为 1000 人，昨日有 900 人点击"商城"，那么"商城"渗透率为 900/1000*100 = **90%**。

**4. 转化率**：针对某个连贯路径，等于使用下一个节点的用户数 / 使用上一个节点的用户数。

例如欢乐斗地主：打开 App（1000 人）→ 进入房间（800 人）→ 参加比赛（700 人）：

- 进入房间的转化率 = 800/1000*100 = **80%**
- 参加比赛的转化率 = 700/800*100 = **87.5%**

### 商业化指标

**1. ARPU：一个时间段内的用户平均收入**

```
ARPU = 付费金额 / 活跃人数
```

例如欢乐斗地主付费总金额 200w，活跃人数 100w，用户平均收入 2 元。

**2. CPM、CPC**

```
CPM（千次曝光成本）= 广告投入总额 / 所投广告的展示数 * 1000
CPC（单次点击成本）= 广告投入总额 / 所投广告带来的点击用户数
```

例如某广告主在欢乐斗地主的闪屏界面投入广告 10w，共展示 1000w 次，CPM = 10。又如某广告主投放闪屏广告 100w，共产生点击 50w，CPC = 2。

**3. ROI：投资回报率**

```
ROI = 收入 / 支出 = ARPU * 用户数 / 所有支出
```

例如双 11 在欢乐斗地主内部投放一个广告 100w，最终带来收入 200w，那么 ROI = 2。

## 用户流失分析

行业内把一个月内不使用产品的用户定义为流失用户，但不同产品形态的用户行为差异非常大——住宿类 App 是低频高价值用户，而欢乐斗地主 7 天不上线可能就已经流失，所以要合理定义流失用户。流失用户发现得越早越好。这里会出现不太好定义的情况：比如先定义 30 天不来即为流失，结果到 30 天时大量用户回流。

### 用回流率确定流失周期

用户流失周期的确定本质上是回流率的确定：一旦用户回流率稳定，就可以定义这个时间段的天数为用户流失周期。

```
用户回流率 = 某个周期内的流失用户数在周期结束后又回来了 / 某个周期内的流失用户数
```

根据这个公式按枚举法，周期天数取 1, 2, …, 30，分别计算回流率，一旦回流率趋于收敛，该周期就是流失周期。例如定义 1 天不来为流失得出一个回流率数值，定义 2 天不来为流失又得出一个数值，以此类推到 60 天就有 60 个回流率数值，可以画出一条曲线——曲线在哪个时间段趋于平缓，那个周期就是合理的流失周期。

### 流失分析：类似套路与差异点

**类似套路：看用户在流失前最后一步干了什么，是什么导致用户体验差而流失。**

以欢乐斗地主为例，用户最后一步行为分布为：40% 在比赛房间里流失、30% 在做任务时流失、20% 在商城里流失、10% 是其他原因；最后一步行为到退出游戏的时长分别为 10s、30s、20s、5s。

| 流失场景 | 占比 | 流失前停留时长 |
|---|---|---|
| 比赛房间 | 40% | 10s |
| 做任务 | 30% | 30s |
| 商城 | 20% | 20s |
| 其他 | 10% | 5s |

基于这些数据可以进一步分析：

- 比赛房间流失最严重，需要对比赛房间进行拆解，看哪个行为占比很高——是在经典模式、残局模式，还是正式比赛过程中，然后进一步往下拆解；
- 任务中的流失：用户做任务花了 30s 然后退出了游戏，这个时间是不是太长，过程中用户是不是遇到了困惑；
- 商城流失花了 20s，用户在商城里基本是买东西，要看用户到底是纠结价格还是其他原因。

可以基于以上数据进行猜测，再通过其他数据验证。

**差异点：必须深度体验游戏。**欢乐斗地主是一款非常复杂、需要占用用户大量时间的 App，数据分析师要研究好用户为何流失，必须很深入地玩游戏，找到游戏中的快感和痛点，跟其他玩家多交流，否则就是脱离业务。

经过多轮游戏体验和玩家交流，发现以下问题比较严重：

- 每天只送 2 次 3000 欢乐豆，几分钟就输完了，找不到游戏的兴奋点以及赢的快感，用户觉得没意思；
- 欢乐豆积累很多之后输得非常快，让人很气愤；
- 感觉作弊机制比较严重，有合伙坑人的可能性；
- 任务越来越多、越来越看不懂，可以直接换欢乐豆的活动越来越少，头衔玩法比较鸡肋；
- 商城内的欢乐豆太贵，没有 1 元试用。

::: tip 游戏分析的要点
对游戏（特别是网游）分析，要结合游戏深入体验和初步数据一起分析，才能有明显效果。
:::

## 用户付费分析

游戏行业前期投入较大、迭代比较快，所以对付费变现有非常高的要求。付费分析的整体思路：

1. 以付费金额分布和付费模块为切入点；
2. 根据第 1 步确定未来重点在高、中、低哪个群体；
3. 进行 A/B 测试，并每天看收入情况。

欢乐斗地主的付费分布有三张饼图，分别对应付费金额分布、付费等级分布、付费模块分布：

- **付费金额分布**：大部分用户愿意付 3 元、10 元，这部分用户占比 90%。
- **付费等级分布**：用户在"短工""长工""佃户"等级时变化都不明显，但到"贫农"等级立马上升到 9%——用户在"贫农"这个等级的付费意愿非常关键；下一个节点是"富农"等级，占比 22%，从 11% 的"中农"直接跳到 22% 的"富农"，"富农"是另外一个节点。
- **付费模块分布**：欢乐斗地主的商城有各种付费方式，最主要的是欢乐豆，占比 70%；钻石只有 25%，其他占比更少。

基于这些数据可以进一步分析。

**为何没有 5 元的付费金额？**商城界面共 8 个坑位位置，但只使用了 7 个，明显浪费一个坑位：第一个坑位是 36000 豆 + 30 钻石，即 3 元；点击第二个坑位 75600 豆（60 钻石）后提示钻石不足，提示是否用 10 元充值 100 钻石、充值成功后自动购买；第三个坑位 132000 豆点击后提示也一样。这说明第二个坑位本身是一个人为的 bug——用户肯定会买第三个而不会买第二个：第二个坑位 10 元只能充 75600 豆，第三个坑位 10 元可以充 132000 豆。同时可以增加一个 5 元的付费坑位——不要小看一个坑位，每个坑位都会产生点击及付费转化。

综合来看，欢乐斗地主 App 无论信息还是坑位都出现较大问题，说明产品功能没有体验到位，主要表现在：

- 当前用户付费金额以 3 元、10 元为主，超过 10 元比较敏感；
- "贫农"和"富农"是两个重要的付费等级节点；
- 商城以欢乐豆充值为主，钻石占比不高。

针对用户群及 App 问题，可以做出以下猜想分析：

- **直接结论**：当前 App 的用户群对钱很敏感，高端用户并不多，并且高端群体整体价值也不大。
- **数据结论**：在未付费用户中，必然存在一部分群体欢乐豆少于 3000 无法游戏，同时也去了商城查看但未消费，这部分用户需要想办法转化进来。
- **体验结论**：玩游戏都有兴奋点——兴奋点是多久，用户在什么级别时最想充值？

结合以上结论，可以做出以下优化：

- 推出 0.99 元 15000 欢乐豆，限额卡片；同时在首页界面提示充值 9.5 折，进一步让用户觉得有便宜可占；
- 对日活中缺少欢乐豆的用户，可以多送几次欢乐豆，让他体验时间长一点，先兴奋起来；
- 当用户在"贫农"和"富农"等级左右时，加强付费引导，满足其成就感。

## 总结

游戏行业非常注重收入，数据分析师需要每天看收入数据，所做的各种分析都要和收入挂钩。除了互联网行业的分析方法，游戏行业更注重分析师的深度体验——单纯的数据只能解决交互上的失误，不能让游戏变得更好玩。分析师最大的价值是让用户玩得更爽，只有到这一步，才能实现真正的增长。

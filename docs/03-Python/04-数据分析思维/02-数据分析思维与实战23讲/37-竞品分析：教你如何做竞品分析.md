# 竞品分析：教你如何做竞品分析

> 竞品分析回答的是"竞争对手在做什么、我该学什么、接下来怎么落地"这三个问题。适用于产品准备进入新行业、业务处于下降或瓶颈阶段、需要向头部玩家学习优点的场景。与[流量分析](./35-流量分析：如何分析数据的波动？.md)、[路径分析](./36-路径分析：用户的使用路径网络分析.md)等针对自身 App 的方法互为补充。

## 为什么要做竞品分析

指标体系、流量分析、路径分析等方法针对的都是自身 App，竞品分析则把视角投向竞争对手。

无论产品在行业中处于什么位置，都需要分析竞品：行业老大要防止外来者，警惕行业老二和老三；行业老二要看老大最近在做什么，从而模仿超越；行业老三或更靠后的玩家一方面要紧跟老大老二，另一方面要放大招、弯道超车。

在实际工作中，做竞品分析通常发生在以下几种情况：

- 当产品准备进入某个行业时，需要先把该行业的竞品分析清楚，主要侧重行业规模和前景的分析；
- 当产品发展处于下降阶段，需要看竞争对手在做什么，主要侧重头部玩家的玩法分析；
- 当产品发展处于瓶颈阶段，需要看竞争对手的数据和功能迭代，持续监控对手数据，从中寻找突破；
- 当产品发展处于快速上升期，一般不会做竞品分析。

对于一款 App，分析师在初期就要监控好竞品的各项数据，保持对竞品数据的敏感性，同时与自身 App 数据结合起来思考优化迭代。

::: warning 竞品分析的两个误区
很多网上的分析报告把竞品的功能罗列得太多，这是最初级的产品体验分析。竞品分析绝不是大而全地把竞品功能罗列一遍，也不是日常的竞品数据监控，配置一张报表就完事。
:::

竞品分析包含两个核心点：

- **竞品的选择**：哪些才是竞品？并不是所有头部玩家都是竞品，而是要根据做竞品分析的目的来选择。
- **分析什么点**：这需要知道分析的背景是什么，从而有针对性地切入，其中"分析什么点"最关键。分析师需要清楚 Leader 想做什么——如果这件事连 Leader 自己都说不太清楚，那最好先别投入大量时间去做。不是做得对或不对的问题，而是问题都没搞清楚，即使他是 Leader。

## 竞品分析的步骤

竞品分析分为三步。

### 第一步：确定分析目的

所有数据分析的第一件事，都是搞清楚分析的目的是什么。做分析一定要带着某种商业意图，分析目的分为以下几种情况。

- **评估进入新行业的可行性**。比如电商公司想做金融业务，这时要评估可行性，竞品分析更偏行业趋势、市场规模、财务收入，看大数不拘于小节。例如先看整个金融行业的情况，再看电商类公司的发展，如京东金融是怎么做的。
- **纯粹看竞品的功能、玩法和数据，学习优点**。"人无我有，人有我优"，以学习为主。这种分析目的比较常见，主要以功能体验、运营手法、具体数据为主，落地性非常强。
- **通过竞品不同版本迭代的功能、玩法和数据，揣摩竞品想干什么**，目的以预防为主。看竞品的版本迭代，思考竞品最近的战略中心在哪，这种情况往往是为了满足管理层的需要。

### 第二步：挑选 1～2 家竞品，进行对比分析

明确分析目的之后，下一步是把竞品与自身进行对比。首先挑选核心功能一样的 1～2 家竞品；其次是功能体验分析；再是运营手法分析，分析竞品的功能是怎么运用的，侧重对比运营手法；最后看宏观和微观的数据分析，也就是数据源——竞品数据源很关键，比如基础数据、财务数据、市场数据。

整个过程是一项由分析师牵头、产品与运营协助的团队任务，同时可能还需要财务、市场部的参与才能完成。

### 第三步：给初步分析结论

在对比分析的基础之上给出初步结论，结论要直接回应分析目的：

- 如果是评估进入新行业的可行性，结论就是回答"是否可以进入这个行业？如果可以进入，步骤是什么？"
- 如果是学习竞品的优点，结论要落到竞品的什么功能好、接下来产品和运营如何去做、预计能带来多少收益。
- 如果是看竞品版本迭代揣摩其战略，结论就是竞品的下一步战略是什么、自身要不要也做某种尝试。这种情况非常难，需要管理层去拍板。

## 案例：优酷与爱奇艺会员对比

以优酷、爱奇艺为例说明完整的竞品分析过程（双方 App 版本可能已更新，例子以文中截图为准）。

::: tip 案例背景
小 A 是负责优酷 App 会员模块的数据分析师。Q3 季度优酷会员增长乏力，而爱奇艺会员仍处于高速增长阶段。管理层希望对爱奇艺会员进行一次分析，学习爱奇艺会员的优点，从而提升优酷会员数。

从案例背景可以看出：**分析目的是提升优酷会员数，分析对象为爱奇艺**。
:::

### 第一步：基础数据与用户画像对比

先看基础数据。如果公司有内部数据，直接使用即可；如果没有，可以使用外部数据源，外部数据源基本可以从 Google、百度、QuestMobile、百度指数获取，但数据源只是一个参考。对于爱奇艺，能拿到的数据很多，但不是每一个数据都需要看，关键是想清楚看过这些数据后，对后面的分析有什么用。

既然分析的是会员数，首先要知道爱奇艺会员数与优酷会员数的差距。

![会员数对比](/data-practice-images/i/image/M00/31/59/CgqCHl8MNsaAfA1TAABUTG3Wk08278.png)

（数据来源为 Google，不是真实数据，仅举例）

从图中可以看出爱奇艺会员数明显占优势。其次要看用户画像：如果优酷和爱奇艺的用户画像比较类似，那么同样的功能、同样的运营手段就对双方都合适。用户画像可以从百度指数查看，从画像数据看，这两款 App 无论性别、年龄、地域都比较类似，在这个基础之上学习爱奇艺的优点是可以解决问题的。

如果在这里贴出用户数、使用时长等数据，实际上意义不大，因为对后面的分析没有用。所以第一步一定要想清楚后面想干什么，然后再去查数据的对比，用这些数据佐证想法。

### 第二步：产品对比——从用户痛点切入

产品对比有很多种方法，一般先画交互流程图，再体验产品模块。这样做的优点是大而全，缺点是在有限时间内不一定能得到结论。实际工作中产品对比要交给专业产品来做，分析师可以提供一种方法：从普通用户的角度看产品，看用户的真正需求和困惑点在哪里，基本可以通过线上问卷或线下调研得出结论。

假设调研发现用户犹豫购买会员的原因有三种：

- **选择困难症**——不知该买哪一家；
- **退货**——用户感觉价格太高、担心买了不满意；
- **功能价值**——付费功能吸引力不够。

从这个角度切入做产品对比，结合用户关心的痛点逐一比较爱奇艺和优酷：

- **选择困难症**：爱奇艺告诉了用户为何要买它，VIP 标识写得非常多、也非常明显，再加上体育会员、FUN 会员和会员俱乐部，提前抢占了用户心智。而优酷这方面比较弱——做一款 App，传播符号一定要很强。
- **退货**：用户购买后感觉不满意想退货退款，爱奇艺和优酷都没有给出解决方案。电商开始做 7 天免费退货就是一种巨大创新，视频会员可以在这方面探索。
- **功能价值**：当用户打开 App 时，要让用户感受到这款 App 对他有价值，最好的方式就是个性化推荐。爱奇艺当时没有个性化推荐，而优酷有。

再进一步是用户关心的价格。爱奇艺价格优势很明显，特别是新用户首 3 个月优惠，对拉新非常给力，而优酷在这一块做得没有爱奇艺好。同时在价格这个模块上，爱奇艺界面上有京东 PLUS 年卡、客服、常见问题、银行卡支付、学生会员、退出时会员弹窗提醒等细节，都做得很好，优酷相对差一些。

用户很在意价格相关的问题，可以结合客服数据进行优化。产品分析的目的是"人有我无"——从用户痛点出发，对比两款 App，看竞品有哪些我们没有的优点功能。

### 第三步：运营手法对比

在分析之前，先理解产品和运营的角色分工：可以把产品理解为生孩子，运营是养孩子。运营把孩子养大，需要持续观察孩子成长阶段的各个指标——成长的时候看身高体重，上学的时候看成绩，长大后看收入，这个过程可以理解为数据分析。

所有用户运营的目的都是提新增、拉留存、降流失，这是广义的用户运营概念。运营往往需要产品内容和产品活动的支撑来吸引用户：

- **内容运营**：通过内容来吸引用户；
- **活动运营**：通过做活动来吸引用户，比如 App 抽奖活动。

例如目的是通过优化渠道提升新增用户数，就可以优化渠道文案、在渠道侧做一些活动激励——即通过内容运营、活动运营达成最终的用户运营。

基于这个框架，对比爱奇艺和优酷在三类运营上的表现：

| 对比维度 | 爱奇艺 | 优酷 |
|---|---|---|
| 用户运营 | 有签到入口，签到内含 0 元秒杀 | 新用户进入后只提示续费，缺少仪式感和趣味性 |
| 活动运营 | IP+会员玩法（如"买特权卡送 3 重国风特权"）、学生会员提示 | 仅有双 12 会员活动，玩法新意不足 |
| 内容运营 | 两个大 Banner 轮播 | 只有一个大 Banner，差异明显 |

在内容运营中，内容生态值得单独拿出来讲：爱奇艺围绕内容有一个会员俱乐部，优酷也有一个俱乐部。对比两个俱乐部，无论 UI、用户使用便捷性、分类 tab 丰富度还是大 Banner，爱奇艺均明显优于优酷。爱奇艺的用户一进入 App 就能知道会员特权可以做哪些事，而优酷并没有给用户这种感觉。在会员俱乐部这个最核心的玩法上，优酷提升空间巨大。

### 第四步：结论与落地

到这里，基础数据对比、产品对比、运营对比都已完成，并且找到了切入点，接下来就是推动产品和运营落地。分析结论应给出具体的落地方案、跟进人、优先级、预期上线时间及预期效果。

::: tip 落地建议汇总

| 类别 | 落地项 | 说明 |
|---|---|---|
| 产品 | 新用户会员价格调整 | 参考爱奇艺的新用户首 3 个月优惠，进一步给出合理的价格曲线，需要考虑收入成本，分析师可以参与 |
| 产品 | 会员模块增加客服功能 | 用户付费时会有疑问，不能把每个用户都当成老司机，至少要有常见问题回答 |
| 产品 | 退货功能尝鲜 | 爱奇艺也未涉及，可进一步分析后做尝试，优先级可以低些 |
| 运营 | 签到功能位置调整 | 当前优酷的签到功能藏得很深，应暴露在会员首页当中，并可对签到渗透率、会员增长人数做估值 |
| 运营 | 完善活动丰富度 | 当前活动玩法过于通俗化（双 12 加会员人人都会玩），优酷需要建立自己的核心竞争力 |

:::

对于表格中的前四项需求，产品和运营可以拉资源落地，因为大家的主要目的就是提升会员数。在落地这件事上，分析师要充当先锋角色，尽最大努力推动：如果产品或运营不太上心，可以去找他们的 Leader 或者自己的 Leader 说明情况，由双方 Leader 做决策，推动会更容易。

## 方法小结

::: tip 竞品分析三步法
1. **确定分析的目的**。
2. **进行对比分析**：宏观基础数据、竞品功能、竞品的运营手段。
3. **给初步分析结论**。
:::

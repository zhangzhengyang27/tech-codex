# 用户增长：用户增长的本质是什么？

> 本篇讨论用户增长的本质：AARRR 模型的三种排列及各自侧重点、国内用户增长的现状与常见误区，以及《增长黑客》中摩拜的增长案例。适合被各种增长概念和模型困扰、需要建立独立增长思维的分析师阅读。相关方法可参考[用户增长：找出快速提升用户数的关键行为](../01-万能的数据分析法则/19-用户增长：找出快速提升用户数的关键行为.md)。

## 用户增长模型

用户增长的基本模型就是业界熟知的 AARRR。这套模型看似很完美，然而很有问题：它从拉新的角度出发，而对一款 App 来说拉新要花很多钱。从这个角度出发就是在不断烧钱，随着资本越来越理性，野蛮增长已经是过去式。

如果从留存这个角度出发，就会好很多：先把产品打磨好、运营服务好，然后在留存的基础上进行变现，挣钱后再投入到渠道去拉新。这样更靠谱——如果一款产品在中期还要靠不断注水才能保持规模，那这样的产品肯定有极大问题，这样的团队也非常不靠谱，只有早点转型做好留存才有希望。

现阶段大部分产品是"先做留存，再做变现，然后做推荐、拉新、激活"这样一套玩法，而不是从拉新开始，因为拉新对渠道的要求太高。渠道思维和产品思维是两种思维，产品思维、用户思维更加靠谱。

未来也可能是"先变现，然后到推荐，再到拉新、激活、留存"的顺序：第一考虑因素是变现——先说清楚产品能带来多少收入、净利润是多少，先做变现和推荐，然后再拿这些钱去拉新、激活、留存。随着资本越来越理性，普遍会从流量思维切换到 ROI 思维，活下去才是最重要的指标。

::: tip 三种模型的启示
三种不同模型的侧重点都不同，企业的打法也完全不一样。与其纠结模型，不如研究自己的产品与用户。
:::

很多人做产品或数据分析时，会往网上看到的某一套模型上硬套，最后效果并不好。因此不必纠结于什么模型，也不要指望通过数据分析突然找到一个很厉害的增长点、带来大量用户增长。平时要学会研究自己的产品、用户，找到当前产品真正存在的问题，慢慢去解决它，建立自己的产品壁垒。也可以学习优秀产品的玩法，思考它们能成功的本质，找到真正的用户痛点——比如 QQ 浏览器和腾讯视频为何能后来居上。

分析师的任务就是做规模和带收入，一直都没变，所以一定要独立思考，不要被各种风口带偏。

从数据分析师的招聘 JD 中也可以印证这一点，职责描述的关键点就是指标体系、数据监控、数据分析和建模、A/B 测试，与日常工作方法一致。

## 国内的用户增长现状

先看关于用户增长的书和资料。国内主要有三本书：《增长黑客》《增长黑客实战》《引爆用户增长》。关于用户增长的大会有 GrowingIO，每年一次，在会上可以推广自己的 GrowingIO 大数据平台。现阶段也有些公司专门成立了用户增长小组。

对这些信息的实际评价：书确实很火、内容很有料，唯一的瑕疵是可落地的干货不多；大会上的干货也不多，更多以品牌宣传为主，不要指望参加一次大会就能学到很多黑科技。如果一个公司没有好好思考就单独成立了用户增长小组，这完全没必要——无论职责还是 KPI 都会与其他组产生很大重合，成立用户增长小组要谨慎。

::: warning 看似管用、落地很难的三种增长方法
- **魔法数字**：假设发现一个用户阅读篇数超过 3 篇，留存将大大提升。基于这个数据，产品想让所有用户阅读篇数超过 3 篇。结论本身没有问题，但落地非常困难——阅读本身就是用户的一种很主动的行为，单独让阅读篇数小于 3 篇的人多阅读本身就非常难。如果做一些活动让他们多去做其他行为，到后来会发现这些用户会流失。
- **优化渠道结构来提升新增用户留存**：用户量大、质量高的渠道总是有限，渠道人员在开始的时候就一直在想这件事。渠道链路非常长，很多因素控制不了，反馈周期也很久；渠道涉及与外部公司合作，很多抉择不是自己能直接控制的。如果真的想通过渠道提升新用户留存，最直接的方法就是把低质渠道砍掉。
- **流失用户召回**：召回的手段很有限，除了 Push 也没有其他手段，Push 还经常被用户吐槽。与其把精力放在召回上，不如放在分析用户流失原因上。
:::

有两个很好的增长思维：

- **北极星指标**：一定要找到最核心的指标。找到后需对北极星指标进行拆解，拆解后的指标需与每个团队的 KPI 挂钩。如果每个人都能知道自己做的每件事是正向还是负向，KPI 完成程度就会很直观。
- **A/B 测试**：目的是公正性和快速反馈性。有两个原则：第一要基于数据分析来做 A/B 测试；第二 A/B 测试不只是看结果数据，还要看过程数据，排坑是第一步。

## 增长案例：摩拜

《增长黑客》里有两篇很有干货的文章，第一篇是"结合 Uber 和摩拜的实战经验，总结用户增长怎么做？"，第二篇是"滴滴用户增长的逻辑"，都值得一读。

这里单独解读摩拜的案例。书里介绍的做法是：

- 在新用户注册流程里砍掉引导页；
- 调整四步验证的顺序，把押金放在身份证之前；
- 对于 App 户外的下载安装，漏斗发现有很多用户直接流失，于是做了一款微信小程序，新用户留存率立即提升。

仅仅通过这些改变，摩拜就带来了很大的流量。结合方法论分析总结如下：

- 通过漏斗模型很容易发现引导页问题；
- 身份证和押金的前后顺序是产品设计层面，本质上就是 A/B 测试；
- 转化率漏斗实际上很长，同时还要做各种维度拆解。

接下来是留存和活跃。对摩拜来说功能本身很简单，用户扫码然后骑车就走。由于产品功能单一，运营就非常关键，摩拜与竞品拼的就是运营。他们做的所有事情就是活动，而活动运营分析的关键就是拉新、促活、传播这三件事。

文章还提到，对于研发人员，速度、执行力极为重要。对分析师也一样：结论产出速度、主动思考、执行力同样极为重要。

> 原文结语："所有的增长招式都越用越烂，效果越来越差，因此有效的方法每个人都藏私，凡是写到博客里的招式，都已经过时、不太好用了。那么整体来说，增长部门不能依靠一两个奇技淫巧，而必须有一套成体系成建制地发现、验证、推广新技巧的方法。"

总结：增长是透明的，也是保密的。对一款产品来说，找到自己产品的增长方法论才是内功，这就需要对产品非常了解，而不是靠奇技淫巧。

::: tip 用户增长的几条原则
- 不要玩概念，要独立思考和辩证性思维；
- 与其关注别人，不如多研究用户数据；
- 学习他人的优点，套用到自己身上；
- 分析师要多看产品、运营的书，所有的分析增长都要靠产品、运营闭环；
- 只有成体系才是可传播、可继承的。
:::

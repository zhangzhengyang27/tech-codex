# 报告撰写：专题报告的完美标准化格式

> 本篇给出专题报告的三个撰写原则（主题一脉相承分叉、通俗简单易懂、结论和闭环先行）与标准化报告的组成部分，并以一份彩妆行业分析报告为样例逐页点评常见问题。适合需要产出、评审专题分析报告的分析师。报告的组织方法也可参考[报告撰写：怎样高效地写一份数据分析报告？](../01-万能的数据分析法则/14-报告撰写：怎样高效地写一份数据分析报告？.md)。

## 报告撰写的三个原则

报告撰写的原则很多，但把握好以下三个原则，基本上没什么问题。

### 原则一：主题一脉相承分叉

只有一个主题，每页 PPT 都围绕这个主题分叉展开。常见两种问题：

- **专题报告没有主题**。报告里这里写点、那里写点，别人看了觉得有问题，但也说不上来。如果写的报告没有主题，那肯定是对专题报告的需求没理解到位。
- **专题报告有主题，但逻辑有点乱**。这是因为本身思维不够严谨，受到的指导太少。

解决办法：看别人的报告是怎么写的，一页一页去斟酌。把自己当作写报告的人——如果是自己会怎么写，别人又是怎么写。这个过程一定要去思考。

### 原则二：通俗简单易懂

数据分析师一定要让别人听明白报告。不管是业务数据分析师，还是偏研发、偏算法的数据分析师，最终都是服务于业务。即使不做口头阐述，也要保证业务方能看懂，否则就是给自己挖坑。一份数据分析专题报告，如果跟分析师最熟的业务方都理解不了，那对其他人来说绝对是天书。

解决办法：看产品经理日常怎么写报告——产品经理提出的建议要让研发明白、需要别人协助，所以他们的报告非常通俗易懂。

### 原则三：结论和闭环先行

PPT 一定要有数据结论，以及在这个结论的基础上业务方准备怎么做。注意是业务方**真的准备怎么做**，而不是分析师建议怎么做——数据分析用来决策而不是建议，很多专题报告还没有达到这个层面。

解决办法：跟业务方多沟通数据结论，让他们给出落地项，而不是分析师建议怎么做。分析师的建议往往推不动落地，所谓的闭环就是一定要落地。

## 报告的组成部分

标准化的专题报告按先后顺序包含以下部分：

- **背景**：为何要做这份专题报告，即问题的识别。
- **分析结论**：如果是面向管理层的汇报，结论可以先行。
- **分析框架**：即问题的拆解，往往这里不需要很细。
- **第一个关键点结论**。
- **第一个关键点的支撑数据**依次摆放。
- **第二个关键点结论**。
- **第二个关键点的支撑数据**依次摆放。
- **整体结论**：把结论再汇总一次。
- **落地项**：产品是怎么落地的，要非常具体（时间、人、预期效果）。

背景一定要有。虽然对非常熟悉的业务方，具体讲的时候可以不说背景，但报告上一定要把背景写上去，否则别人不知道这个报告到底是干什么的。

分析结论通常放在第二页：管理层很多时候后面没时间，让他先看到结论即可。当然结论也可以放在最后。

分析框架就是问题的拆解：把对报告的大致思路放出来，也就是一张思维导图，摆出大的框架就行，拆得很细的可以另存。

接下来是关键点与支撑数据的交替摆放：先把第一个关键点和结论摆出来，下一页依次摆放支撑结论的数据（可能好几页），作用是佐证结论；紧接着是第二个关键点结论及其支撑数据。

再往后是整体结论——在摆完细节之后把结论再强调一次，别人的感受会更深。最后给出落地项，具体到时间、人、预期效果。

::: tip 如何衡量专题报告的价值
在所有的数据结论和落地项中，只要最后有 1~2 个真的应用落地了，这份专题报告就非常有含金量。哪怕报告写得再好，最后没有结论可落地实施，那这个报告就是数据堆积，没有价值。
:::

## 报告点评示例

下面以一份彩妆行业的专题分析报告为样例，逐页点评常见问题。

### 目录页

报告目录分为五部分：行业整体环境、彩妆行业分析、彩妆重点品类分析、彩妆重点产品分析、结论。问题如下：

- 第一和第二部分是重复的——按 MECE 原则看，"行业整体环境"和"彩妆行业分析"很有可能就是一回事。
- 第三和第四部分实际上是一个子集关系——品类和产品。看完品类之后，很自然就去看产品，三和四的结构可以做一些调整。
- 第五部分按主题一脉相承分叉原则，在问题的拆解上还需要优化。

### 行业整体分析页

这一页主要讲长期趋势，有两个问题：

- **不直观**。波峰对应的年份和访问数以及其他详细数据的差距没有显示出来。既然是行业整体分析，首先要把大数告知听众，让页面整体更直观。
- **不够通俗易懂**。报告后面有一个预测，但这幅图不太能支撑预测，听众会疑问预测是怎么来的。虽然结论下面写到了预测方法，但偏专业术语，不通俗易懂。

### 增长倍数页

![增长倍数变化](/data-practice-images/i/image/M00/3B/72/CgqCHl8kAeOAKK8KAAJEfQs0jB4014.png)

问题还是出在通俗易懂上：图中既有 2017 年数据也有 2018 年数据，而且是每一周的数据——"增长倍数"是什么意思？标准线又是什么意思？从业务方的角度不太好理解。不要用"增长倍数"这种词语，可以描述得更详细一些。报告要图多字少，但一定要看面对的对象是谁；文字如果不够通俗易懂，讲 PPT 的时候很可能会把自己绕晕。

### 周期特性页

![周期特性](/data-practice-images/i/image/M00/3B/66/Ciqc1F8j_7iAGEtMAAFosg9-dvU613.png)

这一页存在逻辑性疑问：周期分析属不属于行业整体分析？比如 7 天一个小周期，它属不属于行业整体分析的范畴？这要根据具体业务范畴来定。

### 市场集中度页

两个问题：

- **通俗易懂**：交易指数是什么？公式是什么意思？听众其实特别讨厌公式。
- **思维的严谨性**："市场集中度低于 30%，彩妆市场处于竞争状态"——低于 30% 就是竞争，那多少是不竞争呢？另外听众对头部玩家肯定很感兴趣：有哪些头部玩家？头部玩家的市场集中度是怎样的？

### 客单价页

![客单价趋势](/data-practice-images/i/image/M00/3B/71/CgqCHl8j__aAITObAAGBeXcHYAs444.png)

- **可视化**：图中的趋势是上升、下降还是正常波动，不容易看出来，可视化可以优化。
- **思维的严谨性**：报告里有一段话——"考虑到通货膨胀因素，彩妆利润被进一步压缩"。通货膨胀就会使彩妆利润进一步压缩吗？这个结论不太合适，说这句话时要更严谨，至少要有数据支持。

### 彩妆人群分析页

![彩妆人群分析](/data-practice-images/i/image/M00/3B/67/Ciqc1F8kAfqAXLhrAAVYVLFMdDs550.png)

这几页的主要问题是维度太多、字太多、不容易抓重点。写每一页 PPT 时堆了很多维度，最后就会有一大堆数值罗列，实际上没有必要。如果觉得很难把一些东西丢掉，那就直接写结论。

下面两页是细分人群的购买力分析和属性偏好分析，主要问题是逻辑思维性：需要先说基础属性，再说行为属性，且文字大多是描述性统计，没有建议更没有结论。

![属性偏好分析](/data-practice-images/i/image/M00/3B/67/Ciqc1F8kAhyAT3H2AAenteoj1vs450.png)

### 结论页

报告的结论页读起来"有道理但又有问题"，应该遵循结论和闭环先行原则，至少做到前三项：

- 基于什么数据；
- 发现什么结论；
- 基于这个结论的建议是什么；
- 基于这个建议的产品落地项是什么。

这样业务方看完之后才知道原来是这么回事——有理有据，有落地项有闭环。

### 点评总结

具体到每页 PPT，大都是这里一个点、那里一个点，没有连贯性——这个现象很常见。主题的一脉相承分叉原则说起来容易，做起来难，需要在工作中多实践。

::: tip 写好专题报告的建议
- 平时多看优秀的专题报告，重点是把自己带入到场景中：读别人文章时，思考作者说的到底有没有道理、文章的架构是怎样的。
- 每写一次专题分析，一定要获得他人的反馈，只有这样才能进步。
:::

# 行业分析：行业分析及框架分析

> 本篇介绍行业分析的框架：目标界定与五大模块（界定范围、市场规模、社会热点事件、头部玩家、未来预测），并以"公司试水做电商业务"为例完整走一遍分析流程。行业分析往往从问题识别与拆解展开，方法可参考[问题定义和拆解：如何去定义问题、拆解问题？](./40-问题定义和拆解：如何去定义问题、拆解问题？.md)。

## 行业分析目标

行业分析有两种背景：

- 当前公司准备进入某行业，需要分析师或战略部门给出一份详细报告；
- 当公司业务发展遇到瓶颈，需要分析师去验证当前市场对产品的需求有无变化。

行业分析可以按照[问题定义和拆解：如何去定义问题、拆解问题？](./40-问题定义和拆解：如何去定义问题、拆解问题？.md)的逻辑展开，问题的识别与拆解对达成行业分析目标非常有帮助。

从背景来看，行业分析的目标基本分为两种：

- **转型**：希望通过行业分析看一下公司转型到某个行业有没有一些切入点；
- **用户需求验证**：做用户需求整体的行业分析，比如看用户的需求还在不在。

在这两种分析目标的基础之上，行业分析可以分为五大模块。

![行业分析五大模块](/data-practice-images/i/image/M00/3E/B2/Ciqc1F8tGhSALRyhAABdisCBeAQ347.png)

五个模块依次是：界定范围、市场规模、社会热点事件、头部玩家、未来预测。市面上非常多的行业分析报告，在介绍头部玩家时把头部的 App 整体描述了一遍，实际上没有必要，也没有价值。只要把范围、市场规模、社会热点事件、头部玩家、未来预测说出来即可。

::: tip 行业分析报告的核心标准
**行业分析报告不在于大而全和什么方法，而在于有所发现（切入点）。**
:::

## 电商行业分析举例

以电商行业为例做完整演示。

::: tip 案例背景
公司近期试水做电商业务，管理层知道很难做，但决策层想找一些切入点，于是找战略部，希望战略部给出一些建议。
:::

做这件事时，不能指望决策层或者管理层给出很多信息，需求通常都比较模糊——做行业分析时，想找到一个人很好地把需求描述清楚是很难的，因为大家都是在摸着石头过河。

行业分析的一般节奏是：

- 一周内快速出一些报告，拿着报告去和需求方沟通，这样可以避免一个月后做的专题分析不是对方想要的；
- 在与需求方对齐的基础上，把不确定的点剔除、把很明确的点确定，然后继续深挖。

### 1. 界定范围——在全局视野下找切入点

首先要在全局视野下找切入点：先总结出电商产业链的图谱。产业链图谱包含很多信息——老牌成熟的电商企业有哪些？新型的电商企业有哪些？其中微商、二手电商有哪些？围绕电商，上游供应商是什么？下游有哪些代理运营商？支付方式及物流如何？消费者情况如何（这一块又跟渠道挂钩）？

在产业链图谱的基础上看整个行业就比较清晰；否则直接上来就是淘宝、京东、唯品会，视野就已经被局限死了。

有了产业链图谱，给管理层看完后，比如他想做移动类的综合类电商（手淘、京东、拼多多），这就是界定范围。后面的报告内容就围绕这个点去切入——先把对象明确清楚，找到切入点。

### 2. 市场规模

市场规模分为交易额和用户两部分。

#### 交易额描述

大部分报告的市场规模只给交易额描述：网络零售市场的交易额曲线及其在移动端的占比。从曲线可以明显发现：网络零售市场的趋势是上升的，只不过增长率在下降，同时移动端的交易额也在上升。

但作为分析师一定要看得更细、要有独立思考。就"交易额逐年上升"这个结论来说，更重要的是找到谁在增长：是所有玩家都在增长，还是有些涨有些跌？在当前增长率持续下降的情况下，还有谁逆势上升？这就是拆解思想。

#### 交易额分析

基于"交易额逐年上升"，目标对象是阿里、京东、拼多多三家公司，可以查阅三家的财报看它们的趋势：

- 阿里 2017 年的 GMV 和 2018 年的 GMV 对比，涨了 27%；
- 京东第三季度的 GMV 同比增长 30.5%；
- 拼多多 Q3 过去 12 个月同比增长 386%。

统计时间段不一致是否会有影响？其实每家公司拥有数据的信息量不一样，只要对比本身的逻辑没问题就行。数据分析有直接数据和间接数据两种支持方式，只要能说明问题即可。所有资料都要注意口径和原始数据搜集，即使 Copy 也要找权威的数据源。

基于这个对比可以发现：拼多多才是颠覆者，增长了 386%，非常夸张；而阿里、京东已经比较成熟，涨幅差不多，不用刻意纠结。基于交易额的规模，得出了"拼多多是颠覆者"的结论，所以后面重点研究的对象是拼多多。

#### 用户数描述

大部分报告中的用户数描述是：预计 2018 年中国移动电商用户超 5 亿人。通过这个数据可以得出两个结论：

- 移动电商用户数一直在增长；
- 移动电商用户数增长率逐年下降。

结合中国的人口年龄分布还有一个疑问：移动电商用户数占比 36%，即使按照 16-59 周岁群体占比也只有 55%——从数据上看，这个行业还有很大缺口。

#### 用户数分析

进一步深挖。首先看目前国内的网民数情况（数据源：中国互联网信息中心）：

- 国家总人数约 14 亿，网民数只有 8 亿，移动互联网用户 7.9 亿，基本持平。网民数占人口数 57%（8/14），这个数字并没有想象的那么高，未来仍然有很多用户可以争夺。
- 移动互联网用户数占网民数的 98%（7.88/8.02）——移动互联网已经完全可替代 PC，瞄准的对象是手机终端。
- 中国互联网信息中心发布的网民报告中：71% 的网民会产生网络购物，而用短视频的网民占 74.1%——之前猜测剩下的潜在用户（100-71=29%）可能在短视频里面。

一般的分析报告，市场规模偏描述性统计；而分析师一定要在这个数据上深挖。深挖过程中要先知道目的是什么，然后自己去找数据，而不是别人给什么数就用什么数。

::: tip 市场规模阶段的发现
- 拼多多是颠覆者，它代表了一种增长趋势；
- 网民数占人口数 57%，并没有想象的那么高，未来仍然有很多用户可争夺（厂商）；
- 我国 71% 的网民网络购物，用短视频的网民占 74%，猜测剩下的潜在用户（29%）在短视频里。
:::

### 3. 社会热点事件

前面已经明确了拼多多，接下来针对拼多多看社会发生了什么。先看拼多多的发展历程：2015 年 9 月个人公众号上线，上线后发展极速；2016 年单日流水破 2 亿、用户数破 2 亿；2017 年用户破 3 亿——这是非常恐怖的。

重点看 2016 年和 2017 年的社会热点事件。

- **人均可支配收入**（数据源：国家统计局）：2017 年各省市人均可支配数据显示，除了上海、北京、浙江等经济发达省市，其他省市人均可支配收入也就 2 万块钱左右。用户是真的"没钱"，而市场上大家都在做比较高端的 App，离用户太远了。
- **微信的日活**：2016 到 2017 年，微信的日活涨得非常猛。微信以及微信支付重构了用户的社交方式。
- **物流**：对电商来说，物流是非常重要的一环。2016 年和 2017 年的物流总费用与 GDP 的比例低于 2015 年——这解释了商品为什么能这么便宜（9.9 块包邮）：整个社会的物流效率都有很明显的提升，随着人工智能的介入，这个数字应该还会更低。

![物流总费用与 GDP 比例](/data-practice-images/i/image/M00/62/C7/CgqCHl-ToiKAV780AABBrb1qsoc471.png)

::: warning 热点事件的筛选原则
社会热点事件这一部分，并不是什么热点事件都看，而是要看跟分析对象有关的热点事件，然后用这些数据结论来支撑分析。
:::

### 4. 头部玩家

头部玩家这部分，针对拼多多的产品和用户进行分析。

#### 产品分析

- **商品以日常生活用品为主（纸巾），价格很便宜**。
- **整个体验就是快**，用户基本上一直点"下一步"就行。点进来之后直接拼单，页面写着"还差一个人拼成"，并且每一次都是这样——还差一个人不就是你了吗？点拼单、下一步之后，购买界面特别简单：只有一个购买数量和一个支付方式，支付方式默认是微信支付。对比手淘和京东，拼多多非常简单粗暴。下面一大片空白区域，什么也不放，直接让用户点下一步。
- 点击立即支付时还有细节：姓名直接用微信昵称（淘宝首次购物的支付页面需要自己输入姓名），地域选择默认就是用户所在的地域。基本上用户不用干什么就下单了，整个过程可能不到一分钟。
- **搜索功能很轻，尽量让用户懒起来**。搜索在底层，目的是让用户不用逛——进来后平台说哪些东西好，直接买就行，买完下次再来。

通过体验可以发现，拼多多整个设计对用户的时间成本控制非常讲究。体验 App 时都可以从不同的角度去分析。

#### 用户分析

用户分析不要摆用户的地域、年龄等信息，要摆能说明分析目的的信息。调查发现，41% 的用户原来在淘宝或者超市购买，但在拼多多更便宜就选择了拼多多——这对直接竞品淘宝和京东来说，损失惨重。

同时拼多多的用户中，一线二线的占比已经超过 40%——这真的不只是便宜货这么简单，其中还有人性的因素。据此可以预判，未来会出现更多拼多多式的产品，这个市场需求非常大，现阶段还不成熟。

第二个观察是"老大老二打架，老三很有可能会挂"：拼多多与淘宝、京东、天猫的相似度远远没有与唯品会高——拼多多与唯品会的重合在地域和画像上。唯品会已经做了很多年，现在突然跟拼多多很像，而拼多多当前处于非常强势的时期，所以唯品会确实要思考自己的战略；而京东和天猫会形成很明显的正面竞争局面。

第三个观察是零售的本质还是多、快、好、省：

- 京东是物流快和好；
- 淘宝天猫是多和好；
- 拼多多是省和供应链快（类似于沃尔玛）。

### 5. 未来预测

最后整体复盘一次。行业分析一定要有分析目标：背景是公司准备试水做电商，目标是看当前还有没有切入点、有没有市场空间。通过界定范围、市场规模、热点事件以及头部玩家玩法，可以得出以下几点结论：

- 当前电商领域仍然有大量用户还没有进入，还有非常大的增量空间——注意这里不是存量空间，是增量空间；
- 当前国内的网民数不像想象中那么多，未来厂商的争夺会更加激烈；
- 短视频是非常好的一个渠道，或者说入口；
- 当前国内人均可支配收入不足，大部分都是 2 万元左右，未来的用户仍然会追求性价比；
- 拼多多用户的教育程度、认知以及所见所识，相对来说比手淘、京东的用户差一点。未来面向该类群体做产品时，要结合该类用户的特征——产品要尽量简单粗暴，让用户快速下单；
- 对唯品会来说，未来拼多多对它的威胁可能会大一点。

基于这几个观点就可以形成一些建议，把这些建议给管理者看，确认是否可行。因为有数据源支撑，并且在数据源的基础之上有自己的观点——这个最重要。做完行业分析后会发现非常有意思，因为发现了别人没有发现的点，这里面最重要的是沉下心。

推荐阅读梁宁的万字分析《除了假货，拼多多还有什么？》。阅读时不要单纯接受文中的观点，一定要有自己的思考。

# 用户研究：用户研究和数据分析的根本联系与区别

> 用户研究是分析师日常必须掌握的一项技能。本篇介绍用户研究的三个核心问题（功能满足什么需求、用户反馈最多的问题是什么、如何调研验证）、开展时机、三个步骤与注意事项，并说明用户研究和数据分析如何相辅相成。用户思维与精细化运营的关系可参考[懂用户：数据分析+用户思维=精细化运营](../01-万能的数据分析法则/08-懂用户：数据分析+用户思维=精细化运营.md)。

## 什么是用户研究

用户研究是一种职业意识，任何人都应该具备用户研究思维，包括以下方面。

1. **这个功能能满足用户什么需求？** 大部分 App 都是抄来抄去，这就是没想清楚这个功能能满足用户什么需求。比如爱奇艺、腾讯、优酷三家互为竞品，现在 App 上的功能大多一样；再比如信息流，头条之前有订阅、关注功能，现在其他竞品差不多也都有。
2. **用户当前反馈最多的问题是什么？哪些可以重点解决？** 用户肯定有各种各样的反馈：反馈最多的问题是什么？占比多少？比如反馈的 10 个问题里面占比最多的是 A 问题，A 问题到底能不能解决？不能彻底解决，能不能变相解决？用户抱怨最多的那个问题一定是你产品最大的问题。
3. **针对上面两个问题，需要进行线上或者线下调研，获得数据反馈。** 用户研究最后会落地到怎么去解决这些问题：只有去跟用户聊或者进行问卷投放获得数据反馈，才能够让产品拼到最后。头部玩家重大的 Bug 肯定是没有的，都是拼一些细节。

用户研究贯穿整个项目生命周期：

- **项目前期**：用户需求情况、用户基础画像情况、用户对于低价商品的迫切度。
- **项目中期**：用户行为习惯。
- **项目后期**：用户对产品的反馈点、竞品使用情况。

所有这一切都是为了更好地了解用户，然后与数据分析相辅相成——有时候数据角度并不能很好地反映用户的行为及原因。以拼多多为例，很多人手机里没有安装拼多多，但作为分析师，还是要去看每个爆款 App，了解它为什么成功、它的亮点在哪里。有时候真的离用户太远了，只从数据角度没办法解释，要做真实的用户调研。

::: warning 用户研究要趁早
用户研究在项目启动前就应该开展，并且要快于其他业务方。如果等项目都启动了再去启动，该做的也做了，一个月之后出报告价值不大——这非常考验用户研究人员的先见性和实操性。常见的误解是觉得用户研究没什么用、随便做报告，实际不是这么回事。
:::

## 用户研究的步骤和关键点

用户研究可以分为 3 个步骤：

- **制定研究目的**：有良好的背景和具体的问题；
- **选择研究方法**：定量和定性方法要对；
- **研究结论产出**：精而快。

::: tip 案例：今日头条 App 新用户留存专项
**项目背景**：2015 年今日头条 App 新用户次留、7 留与竞品相比，留存均低于 5% 绝对值，并且新用户流失速度要高于竞品，因此要在数据分析基础上进行产品运营优化，提升用户留存 5% 绝对值。
:::

在真实的项目过程中，除了数据分析师，肯定还要有用研人员的参与。数据分析师的工作分三个阶段：第一阶段整体分析；第二阶段寻找优化切入点，一般是 1~2 个；第三阶段不断重复前面两个阶段，进行一些其他的分析。用研人员同样有三个阶段。

### 第一阶段：制定研究目的

前期用研人员要快速了解当前的问题现状，制定思维脑图。所有人做的都是一件事，只不过落地方式不一样：更好地了解用户和产品，越能更好地解决问题。

### 第二阶段：确定研究方法

用研分为定量和定性两种。真实工作中没那么复杂，主要以用户访谈和调查问卷为主：

- **用户访谈**：定性，把用户约过来聊（单纯的聊天也有很多技巧）。
- **调查问卷**：定量，比如在信息流里投放一份问卷，并给用户一些奖励。忠实用户或追求利益的用户会填写问卷，样本量足够大之后，数据就可以拿来用。

研究方法里最重要的点：

- **定性**：约用户面聊，侧重于 Why 和 How，问得很细很深。
- **定量**：投放问卷，侧重于 What、When、Where。

对一款产品，如果产品经理、分析师离普通用户太远，就非常有必要做定性分析。定量分析非常注重样本量，同时要确保问卷设计的专业性。无论定性还是定量，都需要一定的物质激励，这样才能保证很快的产出。

用户研究的意义要远远大于一次营销活动：很多公司觉得没钱做用研（比如给用户的物质激励），其实小小的奖励很多用户也看不上；而一些营销活动做了就做了、没留下什么价值，大多是薅羊毛，对比而言没有用户研究价值大。

### 第三阶段：结论产出

当前很多用研报告追求大而全，从开始做到最后输出要一个月。大部分公司的节奏都很快，一个月期间项目可能都已经进行了调整。比较好的节奏是两周内输出结论，因为这样：

- 能够和分析师的数据分析报告一起输出，定量定性结合；
- 能够在最迫切需要的时候给出，价值最大化；
- 能够很好地融入整个项目团队，使做的事情更有意义。

## 用户研究的注意事项

用户研究实施时要注意以下事项：

- 用户说什么不重要，更加重要的是用户为何会这样说；
- 不要直接问用户喜欢什么——用户对他们的心理过程根本不了解，最好的工作法是田野工作法（现场调研）；
- 定性分析注重用户分类，定量分析注重样本量和样本代表性；
- 结束访谈后，尽快整理成文档，留住琐碎记忆；
- 用户报告追求精而快。

关于用户研究的未来：短期来看，用户研究这个职业是存在的，大公司一般都有用研团队，小公司基本没有，主要讲究用户研究+MVP 思想（围绕目标迅速搭建一个通用的简单模型给业务），不需要系统化，解决问题即可。长期来看，用户研究是一种职业意识——人人都是用户研究分析师，常常跟数据打交道的人一定要知道用户习惯。

::: tip 数据分析师的用研实践
数据分析师一定要有用户研究的意识，常见的做法是：

- 每天体验产品，看核心数据；
- 每周看客服数据；
- 对于费解的数据分析结论，推动用户研究人员去做用户访谈或者问卷；
- 新项目启动期，如果要线下了解用户，抓住这些机会。
:::

# 时间管理：优秀的数据分析师如何做时间管理？

> 时间管理是很多思维、产品最终落地时的关键。本篇给出数据分析师的时间管理方法论与五个关键点：早起、阶段性熬夜、上下班时间、会议时间、周六日。与提数阶段的集中时间管理实践可直接参考[数据获取与分析：常见的 SQL 技巧和分析方法](./41-数据获取与分析：常见的 SQL 技巧和分析方法.md)。

## 职场时间管理方法论

先看一个反面案例——一份从星期一排到星期天、从早上 6:00 排到晚上 11:00 的日程表。很多人觉得这样非常紧凑，效果也不会差。其实这样的效果真的很一般，因为它有点违背人性：

- 它首先要求一个人的自律性极强，而 90% 的人实际上做不到；
- 除了自律性之外，还需要保持专注性——比如早上 6:00-8:00 做 A 事情，还要把它做完不能拖；
- 同时这是一个非常持续的过程。

它没有考虑人性：人都有七情六欲，也有状态好和状态不好的时候。这种时间管理方法并不值得采用。

时间还是那些时间，但做事时可以遵循一些原则：

- **事情优先级排序**：二八原则；
- **状态好的时候做最重要的事，状态不好的时候做杂事**：以人为本；
- **对最重要的事情进行效果反馈并反思**：刻意练习；
- **有点可控的小压力**：有压力会更高效更聪明。

### 四条原则详解

- **事情一定有优先级排序**。把 20% 的高优事情做完之后，基本上就解决了 80% 的问题。工作中每一天可能真的有很多事，但一定要找到那个高优先级的事情。道理不难理解，关键是有没有真的这样去做。
- **以人为本，而不是以事为本**。状态好，甚至通宵达旦地干都没有问题；状态不好，最好一天都不要碰最重要的事情，等状态好了再去碰。同时也不能不做事——可以跟产品业务聊聊天。这个能力也非常重要：状态不好的时候，怎么样让自己兴奋起来。
- **对最重要的事情进行效果反馈并反思**，这是一个刻意练习的过程。做完重要的事情并不是做完就完了，一定要有反馈、还要反思。很多人是低质量的勤奋，就是在这个点上：始终在自己的思维圈里没有得到别人的反馈，或者得到反馈之后也不反思、不优化。
- **一定要有可控的小压力**，因为有压力才会更高效、更聪明。可以自我感受一下：到底是周一更聪明还是周五更聪明？

### 综合例子

比如某一天有开会、发邮件、提数、专题分析以及跟 Leader 汇报等工作。事情很多，到底哪个更重要？评判标准是：做完哪一件事对接下来一段时间的发展最有好处，那件事就是高优先级——当然除了那些必须要做的，比如管理层突然有临时事件。

以写专题分析为例：做完专题分析后，得到的效果是什么？影响力有没有增加？团队协作有没有变好？有没有一些落地点？如果发现没什么变化，那可能是选错了事，或者这件事压根就没做好。

## 职场时间管理的关键点

### 1. 早起

早起的好处有很多：

- **一天做的事情明显比往常更多**：早上 6:00 跟早上 7:00 起来，或者早上 7:00 跟早上 8:00 起来，绝对是两个概念。不要小看这一个小时或半个小时，非常关键。
- **心情更好，身体更好**：如果迟到或者晚起了半个小时，后面所有的事情都已经发生变化——所有的事情都会变得很紧凑，这对个人的神经不太友好。
- **运气更好**：大部分管理者都是很早到公司的。如果到公司也比较早，久而久之，管理者对员工的印象会相对深一点，通过私下或休闲时交流，印象会更明显地变好，运气也会更好。
- **周一早上不虚，周末两天充实**：很多人怕周一早上开会，因为要从周六日的娱乐状态切换到工作状态，有一个真空期。一旦周六日早起、周一也早起，就可以把很多杂事处理完毕、为工作做好准备，周末两天也会过得很充实。

每天 30 分钟的价值是巨大的。不同时间段的时间价值不一样：早上 6:30-7:00 这半个小时跟下午 5:30-6:00 下班前的半小时，在时间利用、时间效率方面肯定不一样。

### 2. 阶段性熬夜

熬夜一定要有价值。假设接下来的这段时间对发展很重要，就要投入大量时间去做这件事，所以一定会有阶段性熬夜。可以这样理解这件事：当一个产品在前期尝试（比如小流量）时发现效果很不错，接下来就应该投入大量的资源去推广。一个人每年不同时间段（3 月、5 月、6 月）的重要程度不一样，要评估哪一段时间要重点发力，所以肯定会有熬夜的过程。

熬夜也有一些好处：

- 熬夜可以证明比较年轻——因为还熬得动夜；
- 生活不能太常规化，偶尔熬下夜打破平静；
- 熬夜本身就代表了一种压力，压力会让人前进；
- 夜深人静的时候，内心会变得很平静，可能会冒出一些比较"亮"的想法，或者看待事物又有一个不一样的角度。

### 3. 上下班时间

一二线城市的上下班时间有很多，比如 90 分钟（上班 45 分钟，下班 45 分钟）。每个人应该给自己定一个最低目标。

一个可参考的最低目标：一周内要保证有 3 天学习。这段时间必须利用起来，否则就相当于没了。做什么呢？建议做跟自己职业规划相结合的事情，在其他方面多充充电，不要花过多时间做纯工作上的事情。如果确实不知道做啥，看书是最好的打发方式——前期可以看经济类、管理类、心理学类、文学类的书。

尽量不要开车上下班，能打车就打车，能坐公交坐地铁就坐公交坐地铁。开车上下班这段时间就干不了什么，而且一堵车就会很闹心，影响后续工作。

### 4. 会议时间

公司会议很多。会前一定要先了解这个会议有什么主题、想解决什么问题、有哪些人参与；如果跟自身没什么关系，就找个借口不要去。

会议时间有三个关键点：

- **个人汇报**——必须参加，因为需要本人做汇报，自己也会成长；
- **信息的同步和了解**——知道其他人是怎么想的，知道一些未来的业务方向；
- **管理层的思考方式**——学习他人的思维。

第三个价值最大。无论自己汇报还是别人汇报，管理层一定会进行点评、提意见。在这个过程中一定要看管理层的思考方式：能做到管理层，他们的思维一定在某一方面更厉害。特别是写专题分析时对方给的建议，一定要认真听——虽然其中可能有不合理的，但大部分时候是合理的。要知道为什么管理层能想到这个点而自己没有想到，知道哪一块不足，然后去弥补，这个时候提升是最快的。

### 5. 周六日

周六日要做到学习跟娱乐的平衡。很多人到周六日喜欢睡懒觉。其实每个周末少睡一个小时，稍微学习一下——一个小时或者半个小时也好，这证明是在独立思考的。

娱乐也一定要有，一定要放松。建议进行户外运动，尽量不要打游戏、在家躺着、看电视，因为越玩越累。去户外运动运动、打打球、去公园里走走，都非常好。在这个过程中，思维往往就能打开，想到很多亮点。

一旦在周六日进行了学习，下周的工作也会更加自信，状态会非常好。同时作为数据分析师，独自研究一些专题，也只有周末时间能满足。

## 职场时间管理感触

::: tip 两点感触
- **不是工作太辛苦，而是越来越懒**。早上 6:30 去坐公交，会发现车上全是学生——高中读书的时候也是那么早起来，不是做不到，而是真的变懒了。上述关键点也不是要逼自己全部做到：今天心情不好，周末或地铁上完全可以发呆；但保持学习的稳定性很重要。
- **兴趣是伪命题，工匠精神才是源动力**。比如坚持每周固定频率完成一件事，即使遇到难事也要保持节奏——这涉及责任及耐心。
:::

## 总结

时间管理的方法论包括：二八法则、以人为本、定期复盘反馈、给自己一些可控的压力；关键点包括：早起、阶段性熬夜、利用好上下班时间、会议时间和周末时间。

方法不必照搬，选择适合自己的方法合理安排时间即可。最重要的是去实施、去做——坚持一段时间就会有质的飞跃，道理与减肥成功一样：不难理解，难在坚持。

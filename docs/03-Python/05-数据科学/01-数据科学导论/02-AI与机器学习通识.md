# AI 与机器学习通识

> 本篇由原「机器学习」目录的 8 篇课程讲义精编合并而成，作为进入 [统计与建模](../04-统计与建模/01-回归分析) 与 [算法与数据挖掘](../06-算法与数据挖掘/00-数据挖掘导论与流程) 前的概念铺垫——那里有完整的 sklearn 实操，本篇只建立概念框架，不含代码。

## 一、什么是人工智能

**人工智能（AI）**：让机器像人一样去学习、思考与决策。它以机器学习为实现途径，机器学习之下又发展出深度学习方法：

![人工智能、机器学习与深度学习的关系](/python-ml-images/01-人工智能概述__202211291745305.png)

**发展三要素**：数据（原料）、算法（方法）、计算力（引擎，CPU 适合 IO 密集、GPU 适合计算密集的 SIMD 并行）。

**发展脉络**：1950 图灵测试 → 1956 达特茅斯会议（AI 学科诞生）→ 两次浪潮与寒冬 → 2012 AlexNet 引爆深度学习 → 大模型时代。判断机器是否智能的经典判据是图灵测试；1956 年的达特茅斯会议首次提出"人工智能"一词。

![人工智能发展历程](/python-ml-images/02-人工智能发展历程__202211291749980.png)

**主要分支**：计算机视觉（CV）、语音识别、文本挖掘/分类（NLP）、机器翻译、机器人等，各分支相互交叉、共同发展。

![人工智能主要分支](/python-ml-images/03-人工智能主要分支__202211291750109.jpg)

## 二、机器学习工作流程

**机器学习**是从**数据**中自动分析获得**模型（规律）**，并利用模型对未知数据进行预测的程序。完整工作流程五步：

![机器学习工作流程](/python-ml-images/04-机器学习工作流程__202211291801210.png)

1. **获取数据**：数据决定模型上限——样本要具有代表性，注意数据集的划分（训练集构建模型、测试集验证效果）
2. **数据基本处理**：缺失值/异常值清洗、格式统一，保证数据质量
3. **特征工程**：用领域知识把原始数据转换为更能表达问题本质的特征（提取、预处理、降维）——业界共识"数据和特征决定了模型的上限，算法只是逼近这个上限"
4. **训练模型**：选择算法，用训练数据拟合模型
5. **模型评估**：用测试数据检验效果，不达标则回到第 2-3 步迭代

## 三、算法分类

按**是否有监督信号**与**学习方式**划分：

![机器学习算法分类](/python-ml-images/05-机器学习算法分类__202211291806110.png)

| 类别 | 数据特征 | 典型任务 | 代表算法 |
|------|----------|----------|----------|
| **监督学习** | 有特征值 + 目标值 | 目标值连续 → **回归**（房价预测）；目标值离散 → **分类**（垃圾邮件识别） | 线性回归、逻辑回归、决策树、SVM |
| **无监督学习** | 只有特征值 | 聚类、降维 | K-Means、PCA |
| **半监督学习** | 少量标注 + 大量未标注 | 标注成本高的场景 | 自训练、协同训练 |
| **强化学习** | 环境反馈奖励 | 序贯决策（游戏、机器人控制） | Q-Learning、DQN |

## 四、模型评估

**分类模型**核心指标：

- **混淆矩阵**基础上的精确率（precision）、召回率（recall）、F1 值
- **准确率（accuracy）** 在类别不平衡时会失真——诈骗检测类场景要看召回率而非准确率

**回归模型**：均方误差（MSE）、均方根误差（RMSE）、平均绝对误差（MAE）、R²。

**拟合状态**：

![欠拟合与过拟合](/python-ml-images/06-模型评估__202211291810792.png)

- **欠拟合**：训练/测试误差都高——模型太简单，需增加特征或换更复杂模型
- **过拟合**：训练误差低、测试误差高——模型把噪声也学了，需更多数据、正则化或简化模型

## 五、深度学习与延伸

**深度学习** = 多层神经网络：输入层接收原始数据，隐藏层逐层抽象（低层特征→中层语义→高层概念），输出层给出预测。相比传统机器学习免去了人工特征工程，代价是需要更大数据量与算力。神经网络与反向传播的直觉理解可配合 [3Blue1Brown 神经网络系列](https://www.3blue1brown.com/topics/neural-networks) 食用。

# 案例：用户流失预测

除了获取新用户之外，另一方向就是识别出潜在的流失用户，发放一定的权益或者红包让他们留下来。目前，潜在流失用户预测逐渐成为互联网公司数据分析的工作热点，本节就做一个这方面的实战。

#### 衡量分类模型的结果

之前在回归模型的评估上，往往使用预测结果和真实结果的均方误差来衡量，但对于分类问题并不合适。对于分类问题，最常用来衡量模型效果的指标有三个：准确率、召回率和查准率。

对于分类问题，针对某条数据的预测的结果会有以下四种情况：

- True Positive（TP）：本来是真，预测结果也为真；
- True Negative（TN）：本来是假，预测结果也是假；
- False Positive（FP）：本来是假，预测的结果为真；
- False Negative（FN）：本来是真，预测的结果为假。
不难看出，如果结果是 TP 和 TN 都代表是对的，FP 和 FN 都代表是错的。但是不同的场景关注的重点也不同。

（1）准确率

准确率衡量的就是预测结果总的正确个数占总预测的数量，公式为：

准确率 = (TP + TN) / (TP + TN + FP + FN)

（2）召回率

召回率衡量的是找到了多少正样本。对于本来是真的样本，找到了多少个。比如本来有 100 个用户会流失，而预测为真的结果中有 40 个人在这 100 个人里面，那召回率就是 40%。公式为：

召回率 = TP / (TP + FN)

（3）查准率

查准率衡量的是预测为真的所有样本中，真的为真的比例是多少。比如预测有 100 个用户会流失，然后有 80 个用户真的流失了，那说明查准率为 80%。公式为：

查准率 = TP / (TP + FP)

在不同的业务场景，会使用不同的指标来衡量分类模型的好坏。sklearn 提供了现成的函数可以直接计算这三个数值，代码如下：

```
accuracy = accuracy_score(df_train_validator.Churn.values, prediction)
recall = recall_score(df_train_validator.Churn.values, prediction)
precision = precision_score(df_train_validator.Churn.values, prediction)
print("准确率：", accuracy)
print("召回率：", recall)
print("查准率：", precision)

```


可以看到，准确率和查准率还是相当不错的。但召回率不算高，但这也算一个不错的平衡。一般来说召回率都是比较难提升的，毕竟如果盲目提升召回率，则可能会导致查准率下降，这样可能也会导致一个不太置信的预测结果。

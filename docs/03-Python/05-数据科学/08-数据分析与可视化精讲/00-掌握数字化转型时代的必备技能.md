# 掌握数字化转型时代的必备技能

> 本篇是数据可视化分析系列的开篇，回答两个问题：数据可视化分析解决什么问题，整个系列如何组织。阅读后可以对数据可视化分析的定位、应用场景和系列篇章结构建立全局认知，无需前置知识，可直接开始。

## 数据可视化分析的定位

伴随大数据的发展，企业的**业务运营、主营业务增长和商业模式创新**都依赖数字化转型，而**数据分析**是企业实现数字化转型中最重要的一环。历经数十年的信息化建设，各企业已经积累了大量数据，建立起了数据平台和数据体系，数据基础设施日益完善。如何发现、挖掘和利用好这些数据，从而呈现业务、发现异常、分析问题、定位原因，并进一步赋能业务，成为各项工作的关键。

数据可视化分析作为数据分析的新型实现手段和方法，应用随处可见：

- 指挥中心：交通部门通过数据可视化，监测并预测拥堵情况，为交通优化提供合理策略。
- 个人账单：支付宝年度账单，让用户更直观地了解自己的购物、饮食等消费习惯。
- 疫情地图：让疫情传播链条和地区分布情况一目了然。
- 报表平台：企业通过数据可视化发现企业盈亏，从而调整自己的运营策略和发展方向。

相较于生涩的统计数字，**数据可视化报告和报表因其直观、可视化的呈现特点，成为连接数据分析师和企业管理者、业务运营人员、商业分析师、市场营销人员的纽带**。

那么什么是数据可视化分析？它是通过构建数据可视化图表，展示数据特征，从中发现数据信息的过程，包括两个步骤：**数据可视化呈现**和**数据分析洞察**。

数据可视化分析是数据分析师必须掌握的一项**核心技能**。在不同企业中，执行这一动作的角色或岗位有所不同：有的企业设立数据可视化分析师并配备相应技术人员，有的设立数据可视化开发工程师岗位；同时，数据可视化分析能力也是业务运营人员（包括流量运营、内容运营、交易运营等）、商业分析师和企业管理人员的必备能力。从岗位要求看，相关职位普遍要求计算机、统计学、数学、经济学等专业背景和一定的数学、统计学基础，更关键的是系统化的知识结构和基于数据解决业务问题的完整思路，这也是本系列内容着力构建的部分。

## 系列内容结构

本系列共 4 个部分，由浅入深覆盖数据可视化分析的完整流程：

- **基础理论篇**：体系化地梳理数据可视化的概念、建设目标、工作方法、操作流程和关键技术，建立完整的数据分析思维，掌握整体的数据可视化分析方法论。
- **环境部署篇**：通过数据可视化框架 PyEcharts 的安装部署和快速入门，掌握数据可视化开发环境的安装、部署方法，快速看到可视化效果，获得即时反馈。
- **典型案例篇**：基于一个简化的影片租赁数据可视化业务场景，通过 6 个实战案例、7 个操作步骤，从不同维度剖析整个数据分析工作过程，并详述 6 类常用图表的呈现设计和分析方法，具备举一反三的能力。
- **数据发布篇**：整合主流前端框架 Bootstrap + Flask + Python + MySQL，融合 6 个数据可视化图表案例，发布为一个完整的网站，实现从知识单点到系统建设的进阶。

数据能力可以从战略、战术和业务上为不同角色的从业者赋能。掌握数据可视化分析的思维、方法、流程和关键技术，对各数据相关岗位都具有直接价值。

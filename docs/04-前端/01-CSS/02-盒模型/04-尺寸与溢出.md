# 尺寸与溢出属性详解

## 概述

本文档系统讲解 width/height 及 min-*/max-* 尺寸属性与 overflow-x/overflow-y、box-decoration-break 溢出装饰属性。每个属性都配有来自 MDN 的可交互演示，可以直接点击运行查看效果。

## 尺寸属性

### width

设置元素的宽度（内容盒宽度）。

#### width 交互演示（MDN）

```html
<!DOCTYPE html>
<html lang="zh-CN">
  <head>

      * {
        margin: 0;
        padding: 0;
        box-sizing: border-box;

        font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif;
        min-height: 100vh;
        padding: 0;

      .demo-layout {
        display: flex;
        height: 100vh;
        gap: 0;
      }
      .snippet-panel {
        width: 320px;
        flex-shrink: 0;

        btn.addEventListener("click", () => applySnippet(parseInt(btn.dataset.index)));

  </body>
</html>
```

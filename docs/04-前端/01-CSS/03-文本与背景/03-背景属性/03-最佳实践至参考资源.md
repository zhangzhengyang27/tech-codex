# CSS 背景属性完全指南（03）：最佳实践、参考资源

## 最佳实践

### 1. 性能优化

```css
/* ✅ 使用现代图片格式 */
.element {
  background-image: url('image.webp'); /* WebP 比 JPEG 小 30% */
}

/* ✅ 设置后备颜色 */
.element {
  background: #fff url('bg.jpg') center/cover;
}

/* ✅ 响应式背景图 */
.hero {
  background-image: url('hero-mobile.jpg');
}

@media (min-width: 768px) {
  .hero {
    background-image: url('hero-tablet.jpg');
  }
}

@media (min-width: 1200px) {
  .hero {
    background-image: url('hero-desktop.jpg');
  }
}

/* ✅ 懒加载非首屏背景 */
.lazy-bg {
  background-image: none;
}

.lazy-bg.loaded {
  background-image: url('lazy.jpg');
}

/* ✅ 避免大面积 backdrop-filter */
.specific {
  backdrop-filter: blur(10px);
}

/* ❌ 避免 */
.full-page {
  backdrop-filter: blur(10px); /* 性能开销大 */
}
```

### 2. 可访问性

```css
/* ✅ 确保文字与背景对比度足够 */
.text-on-bg {
  background: url('bg.jpg');
  color: #fff;
  /* 添加遮罩确保对比度 */
}

/* ✅ 使用伪元素遮罩 */
.readable-text {
  position: relative;
}

.readable-text::before {
  content: '';
  position: absolute;
  inset: 0;
  background: rgba(0,0,0,0.5);
  z-index: 0;
}

.readable-text > * {
  position: relative;
  z-index: 1;
}

/* ✅ 提供降级方案 */
@supports (background: linear-gradient(45deg, red, blue)) {
  .gradient {
    background: linear-gradient(45deg, #667eea, #764ba2);
  }
}

@supports not (background: linear-gradient(45deg, red, blue)) {
  .gradient {
    background-color: #667eea; /* 降级 */
  }
}
```

### 3. 响应式设计

```css
/* ✅ 响应式背景图 */
.hero {
  background: url('hero-mobile.jpg') center/cover;
}

@media (min-width: 768px) {
  .hero {
    background-image: url('hero.jpg');
  }
}

/* ✅ 使用 aspect-ratio */
.card {
  aspect-ratio: 16/9;
  background: url('card.jpg') center/cover;
}

/* ✅ 使用 CSS 变量 */
:root {
  --bg-primary: #fff;
  --bg-secondary: #f5f5f5;
}

.section {
  background: var(--bg-primary);
}

/* ✅ 移动端禁用视差 */
@media (max-width: 767px) {
  .parallax {
    background-attachment: scroll; /* 移动端禁用 fixed */
  }
}
```

### 4. 代码组织

```css
/* ✅ 使用简写 */
.good {
  background: url('bg.jpg') center/cover no-repeat;
}

/* ❌ 避免冗长 */
.bad {
  background-image: url('bg.jpg');
  background-position: center;
  background-size: cover;
  background-repeat: no-repeat;
}

/* ✅ 需要单独覆盖时 */
.override {
  background: url('bg.jpg') center/cover no-repeat;
}

.override:hover {
  background-color: rgba(0,0,0,0.1);
}

/* ✅ 使用 CSS 变量管理背景 */
:root {
  --hero-bg: url('hero.jpg');
  --pattern-bg: url('pattern.png');
}

.hero {
  background-image: var(--hero-bg);
}
```

## 常见问题

### Q1: background-color 和 background 的区别？

**A:** `background-color` 只设置背景颜色，而 `background` 是简写属性，会重置所有未指定的背景属性。

```css
/* 只设置颜色 */
.element {
  background-color: red;
}

/* 简写会重置其他属性 */
.element {
  background: red; /* 会重置 background-image 等为默认值 */
}
```

### Q2: background-size: cover 和 contain 的区别？

**A:**
- `cover`：图片等比缩放，完全覆盖容器，可能裁剪图片
- `contain`：图片等比缩放，完全显示图片，可能留空

```css
/* cover: 适合全屏背景 */
.hero {
  background-size: cover;
}

/* contain: 适合 Logo 展示 */
.logo {
  background-size: contain;
}
```

### Q3: 如何实现背景图片固定效果？

**A:** 使用 `background-attachment: fixed`：

```css
.parallax {
  background-attachment: fixed;
  background-image: url('bg.jpg');
  background-size: cover;
  background-position: center;
}
```

**注意：** 移动端性能问题，建议媒体查询降级。

### Q4: 如何实现渐变文字？

**A:**

```css
.gradient-text {
  background: linear-gradient(45deg, #667eea, #764ba2);
  -webkit-background-clip: text;
  -webkit-text-fill-color: transparent;
  background-clip: text;
}
```

### Q5: 多重背景的层叠顺序是怎样的？

**A:** 先声明的背景在上层，最后声明的背景颜色在最底层。

```css
.multi {
  background: 
    url('top.png'),      /* 最上层 */
    url('middle.png'),   /* 中层 */
    #fff;                /* 最底层背景色 */
}
```

### Q6: 如何设置背景图片透明度？

**A:** 方法一：使用伪元素

```css
.element {
  position: relative;
}

.element::before {
  content: '';
  position: absolute;
  inset: 0;
  background: url('bg.jpg');
  opacity: 0.5;
  z-index: -1;
}
```

方法二：使用渐变遮罩

```css
.element {
  background: 
    linear-gradient(rgba(255,255,255,0.5), rgba(255,255,255,0.5)),
    url('bg.jpg');
}
```

### Q7: background-origin 和 background-clip 的区别？

**A:**
- `background-origin`：背景图片定位的原点
- `background-clip`：背景的裁剪区域

```css
.element {
  background-origin: content-box; /* 从内容区开始定位 */
  background-clip: content-box; /* 裁剪到内容区 */
}
```

### Q8: 移动端视差效果失效？

**A:** 在移动设备上，`background-attachment: fixed` 可能导致性能问题或失效。建议：

```css
@media (min-width: 768px) {
  .parallax {
    background-attachment: fixed;
  }
}

@media (max-width: 767px) {
  .parallax {
    background-attachment: scroll;
  }
}
```

### Q9: backdrop-filter 浏览器支持如何？

**A:** Chrome 76+、Firefox 103+、Safari 9+ 支持。建议提供降级方案：

```css
@supports (backdrop-filter: blur(10px)) {
  .glass {
    backdrop-filter: blur(10px);
  }
}

@supports not (backdrop-filter: blur(10px)) {
  .glass {
    background: rgba(255, 255, 255, 0.9); /* 降级 */
  }
}
```

### Q10: 如何优化渐变性能？

**A:**

```css
/* ✅ 简单渐变 */
.simple {
  background: linear-gradient(45deg, #667eea, #764ba2);
}

/* ✅ 使用 will-change 优化动画 */
.animated {
  background: linear-gradient(45deg, #667eea, #764ba2);
  background-size: 200% 200%;
  animation: gradient-shift 3s ease infinite;
  will-change: background-position;
}

@keyframes gradient-shift {
  0%, 100% { background-position: 0% 50%; }
  50% { background-position: 100% 50%; }
}

/* ✅ 考虑使用图片替代复杂重复渐变 */
```

# 逻辑边距与填充属性详解

## 概述

本文档系统讲解逻辑边距（margin-block/margin-inline 家族）与逻辑填充（padding-block/padding-inline 家族）共 12 个属性。每个属性都配有来自 MDN 的可交互演示，可以直接点击运行查看效果。

## Margin 逻辑属性

### margin-block

逻辑属性：设置块方向（上/下）的外边距。

#### margin-block 交互演示（MDN）

      <div class="snippet-panel">

  margin-block: 10px 20px;
writing-mode: horizontal-tb;

  margin-block: 20px 40px;
writing-mode: vertical-rl;
}`,
        `#example-element {
  margin-block: 5% 20%;
writing-mode: horizontal-tb;
}`,
        `#example-element {
  margin-block: 1rem auto;
writing-mode: vertical-lr;
}`,
      ];

      let styleEl = document.createElement("style");
      document.head.appendChild(styleEl);

      function applySnippet(index) {
        styleEl.textContent = snippets[index];
        document.querySelectorAll(".snippet-btn").forEach((btn, i) => {
          btn.classList.toggle("active", i === index);
        });
      }

      document.querySelectorAll(".snippet-btn").forEach((btn) => {
        btn.addEventListener("click", () => applySnippet(parseInt(btn.dataset.index)));
      });

      applySnippet(0);
    </script>
  </body>
</html>

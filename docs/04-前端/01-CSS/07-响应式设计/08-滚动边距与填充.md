# 滚动边距与填充属性详解

## 概述

本文档系统讲解滚动吸附与锚点定位场景下控制可视偏移的两大属性家族：scroll-margin（滚动外边距，作用于被滚动的目标元素）与 scroll-padding（滚动内边距，作用于滚动容器），共 22 个属性，覆盖物理方向与逻辑方向（block/inline）变体。每个属性都配有来自 MDN 的可交互演示，可以直接点击运行查看效果。

## scroll-margin 滚动外边距

# 滚动捕捉与平滑滚动

## 概述

本文档系统讲解滚动捕捉（scroll-snap-type/scroll-snap-align/scroll-snap-stop）与平滑滚动（scroll-behavior）共 4 个属性：前者用于实现轮播图、画廊、分页滚动等吸附式交互，后者控制滚动跳转的动画行为。每个属性都配有来自 MDN 的可交互演示，可以直接点击运行查看效果。

## 滚动捕捉

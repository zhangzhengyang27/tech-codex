# 表单控件样式属性

## 概述

表单控件的原生外观往往难以融入自定义设计体系。CSS 提供了三个专门面向表单控件的样式属性：`accent-color`（控件强调色）、`appearance`（外观重置）与 `caret-color`（输入光标颜色）。本文逐一讲解，每个属性都配有来自 MDN 的可交互演示，可以直接点击运行查看效果。

## 表单控件样式

### accent-color

设置表单控件（复选框、单选、进度条等）的强调颜色。

#### accent-color 交互演示（MDN）

```html
      }

      }
      .preview-panel {
        flex: 1;

        overflow: auto;
      }
      .preview-panel > section,
      .preview-panel > div:not(.snippet-panel):not(.demo-layout) {
        flex: 1;
        width: 100%;

        display: flex;
        align-items: center;

      }
      .container > div {
        display: flex;

      }

      #example-element {
        width: 40px;
        height: 40px;
      }

      #example-label {
        margin-left: 10px;
        font-size: x-large;
      }
    </style>
  </head>
  <body>
    <div class="demo-layout">
      <div class="snippet-panel">
        <button class="snippet-btn active" data-index="0">accent-color: red;</button>
        <button class="snippet-btn" data-index="1">accent-color: #74992e;</button>
        <button class="snippet-btn" data-index="2">accent-color: rgb(255 255 128);</button>
        <button class="snippet-btn" data-index="3">accent-color: hsl(250 100% 34%);</button>

    </div>
    <script>
      const snippets = [
        `#example-element {
  accent-color: red;
}`,
        `#example-element {
  accent-color: #74992e;
}`,
        `#example-element {
  accent-color: rgb(255 255 128);
}`,
        `#example-element {
  accent-color: hsl(250 100% 34%);
}`,
      ];

      let styleEl = document.createElement("style");
      document.head.appendChild(styleEl);

      function applySnippet(index) {
        styleEl.textContent = snippets[index];
        document.querySelectorAll(".snippet-btn").forEach((btn, i) => {
          btn.classList.toggle("active", i === index);
        });
      }

      document.querySelectorAll(".snippet-btn").forEach((btn) => {
        btn.addEventListener("click", () => applySnippet(parseInt(btn.dataset.index)));
      });

      applySnippet(0);
    </script>
  </body>
</html>

```

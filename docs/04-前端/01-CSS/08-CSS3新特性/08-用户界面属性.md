# 用户界面属性详解

## 概述

光标样式、尺寸调节手柄与键盘焦点轮廓是构成可用交互界面的基础。本文讲解 `cursor`、`resize`、`outline`（含 `outline-color` / `outline-width` / `outline-offset`）等用户界面属性，每个属性都配有来自 MDN 的可交互演示，可以直接点击运行查看效果。

## 交互属性

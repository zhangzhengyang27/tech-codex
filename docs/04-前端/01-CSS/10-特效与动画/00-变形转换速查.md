# 变形特效

## 概念说明

在 CSS 中执行变形转换的属性是 CSS3 属性中的 [transform](https://developer.mozilla.org/zh-CN/docs/Web/CSS/transform)，能够执行"**位移**"、"**旋转**"、"**缩放**"、"**倾斜**"、"**翻转**"和"**透视**"等变形转换的设置，可以让 Web 页面的表现更加"活跃"，增加页面的交互感。在生产环境中使用该属性时，需要控制一个"度"，避免"过度设计"，否则反而会损害页面体验。

## transform 的 2D 变形函数

### [translate](https://developer.mozilla.org/zh-CN/docs/Web/CSS/translate)

`translate` 让元素从当前位置根据"`left`（X 轴）"参数和"`top`（Y 轴）"参数的设置在水平和垂直方向进行移动。它与用于布局的 `position` 属性（特别是 `position: relative` 时）十分相似：移动后自身位置仍然保留，也不会影响其它元素的位置，但存在区别：

- `translate` 可以作用于已经设置为绝对定位（`position: absolute`）的元素；而绝对定位元素若想改用相对定位（`position: relative`）来移动，则需要对布局进行重新计算，或修改 DOM 的标签嵌套方式。
- 使用 `translate` 可以让 GPU 参与运算，动画的 FPS 更高。
- 使用 `translate` 执行的动画不触发布局重排，位移可精确到浮点数（亚像素）并由合成器直接呈现；而使用 `position` 属性执行动画时每一帧都要重新计算布局，开销更大。所谓"position 最小单位是 1 像素"是早期浏览器的旧说法，现代引擎（Blink/WebKit）的布局精度为 1/64 像素，该说法已不成立。

结论：**"position"属性是为布局而生，而"Transform.translate"是为动画而生**。

该属性值有以下几种类型：

- `translateX( x )`：设置元素在 X 轴方向的偏移
- `translateY( y )`：设置元素在 Y 轴方向的偏移
- `translateZ( z )`：设置元素在 Z 轴方向的偏移
- `translate( x, y )`：同时设置元素在 X 轴和 Y 轴方向的偏移

```html
<div class="wrap">
    <section class="box red-box">translateX</section>
    <section class="box green-box">translateY</section>
    <section class="box blue-box">translate</section>
</div>
```

### [rotate](https://developer.mozilla.org/zh-CN/docs/Web/CSS/rotate)

`rotate` 让元素以当前元素的中心（X=width/2，Y=height/2）进行旋转（若不对 `transform-origin` 进行设置），旋转的角度为参数所设定的值："正数"是顺时针，"负数"是逆时针，单位为 *deg*。

该属性有三种类型：

- `rotateX( angle )`：设置元素在 X 轴方向的旋转
- `rotateY( angle )`：设置元素在 Y 轴方向的旋转
- `rotateZ( angle )`：设置元素在 Z 轴方向的旋转

```html
<div class="wrap">
```

### [scale](https://developer.mozilla.org/zh-CN/docs/Web/CSS/scale)

`scale` 让元素以当前元素的中心进行缩放。参数的值为一个整数或浮点数："1"（默认）不进行缩放，"0.8" 缩小为原来的 80%，"1.5" 扩大到原来的 150%；参数不需要单位。

该属性值有三种类型：

- `scaleX( x )`：设置元素在 X 轴方向的缩放
- `scaleY( y )`：设置元素在 Y 轴方向的缩放
- `scale( x, y )`：设置元素在 X 轴及 Y 轴方向的缩放

```html
<div class="wrap">

  <section class="box green-box">scaleY</section>
```

### skew

`skew` 让元素根据水平（X 轴）和垂直（Y 轴）线参数设定倾斜角度。这里的**X 轴和 Y 轴**与通常理解的坐标系的 XY 轴正好**相反**：**X 轴正值是逆时针**变形，**Y 轴正值是顺时针变形**。基点默认为中心点。

该属性值有三种类型：

- `skewX( angle )`：设置元素在水平轴方向的倾斜
- `skewY( angle )`：设置元素在垂直轴方向的倾斜
- `skew( x-angle, y-angle )`：设置元素在水平轴及垂直轴方向的倾斜

### transform 组合值

和其它具有分支属性的 CSS 属性一样，`transform` 属性也能采用多值组合的方式实现复杂的 CSS 效果。需要注意：若该属性配合过渡特效 `transition` 属性使用，值的先后顺序不同，很多时候效果也不同，需要根据需要调整值设置的顺序。

```css
.wrap {
  transform: scale(1.5) translateX(500px);
}
```

### transform-origin

`transform-origin` 用于设置旋转元素的原点（基点）位置，默认为元素的中点。可接受三种类型的值："方位英文单词"、"Web 常用长度单位"和"百分数"。

- **方位英文单词**：有 "top"、"right"、"bottom"、"left" 和 "center" 五个值可用。如 "top left" 表示左上角，"right bottom" 表示右下角，"center center" 表示默认的中点。
- **Web 常用长度单位**：如像素 "px"、字符 "em"、点 "pt" 等。如 "16px 20px" 表示旋转的轴在 "X 轴" 的 16 像素、"Y 轴（向下为正，向上为负）" 的 20 像素的位置。
- **百分数**：第一个百分数表示相对于元素宽度的百分比位置，第二个百分数表示相对于元素高度的百分比位置。如 "0% 0%" 相当于左上角，"50% 50%" 相当于默认的中点，"100% 100%" 相当于元素的右下角。

```html
<div class="wrap">
  <section>1</section>
  <section>2</section>
  <section>3</section>
  <section>4</section>
  <section>5</section>
</div>
```

### transform-style

`transform-style` 规定如何在 3D 空间中呈现被嵌套的元素（作用于子元素，而不是元素本身），它主要有两个值：

- **flat**（默认）：表示所有子元素在 2D 平面呈现。
- **preserve-3d**：表示所有子元素在 3D 空间中呈现。

`preserve-3d` 更贴近现实世界的视觉习惯，因为人眼看到的东西都是"3D（立体）"的；当值为 "flat" 时，相当于在纸上画画——无论画功再好，画出的东西都是平面的，只是由于透视和明暗关系，有时看起来"很立体"。

```html
<div class="wrap">
  <section class="t1">
    <span>Flat</span>
  </section>
  <section class="t2">
    <span>Preserve-3d</span>
  </section>
</div>
```

```css
.wrap {
  text-align: center;
}
.wrap section {
  width:  160px;
  height: 160px;
  background-color: #000;
  margin: 30px;

  display: inline-block;
}

.wrap section > span {
  width:  inherit;
  height: inherit;

  cursor: pointer;

  background-color: orange;
  opacity: .75;

  color: #fff;
  font-size: 20px;
  letter-spacing: 2px;

  display: flex;
  justify-content: center;
  align-items: center;

  -webkit-transition: all .75s  linear;
  -moz-transition: all .75s linear;
  -ms-transition: all .75s linear;
  -o-transition: all .75s linear;
  transition: all .75s linear;

}

.wrap > section.t1 {
  /*2d场景*/
  transform-style: flat;
}

.wrap > section.t2 {
  /*3d场景*/

}
```

### perspective

"perspective" 意为透视、视角。该属性定义 3D 元素距视图的距离（可理解为景深），只对转换为了 3D 模式的元素生效，单位为像素。

透视是美术与建筑设计中的常见概念：

![](https://zhangzhengyang.oss-cn-beijing.aliyuncs.com/images/202310181522552.png)

![](https://zhangzhengyang.oss-cn-beijing.aliyuncs.com/images/202310181522595.png)

不过，CSS3 3D transform 中的透视点与上面两张示例图不同：CSS3 3D transform 的透视点在浏览器的前方。可以这样理解：显示器中 3D 效果元素的透视点在显示器的上方（不是后面），近似于人眼所在方位。

例如，一个 1680 像素宽的显示器中有一张应用了 3D transform 的图片，同时该元素或其父辈元素设置的 "perspective" 大小为 2000 像素，则该图片呈现的 3D 效果与在约 1.2 个显示器宽度处（1680×1.2≈2000）观察到的真实效果一致。

![](https://zhangzhengyang.oss-cn-beijing.aliyuncs.com/images/202310181522624.jpg)

"perspective" 属性有两种使用方式：一种是直接作为属性使用，即 "perspective: 400px" 的形式；另一种是作为 "Transform" 属性的值使用，同样需要加上单位，即 "transform: perspective(400px)"。早期浏览器需要加上前缀才能兼容，现代浏览器均已支持无前缀的标准写法。

```css
.stage {
  perspective: 600px;
}

.stage .box {
  transform: perspective(600px) rotateY(45deg);
}
```

可以通过 "translateZ" 寻找透视位置：如果说 `rotateX` / `rotateY` / `rotateZ` 可以帮助理解三维坐标，则 `translateZ` 可以帮助理解透视位置。

近大远小：对于没有 `rotateX` 以及 `rotateY` 的元素，`translateZ` 的功能就是让元素在眼前或近或远。例如设置元素 `perspective` 为 201 像素：

```css
perspective: 201px;
```

则其子元素设置的 `translateZ` 值越小，子元素越小（元素远去，看到的就会变小）；`translateZ` 值越大，元素也会越来越大。当 `translateZ` 值非常接近 201 像素但不超过时（如 200 像素），元素的大小会撑满整个屏幕（如果父辈元素没有类似 `overflow: hidden` 的限制）——此时子元素正好移到了观察者眼前，所谓"一叶蔽目，不见泰山"。当 `translateZ` 值再变大、超过 201 像素时，元素就看不见了——人眼无法看到位于眼睛背后的物体。

以下实例直观演示上述行为：

![](https://zhangzhengyang.oss-cn-beijing.aliyuncs.com/images/202310181522655.gif)

"perspective-origin" 属性指定观察视点的位置，默认是所看舞台或元素的中心。当不希望视线放在中心时，可以通过该属性调整。

### backface-visibility

`backface-visibility` 定义当 3D 元素不面向屏幕时是否可见，该属性有两个值：

- **visible**（默认）：表示当 3D 元素通过 "rotate" 属性旋转到元素"背部"时，元素仍然可见。
- **hidden**：表示当 3D 元素通过 "rotate" 属性旋转到元素"背部"时，元素不可见。

在现实世界中，观察者无法透过前方的物体看到其背后的物体；但在 CSS3 的 3D 世界中，默认情况下背后的元素是可见的。为切合实际，常按如下方式设置，使后面元素不可见：

```css
backface-visibility:hidden;
```

## 小结

- 2D 变形函数：`translate`（位移）、`rotate`（旋转）、`scale`（缩放）、`skew`（倾斜），可通过多值组合实现复杂效果，注意与 `transition` 配合时值的顺序会影响效果。
- `transform-origin` 控制变形基点，默认为元素中心，支持方位单词、长度单位和百分数三类值。
- 3D 变形核心：`transform-style: preserve-3d` 开启 3D 空间呈现；`perspective` 定义景深（透视点在浏览器前方）；`perspective-origin` 调整视点位置；`backface-visibility: hidden` 隐藏背面。
- 实践要点：位移动画优先使用 `translate` 而非 `position`（GPU 加速、不触发布局重排）；生产环境中控制变形特效的"度"，避免过度设计。

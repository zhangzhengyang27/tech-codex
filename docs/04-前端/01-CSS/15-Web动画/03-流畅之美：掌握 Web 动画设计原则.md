# 流畅之美：掌握 Web 动画设计原则

## 概念说明

Web 动画已成为 Web 设计的重要组成部分，但要创造出引人入胜的动画效果，需要遵循一些关键的原则。这些原则不仅使动画更吸引人，还确保它们与用户界面和内容完美融合。

确保有效使用动画的最佳参照之一是计算机动画的先驱迪士尼。[迪士尼的动画师奥利·约翰斯顿（Ollie Johnston）和弗兰克·托马斯（Frank Thomas）制定了 12 大动画原则](https://en.wikipedia.org/wiki/Twelve_basic_principles_of_animation)，并在 1981 年的著作《[生活的错觉](https://en.wikipedia.org/wiki/Disney_Animation:_The_Illusion_of_Life)》中引入了这些原则，该书被誉为动画中的"圣经"。

[沃尔特·迪士尼](https://en.wikipedia.org/wiki/Walt_Disney)曾说：

> 对于心灵而言，似乎真实的东西可以与任何物质事实一样重要。我们生活在精神和想象力中，也生活在感官中。卡通动画可以使幻想与我们能够触摸、看到和听到的东西一样真实。

这 12 大动画原则结合了物理学的基本法则——所有动画都需要遵循以确保真实性，以及认知心理学原则——旨在唤起情感。这些原则最初为传统动画（如角色动画）设计，但随着技术不断发展，计算机、手机和可穿戴界面能够实现更高程度的保真度和流动性，图形用户界面（GUI）中已能看到这 12 大基本动画原则的应用：其中一些可以直接用于呈现，另一些则体现在理念上。

## 应用传统动画原则

> Demo 地址：https://codepen.io/airen/full/wvRVMbV

迪士尼 12 大动画原则共同构成了动画制作的基础，不仅适用于传统手绘动画，也适用于 Web 动画，有助于创作出更具表现力、吸引力的动画。这些原则还适用于用户界面设计、游戏开发和影视制作等领域。

### 01：挤压和拉伸（Squash and Stretch）

> Demo 地址：https://codepen.io/airen/full/YzdbdLR

挤压和拉伸（Squash and Stretch）是传统动画中的基本技巧，用于增加动画物体的真实感和表现力。主要思想是：物体在移动或发生形变时应具有弹性，就像现实世界中的物体一样。

- **挤压（Squash）**：物体受到外力压缩时，在垂直方向上缩短、在水平方向上扩展，就像橡皮球被挤压。这种效果使用户感受到物体的质量和弹性
- **拉伸（Stretch）**：物体受到外力拉伸时，在垂直方向上延伸、在水平方向上收缩，就像橡皮球被拉伸。这种效果增加动画物体的拉伸感

挤压和拉伸原则对创建具有重力、重量、质量和灵活性错觉的动画至关重要，通常用于传达力量、速度和重量。经典示例是弹跳的球：球上下移动时被拉伸，触地时被压缩。拉伸和挤压的程度取决于球的材质——橡胶球效果非常明显，模拟保龄球时效果则非常微妙。

在数字界面中，挤压和拉伸使元素感觉触感丰富，并提供关于可操作性的视觉提示或反馈：按压按钮时发生挤压、双击窗口标题栏时发生拉伸、页面滚动到底部时发生挤压和拉伸以表示无法继续滚动。

在 Web 设计中，挤压和拉伸可以轻松地与按钮关联（按钮的按下状态即是挤压）；通过控制挤压和拉伸的程度，可以定义按钮的特性。该效果也适用于界面上的任何交互元素，例如侧边栏的收缩与展开。

这个效果事实上就是模拟一个橡皮球从上面掉落的动画效果。先用 `translate` 让物体沿 `y` 轴改变位置（掉落动画）：

```CSS
@keyframes up {
    0% {
        translate: 0 100px;
    }
    50% {
        translate: 0 0;
    }
    100% {
        translate: 0 0;
    }
}

@keyframes down {
    0% {
        translate: 0 0;
    }
    50% {
        translate: 0 0;
    }
    100% {
        translate: 0 100px;
    }
}
```

再用 `scale` 让物体沿 `Y` 轴产生挤压效果：

```CSS
@keyframes squash {
    0% {
        scale: 1 0.8;
    }
    6% {
        scale: 1 1;
    }
    93% {
        scale: 1 1;
    }
    100% {
        scale: 1 0.8;
    }
}
```

应用挤压和拉伸原则的关键要点：

- **重力和弹性**：传达重力、弹性和质量感——物体受重力作用时被挤压，弹起时被拉伸
- **材料属性**：挤压和拉伸的程度取决于物体的材料属性，橡胶球明显、保龄球微妙
- **意向和动作**：挤压和拉伸动作通常出现在动作的前后，为用户迎接即将发生的事情做准备，使动作更流畅自然
- **体积一致性**：保持物体的体积一致是有效传达挤压和拉伸的关键——拉伸时更薄、挤压时更宽
- **界面应用**：用于传达元素的可交互性和反馈，例如按钮悬停状态用挤压和拉伸提示可点击
- **适度使用**：过度的挤压和拉伸会让动画显得不自然或分散注意力

### 02：预备动作（Anticipation）

预备动作（Anticipation）原则强调为即将发生的动作或事件做准备：在进行某个动作之前，先做一些准备动作来暗示将要发生的事情，通常表现为主要动作之前的短暂停顿或相反方向的动作。预备动作有助于增加动画的可理解性、吸引力和自然感。经典案例是《狮子王》中辛巴扑击前的下蹲——下蹲为跃起提供了预备动作。大多数动作都会出现类似现象，大脑在潜意识层面处理了许多这样的预备动作。

> Demo 地址：https://codepen.io/airen/full/abPrrQx

在数字界面中，预备动作用于告知用户执行特定操作后会发生什么。典型应用是悬停动画：鼠标悬停在元素上时元素产生反应，表明它是可点击的、点击后将有事情发生。

> Demo 地址：[https://codepen.io/airen/full/yLGWWYo](https://codepen.io/airen/full/yLGWWYo) （来源于：[@Vineeth.TR](https://codepen.io/vineethtrv/full/GRYjGXb)）

预备动作的关键要点：

- **引导关注**：吸引用户注意，让其知道重要动作或事件即将发生，帮助预测接下来发生的事
- **增加真实感**：现实中的动作往往带有准备动作，在动画中复刻可增加真实感
- **突出重要性**：强调准备动作可以使用户更加关注即将发生的事情
- **平衡动画速度**：可以用于减缓节奏，使用户更容易跟随动画的发展
- **增加吸引力**：有吸引力的预备动作让动画更有趣，用户更容易与角色或情节产生共鸣
- **提高可理解性**：明确表示即将发生的动作，用户不会感到突然或困惑

预备动作可以是微小的细节（角色的眼神变化、身体的微小移动），也可以是更显著的动作（弯腰、深呼吸等），这些都有助于使动画更生动、更自然。

### 03：舞台布局（Staging）

> Demo 地址：https://codepen.io/airen/full/WNLBqwy

舞台布局（Staging）原则强调确保用户能够清晰地看到动画中的重要要点，以保持情节的清晰和角色的表现力。它是一种与视觉传达和故事叙述相关的技术，旨在引导用户注意力并增强动画效果。

舞台也是集中注意力的关键：就像剧院舞台上的灯光投射在最重要的区域上一样，舞台布局编排了场景——物体在场景中的摆放方式、每个动画的执行时间和方式等，将注意力引导到场景中最重要的物体上。

在界面方面，舞台布局决定了元素的放置位置以及互动发生时的编排方式，将用户注意力引导到预期的元素上。例如音乐应用播放页面中，"喜欢"操作（爱心图标）应与其他编排元素分开。下面这个示例中，"Like" 按钮背景带有微弱的呼吸灯动画，用户点击后还有 "+1" 的动画效果：

> Demo 地址：https://codepen.io/airen/full/rNoEWKZ

舞台布局的关键要点：

- **突出关键元素**：通过放大、高亮或突出重要角色、道具、动作或情节元素
- **清晰度和可理解性**：确保动画场景清晰，用户不感到困惑
- **情感表达**：巧妙的舞台布局增强角色的情感表达，让用户看到角色的情感状态
- **动态导向**：引导用户的目光到需要关注的地方
- **视觉平衡**：元素的排列和定位应在画面中创造平衡和和谐感
- **艺术指导**：布置画面需要从视觉和情感效果出发进行整体规划
- **凸显重要动作**：强调重要动作，使其更具戏剧性和吸引力

### 04：连续动作与关键动作（Straight Ahead Action and Pose to Pose）

> Demo 地址：https://codepen.io/airen/full/GRPbmYZ

连续动作与关键动作原则包含两种不同的动画制作方法：

- **连续动作（Straight Ahead Action）**：从动画序列的起始帧开始，按时间顺序逐帧制作，直到动画完成。更注重连贯性和流畅性，适合制作自然、连续的场景，如水流、火焰、奔跑等；但需要更多时间和精力
- **关键动作（Pose to Pose）**：先确定动画序列的关键帧（关键动作和姿势），再在关键帧之间填充中间帧以平滑过渡。适合强调特定的动作或情感，例如人物的表情、动作、对话等；有助于精确控制动画的关键要点和情感表达

例如角色的行走循环：关键动作用关键帧定义起点和终点的关键位置，连续动作则逐帧捕捉所有过渡时刻。

在 Web 动画中通常使用关键动作方法，尤其是 CSS 动画：定义关键帧后由浏览器自动"插值"中间帧。

> Demo 地址：https://codepen.io/airen/full/gOZNxWQ （来源于 [@David Khourshid](https://codepen.io/davidkpiano/full/Xempjq)）

连续动作的关键要点：

- **流畅性和自然性**：适用于火焰、烟雾等需要流畅自然动作的场景，注意保持动作的连贯性以模仿现实中的流动性
- **创意和灵感**：逐帧制作不受固定关键帧限制，可以更自由地发挥创意
- **时间管理**：每一帧都需要手动制作，良好的时间管理和计划对确保进度非常重要

关键动作的关键要点：

- **规划和结构**：先确定关键帧再填充中间帧，需要良好的动画结构意识
- **控制和调整**：可以准确控制关键帧，确保动画效果符合意图，适合制作角色表演等复杂动作
- **编辑和修正**：更容易编辑修改——在关键帧之间插入或删除帧即可修正，不会破坏整个动画
- **时间管理和规划**：虽然比连续动作更有效率，仍需合理规划以确保动画按计划进行

无论选择哪种方法，都需要具备良好的动画基础知识（时序、空间感和物理原理），以确保动画自然、吸引人且令人信服。方法的选择取决于项目需求、动画风格和技能；两者也可以结合使用以达到最佳效果。

### 05：跟随动作与重叠动作（Follow Through and Overlapping Action）

> Demo 地址：https://codepen.io/airen/full/Yzdorxm

跟随动作与重叠动作原则强调：物体停止运动时，其附着部分可能继续运动而不是立刻停下，使动画看起来更自然流畅。具体包括：

- **跟随动作（Follow Through）**：主要动作停止时，附着在物体上的次要部分（如绳子、头发、衣服）继续运动一段时间后逐渐停下，模拟现实中的动态效应
- **重叠动作（Overlapping Action）**：不同部分的运动不完全同步——一部分的运动可能领先于其他部分，然后逐渐趋于同步。不同部分的相对运动增加动画的生动性

这一原则反映了物体的各个部分并非同时移动。以摇晃头部为例：头发的运动稍微滞后于头部（重叠动作）；头部停止运动后，头发仍会稍微继续运动（跟随动作）。

> Demo 地址：https://codepen.io/airen/full/ZEVdabm  （来源于 [@Wikyware Net](https://codepen.io/wikyware-net/full/PoqEwvo)）

在 Web 动画设计中，可以让彼此相关的元素以不同速率移动。例如一个图像、一个标题和一个描述：运动的发起者是最关键的元素（图像），标题和描述跟随其后。这一原则有助于在界面中建立层次结构。

Web 中的视差效果就是类似的应用。例如卡片滑动时，卡片上的缩略图和 Logo 以不同的速度开始，呈现重叠动作：

> Demo 地址：[https://codepen.io/airen/full/JjwQOKj](https://codepen.io/airen/full/JjwQOKj) （来源于 [@Andy Merskin](https://codepen.io/andymerskin/full/XNMWvQ) ）

一些悬浮状态的动画效果也可以使用该原则制作。

需要注意的是，并非所有应用都需要跟随动作和重叠动作，且动画不能减慢用户完成任务的速度。

该原则的关键要点：

- **动作的延续性**：主要动作完成后某些部分仍继续移动，模仿现实中的动量和惯性
- **主要元素**：动作始于主要元素（如身体或头部），附属部分（头发、衣物等）随主要元素的运动产生延续性动作
- **不同速度的运动**：不同部分以不同速度运动，创建动作之间的层次感，使动画更具深度和维度
- **层次结构**：主要元素启动动作序列，其他部分以不同速度和方向运动，有助于建立界面或场景的层次结构
- **自然感与真实感**：跟随动作赋予动画自然感；重叠动作反映物体的复杂性和现实世界的物理原理

跟随动作和重叠动作的核心是模仿自然运动、增强动画的真实感和流畅性，在角色动画、界面设计和物体运动中应用广泛。

### 06：渐快与渐慢（Slow In and Slow Out）

> Demo 地址：https://codepen.io/airen/full/mdaZqpw

渐快与渐慢也被称为"缓动"，强调物体在动画开始和结束时逐渐加速和减速，模仿现实世界中物体启动和停止的方式。具体包括：

- **渐快（Slow In）**：物体从静止或低速状态开始运动时，初始帧较慢，然后逐渐加速，模拟现实中的惯性和逐渐加速过程。例如骑自行车时先用力踏脚踏板，然后慢慢加速到期望速度
- **渐慢（Slow Out）**：物体即将停止时，最后几帧较慢，逐渐减速至停止，模拟现实中的逐渐减速过程。例如汽车停下前司机慢慢松开油门、轻踩刹车

在 Web 动画中，动作结束时通常采用缓动，使其看起来更平滑愉悦。缓入缓出不仅是美学实现，越来越多地被用作认知支持，帮助用户理解已经发生的动画——没有缓入缓出的动画会显得呆板无生气。

渐快和渐慢原则在 Web 动画中的常见场景：

- **滚动动画**：网页滚动时内容速度逐渐增加，提供更自然的滚动体验
- **弹出菜单**：菜单以渐进的动画逐渐展开，减轻突然出现的感觉
- **轮播幻灯片**：当前幻灯片慢慢减速，下一张逐渐加速
- **过渡效果**：页面切换或元素显隐使用渐快渐慢，平滑过渡
- **加载动画**：渐快渐慢的加载动画让用户感到顺畅
- **按钮交互**：悬停或点击时颜色、大小以渐快渐慢方式变化，增加交互吸引力

渐快和渐慢是 12 原则中在 Web 动画里使用最频繁的一条，因为它能与 Web 动画的缓动函数直接匹配：`ease-in`、`ease-out`、`ease-in-out` 和 `cubic-bezier()` 等。

缓动函数用于控制动画的速度变化，以模拟现实世界中物体的渐快和渐慢运动：

- `ease-in`：动画开始速度较慢，然后逐渐加速——与渐快原则一致
- `ease-out`：动画结束时逐渐减速——与渐慢原则一致
- `ease-in-out`：结合渐快和渐慢，开始时较慢并逐渐加速，结束时逐渐减速

使用加速曲线（`ease-in`）实现渐快效果：元素位置变化缓慢、速度逐渐增加，以一定的加速度移动。当元素以全速飞出屏幕时应使用加速曲线，如系统通知或页面上的卡片。注意：**只有当对象永远离开屏幕、无法回忆或返回时，才应使用渐快原则**。

减速曲线（`ease-out`）与之相反：元素出现在屏幕上时以最大速度飞向屏幕，逐渐减速直到完全停止，适用于从屏幕外部出现的卡片或对象。

`ease-in-out` 是最匹配渐快与渐慢原则的缓动函数，它使元素在动画的开始和结束都表现出速度变化，创建更流畅、自然的动画，也是 Web 动画中最常见的。对使用哪种运动方式感到困惑时，选择渐快与渐慢即可，因为它最能模拟现实世界中物体的运动方式。

还可以使用 `cubic-bezier` 缓动函数控制渐快和渐慢效果：调整其参数可创建自定义的速度曲线。典型的匹配方式：

- **渐快（`ease-in`）**：初始速度较慢、逐渐加速，典型参数 `(0.42, 0.0, 1.0, 1.0)`
- **渐慢（`ease-out`）**：接近结束时逐渐减速，典型参数 `(0.0, 0.58, 0.58, 1.0)`
- **渐快渐慢结合（`ease-in-out`）**：开始和结束时较慢、中间加速，典型参数 `(0.42, 0.0, 0.58, 1.0)`

> Demo 地址：https://codepen.io/airen/full/ExGBqWN

缓动函数与二次贝塞尔曲线的更多应用细节参见《CSS 缓动函数基础：为 Web 动画注入灵魂》与《使用 cubic-bezier() 函数创建高级动画》。

渐快和渐慢原则的关键要点：

- **速度变化**：动画开始时较慢逐渐加速（渐快），或结束时逐渐减速（渐慢），模仿现实世界中物体启动和停止的方式
- **流畅性**：使动画不显得突兀生硬，用户更容易理解和接受运动
- **模仿真实**：与用户日常经验一致（车辆启动停止、物体抛物线运动等），更容易与动画互动
- **情感表达**：加速传达紧迫感，减速传达柔和或放缓的感觉
- **应用广泛**：适用于界面动画、角色动画、过渡效果等各类动画

### 07：弧线（Arc）

> Demo 地址：https://codepen.io/airen/full/WNLqVzV

现实世界中大多数物体沿轻微的弧线移动：扔出的石子或纸飞机沿弧线路径飞行，而不是直线。遵循平滑曲线的运动在审美上更令人愉悦，因为动作看起来更自然、流畅和真实。有时动作围绕一个点旋转（手臂绕肩膀旋转），有时受外部力量作用（重力、向心力和离心力）。弧线原则就是用弧线运动模仿这些现象。

在 Web 动画中，弧线路径常用于以下场景：

- **导航菜单**：弹出子菜单遵循弧线路径，悬停主菜单项时子菜单以自然方式滑出
- **UI 元素的弹出和消失**：点击按钮展开更多选项时，选项框以弧线路径从按钮位置出现
- **轮播幻灯片**：弧线路径用于切换幻灯片，使过渡更流畅吸引人
- **游戏界面**：模拟物体的移动，如飞行射击游戏中的子弹路径或角色的跳跃路径

这一原则的典型示例是 Mac 的 Dock 栏悬停动画，它使 Dock 栏中应用程序之间的导航变得直观而有趣：

> Demo 地址：https://codepen.io/airen/full/dywBxwK （来源于 [@Jhey](https://codepen.io/jh3y/full/GRwwWoV)）

从高处抛出的球沿抛物线路径运动——弧线使事物看起来更自然。界面中遵循对角线路径的元素可以通过弧线运动变得更自然；想突出元素路径时可以使用弧线。

使用弧线原则的关键要点：

- **运动的自然性**：现实中的运动大多沿曲线或弧线路径（绕中心点或轴心），使用弧线路径增加动画的自然感
- **流畅性**：物体沿弧线运动时速度在起始和结束点逐渐加速或减速，而不是突然改变方向，增加连续性和流畅性
- **动态效果**：弧线路径让运动轨迹更容易被感知，提高动画的吸引力和情感表达
- **角色动作**：表现手部、头部或身体运动时弧线路径尤为重要，可增加角色的表现力和情感表达
- **3D 动画**：弧线路径有助于模拟现实世界中的物体运动，使 3D 动画更真实

### 08：附属动作（Secondary Action）

> Demo 地址：https://codepen.io/airen/full/KKbjOjz

附属动作（Secondary Action）原则强调在动画中添加额外的次要动作，以增强动画的真实感和表现力。附属动作是主要动作的补充，为角色表现增添深度；它通常与主要动作相辅相成，但不应分散用户注意力。

附属动作还有助于传达主要动作已经发生或正在发生。在人机交互中，反馈的作用是让用户知道所期望的动作已经发生——反馈是数字界面可用性的关键组成部分；没有反馈本身也是"没有动作发生"的反馈。良好的反馈是信息丰富的、与动作相关、与动作的含义相关并产生闭合感的。

在 Web 中，附属动作用于引发用户情感。例如用户提交了一个非常长的表单后，可以为提交按钮添加辅助的庆祝动画（如纸屑），祝贺用户完成了耗时的任务，增强体验并营造愉快氛围：

> Demo 地址：https://codepen.io/airen/full/poqMzZW

Twitter 卡片上点赞的动画效果是附属动作原则在 Web 动画中应用的典型案例：

> Demo 地址：https://codepen.io/airen/full/eYbqOWe

附属动作原则的适用情境：

- **微交互**：鼠标悬停时按钮微微变色或产生微小的动画效果，强调可点击性
- **加载动画**：页面加载内容时显示加载动画或进度指示器，告知用户操作正在进行
- **提示框**：弹出的提示框附带淡入淡出动画，提供友好的反馈和指导

应用附属动作原则的要点：

- **增加真实感**：现实中的动作往往伴随其他次要动作（说话时的手部动作、表情、眨眼等）
- **情感表达**：用于表达角色或界面的情感和意图
- **补充主要动作**：与主要动作一致，补充并增强主要动作
- **不分散注意力**：附属动作不应分散注意力，要与主要动作协调一致，确保用户关注重点
- **动态平衡**：可以用于平衡动画中的运动和重点，使动画更和谐均衡

### 09：时间控制（Timing）

> Demo 地址：https://codepen.io/airen/full/ExGqaEW

时间控制是所有界面动画的基本要素，它与缓动一起在动画编排中发挥重要作用。时间控制强调动画中物体和角色的运动速度和节奏，可以增加动作的流畅性、引导用户注意力并传达可用性。时间控制不当的后果：过长的过渡让用户等待太久；过快的动画让用户错过重要信息。正确控制动画时间可以帮助用户感知反馈并顺利完成任务，甚至带来愉悦感。

在 Web 动画中，时间控制可以向用户提供信息。例如将文件上传动画的速度与文件大小关联——上传大文件时过程较慢、小文件时较快，让用户知道需要多长时间以及原因。

大多数 Web 动画的时长在 `200ms ~ 600ms` 之间。[Material Design](https://m2.material.io/design/motion/speed.html#duration) 对每种类型的动画时长有详细的解释。以下卡片轮播动画中，每张卡片延迟 `3s` 开始向上滚动：

> Demo 地址：https://codepen.io/airen/full/OJrKPKe

时间控制原则的关键要点：

- **节奏和速度**：不同速度和节奏传达不同情感——快速传达兴奋和紧张，慢速传达冷静和放松
- **情感表达**：通过控制动作的速度和持续时间表达情感状态
- **喜剧效果**：正确的定时和速度可以让笑点更加突出
- **运动的连贯性**：运动按一定的时间表进行，保持动画的真实感
- **动态感**：改变时间控制创造动态感，帮助用户理解动画中发生的事情

### 10：夸张（Exaggeration）

> Demo 地址：https://codepen.io/airen/full/KKbOpym

喜剧演员使用夸张的表情、动作和语言来引发笑声。借鉴到 Web 设计中，夸张用于强调屏幕上最重要的元素。这里引入人机交互（HCI）中的两个重要概念：**可见性**和**可查找性**——界面中的所有元素可能是可见的，但设计元素的方式决定了最重要的操作是否易于查找，例如主要按钮被设计得比次要按钮更突出。有选择地在某些 UI 元素上应用夸张，可以增强视觉效果、情感表达力和吸引力；夸张是一种强调性技巧，能引导用户注意力，传达兴奋、期待或被奖励的情感。

在 Web 动画设计中，可以夸张某些元素以清楚展示交互方式。例如用户提交表单后使用夸张的反馈动画（如成功提交时的火箭升空）传达成功和满足感：

> Demo 地址：https://codepen.io/airen/full/oNJKjXv

::: warning 夸张的度
好的动画对用户来说应该是无形的。夸张过度会让用户感到烦恼，出现这种情况时应使动画更加细微。
:::

应用夸张原则的关键要点：

- **强调特征**：强调物体或角色的特征，增加辨识度和记忆点
- **情感表达**：夸大表情、手势和动作，使用户更容易理解情感状态
- **视觉效果**：增加动画的视觉吸引力，吸引用户目光
- **动态感**：夸大物体的运动或物理特性，使动画更具生动性
- **喜剧效果**：夸大角色的行为和特征，增加娱乐价值

夸张应谨慎使用：程度适当，不分散注意力、不破坏动画的连贯性。

### 11：立体造型（Solid Drawing）

> Demo 地址：https://codepen.io/airen/full/WNLVrJV

在计算机生成图像（CGI）出现之前，经典动画师会为对象和角色绘制三维属性（形状、重量、高光和阴影），使其看起来自然逼真。在人机交互（HCI）中，对应的概念是拟物化（Skeuomorphism）——从现实物体中汲取灵感应用到界面设计中。从 GUI 的早期开始，界面一直使用高光、阴影和纹理模仿现实物体，如按钮的斜角和浮雕效果、便签应用的页面纹理。随着时间推移，界面设计从拟物转向极简主义设计（Flat Design），再回到现在被称为"[Neumorphism](https://en.wikipedia.org/wiki/Neumorphism)"的设计风格。

在未来的增强现实（AR）和虚拟现实（VR）应用中，将更需要密切模拟光线、阴影和环境的真实世界属性，以实现真实世界与增强现实元素之间的无缝过渡。无论流行趋势如何，利用光线、阴影和形状的真实世界属性可以使界面更具沉浸感，并具有物理可感性（提示用户应该做什么的感知特征）。

理解立体造型的基础原则有助于设计更成功的动画。通过添加阴影、高光和投影可以创建立体感，使元素看起来像是浮在页面上，帮助用户理解层次结构：

> Demo 地址：https://codepen.io/airen/full/wvRVEBX （来源于 [@Nick](https://codepen.io/OfigenusMaximus/full/MWzoaYm)）

虽然 Web 动画通常是 2D 的，但通过 3D 模拟技术，可以在 Web 中创建具有深度和透视感的场景：

> Demo 地址：https://codepen.io/airen/full/zYygJBv

立体造型原则的关键要点：

- **三维感**：考虑物体和角色的三维形状和结构（深度、体积、质地）
- **透视和比例**：正确表达物体远近、大小和相对位置
- **光影和阴影**：通过光影表现增强物体和角色的体积感
- **动态效果**：正确的立体造型使运动更具体、流畅和有力
- **背景和环境**：立体造型同样适用于背景和环境，使整个场景更具深度和现实感

### 12：吸引力（Appeal）

> Demo 地址：https://codepen.io/airen/full/abPeaVB

动画需要吸引用户。虽然没有确切的数学公式，但任何动画都应该引起用户注意并产生吸引力。吸引力（Appeal）原则强调创造出具有吸引力的角色和设计，使用户对动画产生兴趣，涵盖角色设计、动态效果和情感表达等多个方面。

UI 设计需要是功能性的，但功能与美学不应对立。在 UI 设计中吸引力至关重要——同类产品众多、竞争激烈，动画可以定义产品的个性，与用户建立情感联系。

吸引力原则的适用情境：

- **品牌建设和标志性动画**：增强品牌形象和标志，吸引用户对品牌产生兴趣
- **用户导引**：引导用户完成特定任务或浏览内容
- **用户互动**：创建有吸引力的按钮、图标等互动元素，鼓励互动
- **用户反馈**：在成功提交表单等场景添加愉悦的动画效果
- **用户引导和教育**：传达信息、教育用户如何使用产品或展示复杂概念
- **交互性游戏**：增加游戏性和用户参与度
- **用户情感连接**：建立情感连接，使用户更深刻地理解和体验产品或服务

> Demo 地址：https://codepen.io/airen/full/bGOXxmJ

应用吸引力原则的要点：

- **角色设计**：角色应具有独特性和魅力（外观、特征、服装、表情），使用户愿意产生情感共鸣
- **情感表达**：用户能够理解和共感角色的情感，建立联系
- **动态效果**：动作应流畅、有趣和引人注目
- **故事情节**：吸引人的故事情节使用户愿意关注和投入
- **符合受众**：考虑受众的需求和兴趣，使目标受众感到兴奋和满足

吸引力是综合性原则，涉及设计、动态、情感和故事情节等多个方面，往往决定动画的成功和影响力。

## 小结

掌握迪士尼的 12 大动画原则需要时间、实践和持续的应用。这些原则不仅对传统手绘动画有价值，对当代 Web 动画技术同样适用。

12 条原则可以归纳为三个层面：**物理真实性**（挤压和拉伸、跟随与重叠动作、渐快与渐慢、弧线、时间控制）让动画符合现实运动规律；**叙事与引导**（预备动作、舞台布局、附属动作、夸张）控制注意力和信息传达；**表现品质**（连续动作与关键动作的方法选择、立体造型、吸引力）决定动画的最终观感。将这些原则应用于 Web 动画，能显著提升动画质量与用户体验。

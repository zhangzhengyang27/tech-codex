# CSS 缓动函数基础：为 Web 动画注入灵魂

## 概念说明

使用 CSS 的 `transform`、`transition`、`animation` 与 `@keyframes` 可以制作出 CSS 动画，但要制作出流畅、优雅、自然的动画，关键在于控制动画的速度。**缓动函数（Easing Function，也称时间函数）就是影响动画速度或速率的重要条件之一**。

制作动画的一个必要原则是让动画更接近现实运动。如果页面上十几个元素都使用相同的持续时间和相同的预设缓动函数（如 `linear`、`ease`），界面会显得单调；而让动画的运动节奏更多样、更自然，能显著提升用户体验。

缓动函数不改变动画的起止状态，只改变属性值变化的快慢节奏。它主要用作过渡动画的 `transition-timing-function` 或帧动画的 `animation-timing-function` 属性值。

### 一个直观的对比示例

下面示例中的五个轮子（`.wheel`）都从屏幕左侧滚动到右侧，再返回起点：

> Demo 地址：<https://codepen.io/airen/full/YzBpGxx>

五个轮子的关键帧动画属性完全相同：

```CSS
@keyframes move {
    to {
        translate: calc(100vw - 2rem - 88px) 0;
        rotate: 2turn;
    }
}
```

动画持续时间也相同，均为 `5s`：

```CSS
.wheel {
    animation: move 5s infinite alternate;
}
```

也就是说，五个轮子共享相同的持续时间、相同的关键帧、相同的属性值变化量，但呈现出的动画效果明显不同。造成差异的是**缓动函数**——每个轮子使用了不同的 `animation-timing-function`：

```CSS
.wheel {
    animation: move 5s infinite alternate;
    
    &:nth-child(1) {
        animation-timing-function: linear;
    }
    
    &:nth-child(2) {
        animation-timing-function: ease;
    }
    
    &:nth-child(3) {
        animation-timing-function: ease-in;
    }
    
    &:nth-child(4) {
        animation-timing-function: ease-out;
    }
    
    &:nth-child(5) {
        animation-timing-function: ease-in-out;
    }
}
```

**结论：缓动函数是一种改变属性动画速度的东西。**

## 原理与机制

### 距离-时间图表

将一个元素（如一个圆圈）从屏幕左侧移动到右侧，把动画分解为 `24` 帧。最"合理"的做法是均匀分割空间，即假设圆圈以恒速从左滚到右：

> Demo 地址：<https://codepen.io/airen/full/LYqbbXX>

这样制作的动画很呆板，运动对象似乎没有质量感和动力感。

把这种动画绘制在图表上：

- 水平方向 `x` 轴表示动画持续时间（`animation-duration`）的百分比
- 垂直方向 `y` 轴表示距离（`@keyframes`）的百分比，即已完成的运动百分比（也常称进度）

动画持续时间决定了动画从第一个关键帧（`0%` 或 `from`）到最后一个关键帧（`100%` 或 `to`）所需的时间。从左下角（`0%` 持续时间、`0%` 进度）出发，到右上角（持续时间和进度均 `100%`）结束，起点 `A` 与终点 `B` 连成一条路径（曲线），用来表示动画速度。这条曲线就是**缓动曲线**（缓动函数）。

上面这种恒速情形对应的曲线是唯一没有弯曲部分的缓动曲线，称为**线性曲线**。

现实生活中的物体运动并非恒速。给物体的运动添加不同的斜率，运动路径就变成真正的曲线——这正是五个轮子在相同距离、相同时间下运动结果不同的原因：从 `A` 点到 `B` 点虽然用时都是 `5s`，但运动曲线（速度）不同，最终动画效果就不同。

由此构成四种主要的缓动曲线类型：`linear`、`ease-in`、`ease-out` 和 `ease-in-out`（`ease` 可视为 `ease-in-out` 的一种变体）。大多数动画使用这四种曲线之一。`ease-*` 曲线还可以进一步微调以产生更多细微差别，例如 [easings.net](https://easings.net/) 中展示的各条缓动曲线：

> URL: <https://easings.net/>

此外还有弹簧曲线等更高级的形式。缓动曲线的重要特点是：

- 不改变属性值的起始点
- 不改变属性值的结束点
- 不改变动画的持续时间
- 只改变属性值变化的速度

### 用 f(t) 描述动画

缓动函数（动画曲线）是在可动画化的属性和时间之间绘制的一种图形，定义了动画速度如何随时间变化。动画中通常用 `f(t)` 表示某个属性（如位置、颜色）随时间 `t` 变化的函数：`t` 代表时间，`f(t)` 的输出值表示属性在对应时间点上的取值。`f(t)` 的具体形式取决于动画需求和所用的数学模型。

从数学角度看，距离作为时间函数对时间的一阶导数就是速度：运动曲线陡峭的地方速度高，平缓的地方速度低。下面通过一个简单示例说明这一点。

### 示例：为什么 linear 显得机械

构建一个物体移动动画：通过 `translate` 将一个轮子（`.wheel`）从点 `A`（初始位置）移动到点 `B`（结束位置），距离为 `1000px`，总耗时 `1s`。用 CSS 帧动画定义如下：

```CSS
@keyframes move{
    to {
        translate: 1000px;
    }
}

.wheel {
    translate: 0px; /* 可以省略不写 */
    animation: move 1s linear both; 
}
```

> Demo 地址：<https://codepen.io/airen/full/dyaORbL>

示例先使用最简单的 `linear` 缓动函数。`linear` 曲线是线性的，动画恒速运动，整体显得生硬。绘制轮子的运动图即可解释原因：运动图有两个坐标轴，一个是距离（运动进度，对应 `@keyframes` 中动画属性变化），另一个是时间（动画持续时间）。轮子在 `1s` 内移动 `1000px`：

- `0s` 时动画未开始，轮子位于初始值（`translate: 0`）
- 动画播放完（经过 `1s`）后，轮子行进了 `1000px`（`translate: 1000px`）

图表左下角表示 `0%` 持续时间和 `0%` 距离，右上角表示两者均达到 `100%`。把初始位置和最终位置标入图中，再添加不同时间点的位置数据点（如 `.0375s`、`.6s` 等），连接所有点后即得到该动画完整的"距离-时间"图。

### 速度与曲线斜率的关系

速度的计算公式：

    速度 = 行驶距离 ÷ 走完这段距离所花费的时间

一辆汽车在 `1` 小时内行驶 `100` 公里，速度就是每小时 `100` 公里。速度加倍，则相同时间行驶 `200` 公里，或者说半小时行驶 `100` 公里；速度减半，则相同时间只能行驶 `50` 公里，或者说需要两小时才能走完 `100` 公里。

回到轮子示例：在"距离-时间"图上计算不同时间间隔内的运动速度，会发现四个时间间隔内速度完全相同（`s1 = s2 = s3 = s4`），即无论选择哪个时间间隔，轮子都以每秒 `1000px` 的速度移动。而现实中的物体运动不会恒速——它们慢慢开始、逐渐加速、移动一段时间、再减速直到停止。示例中的轮子从一开始就以恒速移动，又以完全相同的速度突然停止，这正是动画显得呆板和不自然的原因。

改变速度后，图表外观随之变化：

- **加速**：速度加倍时，轮子 `.5s` 内移动 `1000px`；速度三倍时，`0.3333s` 内移动 `1000px`。在同一图表上绘制这些情形可以发现，**当速度变快时，运动曲线与时间轴的夹角会变大（`α1 < α2 < α3`）**。
- **减速**：速度减半时，轮子需 `2s` 移动 `1000px`（`1s` 只走 `500px`）；速度降至三分之一时，需 `3s` 移动 `1000px`（`1s` 约走 `333.33px`）。**当速度变慢时，运动曲线与时间轴的夹角会变小（`α1 > α2 > α3`）**。

即：运动曲线越陡峭，短时间带来更大的距离变化，速度更快；曲线越平缓，长时间只带来微小的距离变化，速度更慢。

### 构造自然的运动曲线

上述情境只调整了轮子从 `A`（`translate: 0`）到 `B`（`translate: 1000px`）的运行速度，物体仍恒速运动。基于"速度与斜率"的关系，可以在图表上绘制出更自然的运动曲线：

1. **缓慢开始，逐渐加速**：现实物体通常缓慢开始再慢慢加速。让 `0s` 至 `0.25s` 之间曲线平缓（速度较慢），`.25s` 之后曲线变陡（速度更高）。但折线在 `.25s` 处形成一个锐角，转换点不平滑，需要把折线变成一条曲线。
2. **到达前逐渐减速**：现实物体停下之前会逐渐减速。假设轮子在 `.6s` 左右开始减速，在折线图上再增加一个变换点：`0s` 至 `0.25s` 缓慢运行，`.25s` 至 `.6s` 加速移动，`.6s` 至 `1s` 慢慢减速直至停止，并把两个折角点抹平，使整条折线成为曲线。

这两条曲线与常见的 `ease-in` 和 `ease-in-out` 非常相似。注意，拐角处绘制的曲线实际上是许多小线段的集合；线段越陡峭速度越快，越平缓速度越慢——组成曲线的线段逐渐变陡时速度逐渐增加，逐渐变平时速度逐渐减慢。

## 缓动函数的设计

"应该在什么情况下使用哪种缓动函数"没有统一答案：**没有一种缓动函数适用于所有情况**。设计缓动函数是动画设计的关键组成部分。缓动函数通常根据现实世界的物理规律设计，但并不总是遵循这些规则。现实世界是动画灵感的好来源：现实中没有物体会像 `linear` 那样以全速开始然后立即停止，物体总有一定的加速或减速度。这也是迪士尼动画十二原则（在很大程度上基于物理学及其夸张表现）所概述的概念之一。

设计缓动函数时牢记：**陡峭（垂直）表示速度快，平缓（水平）表示速度慢**。可以在 `(x, y)` 坐标系（"距离-时间"图表）中创建许多不同类型的缓动函数。

除了在帧内制作缓动函数，还可以打破帧限制，使动画超出关键帧之间的值，以此创建弹跳、弹簧等效果的动画曲线。

例如一个滑出菜单栏的动画：

> Demo 地址：<https://codepen.io/airen/full/JjxbevQ>

点击右上角的"☰"图标，菜单栏从屏幕右侧滑入，但动画感觉生硬，因为 `transition-timing-function` 使用了 `linear`：

```CSS
@layer animation {
    .menu {
        translate: 100%;
        transition: all 0.3s linear;
    }
  
    input[type="checkbox"]:checked ~ .menu {
        translate: 0;
    }
  
    input[type="checkbox"]:unchecked ~ .menu {
        translate: 100%;
    }
}
```

优化方式有两种：一是改用预设曲线函数 `ease`、`ease-in`、`ease-out` 或 `ease-in-out`；二是使用 `cubic-bezier()` 自定义缓动函数。

### 用 cubic-bezier() 自定义缓动函数

`cubic-bezier()` 通过修改四个不同点的位置创建所需的动画曲线。由于动画对象的初始和最终状态已知，曲线的两个端点（锚点）固定，只需调整另外两个点的位置（控制点）。

`cubic-bezier()` 接受四个数字（`n1`、`n2`、`n3`、`n4`），仅代表两个控制点的位置：

- `n1` 和 `n2` 代表第一个控制点的 `x` 和 `y` 坐标
- `n3` 和 `n4` 代表第二个控制点的 `x` 和 `y` 坐标

改变控制点位置会改变曲线形状，从而影响动画效果，因此修改 `n1`、`n2`、`n3`、`n4` 中任何一个或全部都会改变最终曲线。例如下图表示 `cubic-bezier(.14, .78, .89, .35)`。

可以使用 [cubic-bezier](https://cubic-bezier.com/) 在线工具来设计所需的缓动函数：

> 工具地址：<https://cubic-bezier.com>

若希望菜单以非常快的速度滑入，然后优雅地减速并停止，可用 [cubic-bezier](https://cubic-bezier.com/) 工具获得 `cubic-bezier()` 函数的 `n1`、`n2`、`n3` 和 `n4` 坐标值，例如 `cubic-bezier(.05, .69, .14, 1)`，替换 `linear` 作为 `transition-timing-function` 的值：

```CSS
.menu {
    transition: all 0.3s cubic-bezier(.05, .69, .14, 1);
}
```

> Demo 地址：<https://codepen.io/airen/full/WNPoLEa>

动画将以快速开始然后减速，而不是全程恒速。`cubic-bezier()` 函数强大且灵活，可以制作各式各样的动画曲线——每一条不同的曲线都会给动画带来不同的效果。例如前文的轮子转动示例改用 `cubic-bezier()` 后，转动效果会各式各样：

> Demo 地址：<https://codepen.io/airen/full/VwgmVaJ>

## CSS 缓动函数的类型

缓动函数 `f(x)` 是一个数学函数，满足 `f(0)=0` 和 `f(1)=1`，精确描述动画期间物体从一个状态到另一个状态的移动速率。它为移动对象添加加速和减速效果，主要有四种类型：恒速（`linear`）、加速（`ease-in`）、减速（`ease-out`）和加减速（`ease-in-out`）。

进一步细分，还有七种缓动动画：二次缓动（Quadratic）、三次缓动（Cubic）、四次缓动（Quartic）、正弦缓动（Sinusoidal，也叫 Sine）、五次缓动（Quintic）、指数缓动（Exponential）和圆形缓动（Circular）。注意，只有加速（`ease-in`）、减速（`ease-out`）和加减速（`ease-in-out`）才有这些细分类型。

CSS 中主要有四种类型的缓动函数：

- **线性缓动函数**： `linear`
- **三次贝塞尔函数**：`ease`、`ease-in`、`ease-out` 和 `ease-in-out`
- **阶梯函数（分段函数）** ：`steps()`、`step-start` 和 `step-end`
- **自定义缓动函数**：`linear()`

它们用作 `transition-timing-function` 或 `animation-timing-function` 的值：

```CSS
.transition {
    transition-timing-function: linear;
}

.animation {
    animation-timing-function: linear;
}
```

也可用于简写的 `transition` 和 `animation` 属性：

```CSS
.transition {
    transition: transform 2s linear;
}

.animation {
    animation: move 2s linear;
}
```

### 线性缓动函数

线性缓动函数（`linear`）创建的动画从开始到结束都以恒定速度运动，整个过程中速度没有变化，速度曲线是一条直线。通过 `linear` 关键词即可设置：

```CSS
.transition {
    transition-timing-function: linear;
}

.animation {
    animation-timing-function: linear;
}
```

线性缓动函数的特征：

- **匀速运动**：动画以恒定速度运动，过程中没有加速或减速
- **简单直接**：速度曲线是一条直线，动画均匀进行，没有起伏
- **预测性**：由于速度恒定，开发者可以轻松预测和控制动画的行为

优点：

- **预测性**：可精确控制动画的速度和持续时间
- **简单性**：易于实现和调整，适用于简单的动画需求

缺点：

- **缺乏自然感**：大多数现实世界的运动都伴随加速和减速，线性运动不具备自然感
- **单调乏味**：速度恒定，可能显得单调，缺乏动态性

线性缓动函数是唯一 `f(x) = x` 的缓动函数，因为它在两点上受限。

### 三次贝塞尔缓动函数

线性缓动函数使用不当或过于频繁时，动画会显得单调和不自然。用户对自然运动更有反应，即需要能加速和减速的非线性缓动函数。

CSS 中使用由四个点定义的贝塞尔曲线来设置三次贝塞尔缓动函数。通过调整 `cubic-bezier()` 中两个控制点的坐标，可以得到各种不同类型的缓动函数：

> 工具地址：<https://cubic-bezier.com>

```CSS
.transition {
    transition-timing-function: cubic-bezier(.49,1.1,.69,.67);
}

.animation {
    animation-timing-function: cubic-bezier(.08,1.34,.95,.03);
}
```

常用的预定义缓动函数 `ease`、`ease-in`、`ease-out` 和 `ease-in-out` 都属于三次贝塞尔缓动函数，可作为设置非线性缓动函数的快速方法：

- **`ease`**：既有加速又有减速，但两者不均匀
- **`ease-in`**：以缓慢的速度开始，逐渐加速，最终达到最大速度。例如汽车启动
- **`ease-out`**：以快速开始，然后随时间减速，有点像球在地板上滚动。与 `ease-in` 相反，不显示初始加速
- **`ease-in-out`**：开始逐渐加速，然后朝末尾减速

其中 `ease` 是 CSS 缓动函数的默认值，是 `ease-in-out` 的一种变种：变化在开始和结束时都比较慢，只在中间某个地方加速，能给用户很好的感觉。

这些预定义缓动函数也可以用 `cubic-bezier()` 函数定义：

```CSS
:root {
    --linear: cubic-bezier(0.0, 0.0, 1.0, 1.0);
    --ease: cubic-bezier(0.25, 0.1, 0.25, 1.0);
    --ease-in: cubic-bezier(0.42, 0, 1.0, 1.0);
    --ease-out: cubic-bezier(0, 0, 0.58, 1.0);
    --ease-in-out: cubic-bezier(0.42, 0, 0.58, 1.0);
}
```

三次贝塞尔缓动函数由四个实数定义，指定三次贝塞尔曲线的两个控制点 `P1` 和 `P2`。曲线端点 `P0` 和 `P3` 固定在 `(0, 0)` 和 `(1, 1)`，`P1` 和 `P2` 的 `x` 坐标被限制在 `[0, 1]` 范围内。

三次贝塞尔缓动函数的特征：

- 具有非线性的动画速度，可产生加速和减速效果，使动画更自然流畅
- 允许在动画的不同阶段定义不同的速度曲线——两个控制点的位置可微调，以满足特定需求
- 自定义性高，可根据设计要求精确控制动画的速度和效果

优点：

- **自定义性强**：可根据需要创建自定义缓动效果
- **自然流畅**：能模拟现实生活中的加速和减速运动

缺点：

- **难以调整**：创建和微调可能需要数学知识和实验，对初学者不友好
- **复杂性**：复杂的缓动函数会增加动画的复杂性，需要更多测试和调试

三次贝塞尔缓动函数是创建自定义、自然流畅动画效果的强大工具，适合希望实现特定动画效果或提升用户体验的项目。

### 阶梯缓动函数

CSS 中的阶梯缓动函数主要有 `step-start`、`step-end` 和 `steps()`。阶梯缓动函数将输入时间分成指定数量的等长间隔，动画从一个值跳到下一个值。`steps()` 函数可指定步数和跳跃位置（可选）。它还有两个预定义关键字：`step-start` 等同于 `steps(1, start)`，`step-end` 等同于 `steps(1, end)`。

阶梯缓动函数允许动画以不连续的方式在特定数量的帧之间跳跃，可想象为一种"跳跃"动画。

例如轮子 `.wheel` 从点 `A`（`translate: 0`）移动到点 `B`（`translate: 1000px`），将动画限制为五步，动画将跳跃到以下五个关键帧位置：`200px`、`400px`、`600px`、`800px` 和 `1000px`：

```CSS
.wheel {
    animation: move 5s steps(5) both;
}
```

> Demo 地址：<https://codepen.io/airen/full/abXpzqd>

`steps()` 还有额外的选项控制包含哪些关键帧。上例中动画从 `0px` 移动到 `1000px`，使用 `steps(5)` 时以 `1000px` 的位置结束。若希望动画从 `200px` 开始，可使用第二个参数 `jump-*` 选项，它影响从动画时间轴中选择关键帧的方式。`jump-*` 选项包括 `jump-start`、`jump-end`、`jump-none`、`jump-both`、`start` 和 `end`，其中 `start` 与 `jump-start` 行为一致，`end` 与 `jump-end` 行为一致。

```CSS
.wheel {
    --jump: jump-start;
    animation: move 5s steps(5, var(--jump)) both;
}
```

> Demo 地址：<https://codepen.io/airen/full/MWLJwKa>

CSS 阶梯缓动函数有两个明显特征：

- **非连续性**：将动画分成指定数量的间隔，使动画在指定的帧之间跳跃，创建非连续的动画
- **控制精确**：可通过步数和跳跃位置精确控制动画跳跃到的关键帧位置，实现特定效果

优点：

- 非常适合模拟离散的动画，例如物体跳跃、切换帧或机械动作
- 提供更多控制选项，可自定义动画的节奏和速度
- 可制作有趣独特的效果，如像素化转场或分段过渡

缺点：

- 离散的特性使其不适合创建平滑的过渡或动画
- 使用不当可能导致动画显得生硬和不自然
- 需要更多调整和试验才能获得所需效果

`steps()` 阶梯缓动函数在特定场景下非常有用，适合创建离散性质的动画。例如 CSS 中的雪碧图帧动画（Sprites Animation）一般就用 `steps()` 构建：

### 自定义缓动函数 linear()

CSS 预定义的 `ease`、`ease-in`、`ease-out`、`ease-in-out` 以及 `cubic-bezier()` 可以满足大部分动画需求，但弹跳、弹簧这类更特定的效果无法用它们实现。

为此，W3C 规范的 [CSS 缓动函数 Level 2 版本](https://drafts.csswg.org/css-easing/#the-linear-easing-function) 新增了 `linear()` 缓动函数。`linear()` 与 `linear` 关键词是两个不同的缓动函数：`linear` 的动画曲线始终是一条直线，而 `linear()` 函数可定义一个分段线性函数，在指定的点之间进行线性插值。

`linear()` 可以绘制包含任意多个点的运动曲线，从而模拟弹跳和弹簧等更复杂的动画效果：

```CSS
:root {
    /* 弹跳缓动曲线 */
    --bounce-easing: linear(
        0, 0.0157, 0.0625, 0.1407, 0.25 18.18%, 0.5625, 1 36.36%, 0.8907, 0.8125,
        0.7657, 0.75, 0.7657, 0.8125, 0.8905, 1, 0.9532, 0.9375, 0.9531, 1, 0.9844, 1
    );
  
    /* 弹簧缓动曲线 */
    --spring-easing: linear(
        0, 0.009, 0.035 2.1%, 0.141, 0.281 6.7%, 0.723 12.9%, 0.938 16.7%, 1.017,
        1.077, 1.121, 1.149 24.3%, 1.159, 1.163, 1.161, 1.154 29.9%, 1.129 32.8%,
        1.051 39.6%, 1.017 43.1%, 0.991, 0.977 51%, 0.974 53.8%, 0.975 57.1%,
        0.997 69.8%, 1.003 76.9%, 1.004 83.8%, 1
    );
 
    /* 弹性缓动曲线 */
    --elastic-easing: linear(
        0, 0.218 2.1%, 0.862 6.5%, 1.114, 1.296 10.7%, 1.346, 1.37 12.9%, 1.373,
        1.364 14.5%, 1.315 16.2%, 1.032 21.8%, 0.941 24%, 0.891 25.9%, 0.877,
        0.869 27.8%, 0.87, 0.882 30.7%, 0.907 32.4%, 0.981 36.4%, 1.012 38.3%, 1.036,
        1.046 42.7% 44.1%, 1.042 45.7%, 0.996 53.3%, 0.988, 0.984 57.5%, 0.985 60.7%,
        1.001 68.1%, 1.006 72.2%, 0.998 86.7%, 1
    );
}
```

> Demo 地址：<https://codepen.io/airen/full/yLZLYmx>

`linear()` 函数的特点：

- 沿指定时间间隔内的点之间进行线性插值
- 可自定义缓动曲线，实现更复杂的动画效果，如反弹和弹簧
- 支持定义多个点，允许绘制任意的自定义缓动曲线

优点：

- 提供更多自定义选项，可创建自然感觉的 UI 动画
- 可创建各种不同的缓动曲线，满足特定动画需求
- 可创建自定义的非线性缓动效果，如反弹和弹簧

不足：需要更多参数和定义，相对于标准缓动函数工作量更大。

## 选择合适的缓动函数

### 与光相关的属性

对与光相关的属性（颜色、亮度、不透明度）做动画时，最好使用 `linear`。线性缓动函数为这些属性提供最均匀、一致的过渡。例如颜色过渡动画中，`linear` 产生最均匀的颜色混合：

```CSS
.animated {
    transition: background-color 200ms linear;
}
```

> Demo 地址：<https://codepen.io/airen/full/rNPjepy>

示例中三个元素的背景颜色（`background-color`）都从 `#EA42F7` 过渡到 `#73FBFD`，唯一区别是缓动函数分别为 `linear`、`ease-out` 和 `ease-in`。非线性缓动函数会导致颜色混合不均匀：使用 `ease-out` 时，中间点（颜色过渡的临界点）更偏左，背景色很快从 `#EA42F7` 过渡到 `#73FBFD`；使用 `ease-in` 时，中间点更偏右，过渡用时更长。因此对颜色过渡，线性缓动函数是大多数情况下的最佳选择。

### 旋转

旋转是另一个适用于 `linear` 的用例：

> Demo 地址：<https://codepen.io/airen/full/mdvRPgY>

Demo 中左侧元素使用默认值 `ease`，旋转时会停顿一下再继续，像扁平轮胎滚动一样不平滑；右侧元素使用 `linear`，旋转过程一致，观感更舒适。

不过旋转比光相关属性更微妙，`linear` 并不总适用。例如转盘抽奖：现实中转动抽奖转盘时它会慢慢停下，因此 `ease-out`（减速）比 `linear` 更合适（`ease` 或 `ease-in-out` 也可以）：

```CSS
.wheel {
    --rotation: 0deg;
    rotate: var(--rotation);
    transition: rotate 2s ease-out;
}
```

> Demo 地址：<https://codepen.io/airen/full/poGREoZ>

总体而言，遇到旋转相关的动画，可先选择线性缓动函数，不合适再更换。

### 交互元素

交互元素（可点击、悬停、可拖动等）是一个广泛的动画类别。为交互元素动画选择缓动函数时，可参考以下情境：

**`linear`（恒速）**：自然界物体很少恒速移动，恒速动画感觉机械化。但有时机械感正是目标，例如让火车的速度感觉机械化以产生火车驶过的幻觉。也适用于不受物理影响的元素、以及颜色和不透明度的过渡。

**`ease-in`（加速）**：开始缓慢，周期结束前加速，给人加速的感觉。适合将对象平滑地过渡出视野，适用于从屏幕飞出并永远离开的元素，例如用户关闭通知时。缺点是可能感到迟缓。

**`ease-out`（减速）**：开始很快，时间结束前逐渐变慢，给人减速的感觉。适合将对象移动到视图中并强调重要视觉信息，适用于从屏幕外部出现的元素（如从外部滑入的通知）、从屏幕外滑到视口的卡片，也非常适用于页面过渡效果。

**`ease-in-out`（加减速）**：开始缓慢，中点前变快，然后再次减速，先加速后减速。对大多数运动感觉流畅且响应灵敏，常用于将对象从屏幕一部分移动到另一部分、元素消失但可被带回原位（如菜单），尤其适用于按钮和需要即时反应的元素。缺点是应用于所有情况时可能感觉不自然或过于完美。

如果预定义缓动函数无法满足需求，需考虑 `cubic-bezier()` 函数；它使用更复杂，需要不断调试才能得到满意效果。对于需要分段、定格呈现的动画效果（如雪碧图帧动画），`steps()` 更为合适。对于弹跳或弹簧类动画效果，目前最合适的是 `linear()`。

### 常见错误

互动类动画在 Web 上随处可见，但很多动画因一些小错误而效果不佳。避免以下错误可以解决大多数 UI 动画问题。

**错误一：迟钝的交互。** 时间和速度都会影响动画及交互效果。持续时间（`animation-duration`）的经验值：

- 淡入淡出和颜色动画：使用几乎瞬时的持续时间（小于 `100ms`）
- 简单效果和相对较小的动画：使用较短持续时间，约 `100ms ~ 300ms`；也适用于用户发起的需要反馈的操作（触摸、点击、滑动等）
- 更复杂的效果和较大规模的动画（如页面过渡或屏幕内外的对象移动）：使用较长持续时间（大于 `300ms`）
- 慢动画（大于 `500ms`）：保留给大幅移动和影响氛围的背景元素

一般认为交互在 `100ms` 内发生即为瞬间。调整动画速度除持续时间外，还可通过缓动函数。例如两个悬停交互效果，一个使用 `ease-in`，另一个使用 `ease-out`：

> Demo 地址：<https://codepen.io/airen/full/LYqxQpL>

```CSS
@layer animation {
    .tooltips__content {
        translate: -50% 100%;
        opacity: 0;
        transition: 
            opacity .3s var(--easing),
            translate .3s var(--easing);
        
        .tooltips:hover & {
            opacity: 1;
            translate: -50% calc(-100% - 1.5rem);
        }
    }
}
```

两个悬停动画除缓动函数外完全相同：相同的持续时间（`transition-duration: .3s`），都没有显式设置延迟，但交互感差异巨大。对交互而言，`ease-out` 通常更好，因为反应更快——大多数运动发生在最前面，用户更容易注意到变化。这一经验法则也可以被打破，很多情况下 `ease-in` 或 `ease-out` 都能制作更好的动画，但多数情况下为交互选择 `ease-out` 感觉更"妥当"。

**错误二：给拖动事件添加缓动。** 拖动事件应与用户的鼠标或触摸输入实时跟踪。一旦开始给所有事物添加动画，很容易陷入给本不应动画的事物添加缓动函数的陷阱，拖动是主要问题。对比带缓动效果的可拖动控件与不带缓动的控件即可看出差别。并非总要把一切都做成"令人愉悦"的动画，尤其当它们妨碍更直接的反馈时。缓动效果应保留给真正受益于它们的交互。

**错误三：脱离现实世界的运动。** 大多数情况下 `ease-out` 是最佳默认缓动，但也有例外：如果组件充当现实世界物品的比喻，动画也应如此。开关是常见例子。对比以下两种开关动画，哪一个更像真实的"咔哒"开关：

```CSS
@layer animation {
    input[type="checkbox"]::before{
        transition: translate .3s var(--easing);
    }
  
    input[type="checkbox"]:checked::before {
        translate: calc(var(--w) - 100% - var(--bw) * 2 - var(--p) * 2);
    }
}
```

> Demo 地址：<https://codepen.io/airen/full/xxMgYXL>

左侧开关使用 `ease-out`，右侧使用 `ease-in`。右侧开关更像现实世界的开关：最初有一点阻力（克服内部弹簧的阻力），然后潜在能量释放，开关迅速进入最终静止位置，几乎可以"听到"它卡嗒扣上。两个开关持续时间相同，缓动效果造成了明显的感觉差异。

然而，通过在开始时增加阻力（`ease-in`），又与"前期展示更多运动以避免交互滞后"的原则相冲突。因此需要调整精确的缓动效果和时间，在现实世界比喻与响应式 UI 之间取得平衡。互动复杂且高度情境化，难以制定普遍规则，但若有疑问，对大多数互动使用默认的 `ease-out` 是正确选择，并根据需要进行调整（尤其当与现实情境不同时）；同时也不要忘记，不使用缓动效果也是一个选项（如拖拽示例）。

综上，动画缓动更微妙、更具普遍性的方法包括：

- 缓动帮助人脑注意到变化（物体横穿屏幕的动画比一帧内"瞬移"更易察觉），用它们提高对动作的识别
- 前期加入更多运动和变化也有助于提高识别度（`ease-out`）
- 使动画模仿现实世界（所有物体移动时都有动量并适当加速或减速；开关"卡嗒"开关而非平稳滑动等）
- 动画会引入输入延迟，只在用户此刻没有拖动、缩放、滚动时才添加

## 小结

缓动函数（时间函数、动画曲线）通过影响动画速度改变动画的外观和感觉，使动画接近自然运动，改善用户体验。预定义的 `linear`、`ease`、`ease-in`、`ease-out`、`ease-in-out` 可以快速添加时间函数；`cubic-bezier()` 和 `linear()` 函数可创建自定义缓动函数，获得更引人注目的动画；阶梯函数 `steps()` 可用来创建"跳跃"动画（Sprites 动画）。

除浏览器开发者工具外，互联网上还有众多在线工具可以简化和优化自定义缓动函数的创建过程。

本文探讨的是 CSS 缓动函数的基础知识，以预定义缓动函数为主。要创建更流畅、更吸引人的动画，必须掌握 `cubic-bezier()`、`steps()` 和 `linear()` 等函数的进阶用法——它们各自的特性、设计和应用值得单独深入探究。

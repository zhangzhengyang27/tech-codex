# 数学的魔法：探索数学在动画中的应用

## 概念说明

在数字化时代，数学不再是抽象的理论，而是动画创造中的实用工具。动画是一种模拟运动的视觉过程，关乎时间和比例，与数学有着紧密的联系。动画制作中通常强调创造力，但创造力离不开数学——只有与数学结合，才能创造出更杰出的动画效果。

Web 开发者或设计师在创造动画时需要各种数学技术，包括几何学、三角学、线性代数和微积分等：处理移动和变化的对象时，需要解决几何问题，并从一组简单的方程中识别未知数。对应用于动画中的数学知识有基本的理解，是创造更优秀动画的前提。

## 动画中的数学基础

从表面上看，制作 Web 动画是在通过 CSS、SVG 和 JavaScript 等技术处理物体（元素）的移动和变化，例如几何变换（平移、旋转、缩放等）、曲线和路径、插值计算、色彩与光影、投影与视角以及物理模拟（牛顿力学和粒子系统）等——这些都离不开数学。例如，只有利用好相关的数学知识，才能为动画提供更合理的时间与速度，使动画更自然；处理动画元素的外形和位置时，也需要通过三角函数等确定元素的位置、距离等。可以说，数学在动画中无处不在。

### 几何知识

几何知识在动画制作中至关重要，它提供了对物体形状、位置和运动的深刻理解。开发者可以使用圆圈、正方形和三角形构建动画元素的基本形状，然后通过操纵它们创造最终的动画效果：

> Demo 地址：https://codepen.io/raymondyang/full/eWGewE （来源于 [@Ray](https://codepen.io/raymondyang) ）

可用于动画制作的几何知识包括：

- **角色设计（基本几何形状）**：使用圆、矩形、三角形等基本几何形状作为角色和物体的基础结构，是构建更复杂图形的基本单元。
- **物体的变换和动画**：平移、旋转和缩放等几何变换用于实现物体的运动和变化，控制物体在场景中的位置、方向和尺寸。
- **三维几何学**：在三维动画中，几何学和线性代数用于描述和变换三维空间中的物体，创造具有深度感的场景。
- **几何构建与分解**：将复杂物体通过基本几何形状组合构建，或将复杂形状分解为简单几何元素，更有效地处理和控制复杂物体结构。
- **路径和运动轨迹**：使用几何学中的路径和曲线（包括贝塞尔曲线等）定义物体的运动轨迹，使运动更自然和艺术化。
- **光影和投影**：几何学原理用于计算光影、阴影和物体的投影效果，增加画面逼真度。
- **刚体运动和碰撞检测**：几何知识用于描述刚体运动和进行碰撞检测，确保物体之间的交互看起来自然。

三角函数在动画中的常见应用场景：

- **平滑的运动和旋转**：正弦和余弦函数产生平滑的运动和旋转效果，避免突兀和生硬。
- **摆动和振动效果**：正弦函数模拟钟摆的摆动或头部的摇晃等，通过调整振幅和频率创造逼真的摆动效果。
- **路径和轨迹的生成**：生成圆周运动、椭圆路径等复杂路径和轨迹。
- **变换效果**：应用于缩放、平移等几何变换，实现放大缩小、折叠展开等效果。
- **动画过渡和淡入淡出**：调整透明度变化，实现平滑的出现或消失。
- **声音和光效应的同步**：与声音或光效应的波形同步，增强动画的视听表现。
- **复杂动画效果的实现**：组合和调整多个三角函数，模拟自然界的运动、气象效应等复杂现象。
- **角色肢体的自然运动**：用正弦和余弦模拟角色肢体的自然摆动，创造更有生命力的角色表现。
- **动画转场效果**：实现平滑的转场，例如角色从站立到行走的过渡，增强场景连贯性。

### 线性代数

线性代数在特效制作、运动控制以及场景变换等方面起到关键作用：

- **特效制作**：通过矩阵运算精确控制图像的变形、旋转、缩放等，例如实现相机的移动和旋转、物体的形变。
- **相机运动**：描述和控制相机的平移、旋转和缩放，通过矩阵变换实现相机在三维空间中的任意运动。
- **图形变换**：提供描述和实现平移、旋转、缩放等变换的数学工具，使物体呈现自然而流畅的运动轨迹。
- **光影效果**：计算光源对物体的照射效果，包括阴影、反射和折射等，使场景更逼真。
- **三维空间变换**：提供三维矩阵变换和投影等工具，准确控制物体在三维场景中的各种变化。

### 微积分

微积分在动画中的应用主要涉及场景优化、运动模拟、特殊效果实现等方面：

- **运动模拟**：对位置、速度和加速度等物理量进行微积分运算，准确描述物体的运动轨迹。
- **光影效果的计算**：计算光线的传播、反射和折射，模拟不同材质表面的反射特性。
- **场景优化**：对复杂场景的多维数据进行积分和微分，提高渲染效率和图像质量。
- **特殊效果的实现**：对流体动力学和热力学等物理规律进行微积分建模，实现液体流动、火焰燃烧等效果。
- **形状变换和插值**：对形状参数进行微积分运算，实现形状的平滑变化。
- **动画曲线的设计**：对曲线方程进行微积分和积分操作，调整动画元素的变化速度和过渡效果。

### 物理知识

物理知识对创造真实自然的动画效果至关重要：

- **运动和力学模拟**：使用牛顿运动定律等物理规律计算物体的运动轨迹、速度和加速度。
- **重力和空气阻力**：模拟重力对物体的影响，以及空气阻力对运动轨迹的影响。
- **碰撞和反弹**：通过考虑能量守恒和动量守恒，表现逼真的碰撞和反弹效果。
- **流体动力学**：模拟流体的流动、波浪和涡流，创造逼真的水面、烟雾等效果。
- **布料模拟**：考虑布料的弯曲、拉伸和重力影响，使服装等布料呈现真实的运动和形态。
- **角色动作和关节**：用解剖学和生物力学原理模拟角色的骨骼和关节运动。

数学在动画的各个方面发挥着至关重要的作用：动画师可以利用比例、尺度、时序、物理学等知识创造逼真的动画、模拟动画效果，并设计引人入胜的视觉效果。

## 动画中的线性插值计算

CSS 过渡动画和关键帧动画中，动画设计软件或客户端（比如浏览器）会自动在状态之间进行插值计算：过渡动画会在开始状态和结束状态之间对过渡属性进行插值计算；关键帧动画的相邻两个关键帧（`@keyframes` 规则中相邻的两个选择器）之间会对关键帧进行插值计算。

这些插值是自动计算的，但在制作动画时，很多时候需要自己计算插值——这样做可以使动画更流畅和自然。例如在两个状态之间对某个属性值变化时，可以使用线性插值计算：将对象从 `A` 点移动到 `B` 点时，它可以显著改善动画效果。

### 线性插值的定义

线性插值通常称为 Lerp，是"Linear Interpolation"的简称，是一种在两个点之间进行线性插值的数学运算：在给定的两个数值之间生成一个新值，新值位于两个给定值的直线路径上，位置由插值参数决定。计算公式如下：

```
lerp(a,b,t) = a + (b − a) * t
```

其中 `a` 是起始值，`b` 是结束值，`t` 是插值参数，通常在 `0 ~ 1` 之间。

### 线性插值的应用场景

- **运动动画**：在两个关键帧之间平滑移动对象，在每一帧之间应用线性插值创建更自然的移动效果。
- **颜色渐变**：在颜色之间创建平滑的渐变效果，例如界面元素的状态变化或过渡。
- **相机移动**：在虚拟三维空间中平滑移动相机位置，创建平滑的相机跟随或场景切换过渡。
- **缩放效果**：在缩放系数之间应用线性插值，使对象以自然的方式放大或缩小。
- **透明度过渡**：在透明度值之间进行线性插值，实现淡入淡出等效果。
- **路径动画**：在路径上的点之间应用线性插值，创建对象沿路径平稳移动的效果。

### 鼠标跟随效果

一个典型应用是鼠标跟随效果——改变 `translateX()` 和 `translateY()` 的值时就应用了线性插值计算：

> Demo 地址：https://codepen.io/airen/full/WNPPWWB （来源于 [@Chris Caldwell](https://codepen.io/chriscaldwell/full/pNXOpV) ）

具体代码如下：

```JavaScript
var mouseX = 0;
var mouseY = 0;
var mouseMoved = false;

// LERP || Linear Interpolation
function lerp(A, B, t) {
    // A = Starting position
    // B = Final position
    // t = time or percentage A and B i.e. 0.0 to 1.0
    return A + t * (B - A);
}

function handleMouseMove() {
    mouseMoved = true;
    mouseX = event.clientX;
    mouseY = event.clientY;
}

document.onmousemove = handleMouseMove;

function setTransform(element, dx, dy) {
    var transform = "translateX(" + (dx) + "px) translateY(" + (dy) + "px)";
    element.style.transform = transform;  
}

function followMouse(element, t) {
    // Determine Start Position
    var startX = element.getBoundingClientRect().left;
    var startY = element.getBoundingClientRect().top;
  
    // Determine End Position
    var targetX = mouseX - element.offsetWidth / 2;
    var targetY = mouseY - element.offsetHeight / 2;
  
    // Determine LERP position
    var newX = lerp(startX, targetX, t);
    var newY = lerp(startY, targetY, t);
  
    // Set Position using Transforms
    setTransform(element, newX, newY);
}

// Set Position
function setPosition(element, target) {
    // Determine Position
    var targetX = target.offsetWidth / 2 - element.offsetWidth / 2;
    var targetY = target.offsetHeight / 2 - element.offsetHeight / 2;
  
    // Set Position using Transforms
    setTransform(element, targetX, targetY);  
}

// Animation
window.requestAnimationFrame(draw); 
function draw() {
    if (mouseMoved) {
        followMouse(el1, 0.1);
        followMouse(el2, 0.3);    
    }
    window.requestAnimationFrame(draw); 
}

// Handle Load
window.onload = function() {
    var el1 = document.getElementById("el1");
    var el2 = document.getElementById("el2");
    var viewport = document.body;

    // Set Initial Positions
    setPosition(el1, viewport);
    setPosition(el2, viewport);
};
```

通过这种方式，随着位置和目标之间的距离减小，对象移动的距离变得更小——对象在靠近目标时会减速，从而创建出漂亮的缓动效果。

基于同样的方式调整参数，可以创造其他动画效果。例如通过线性插值改变重复圆锥渐变的圆心位置，实现另一种鼠标跟随动画：

### 平滑滚动

线性插值还可以应用在交互中，例如使滚动效果更平滑流畅：

```JavaScript
const page = document.querySelector(".page");
const wrapper = document.querySelector(".page__wrapper");

const ease = 0.05;

const scroll = {
    current: 0,
    target: 0, 
    limit: 0
};

const updateTarget = (e) => {
    scroll.target += e.deltaY;
};

document.addEventListener("mousewheel", updateTarget);

// 线性插值计算
const lerp = (current, target) => {
    const distanceBetween = target - current;
    const distanceToTravel = distanceBetween * ease;
    return current + distanceToTravel;
};

const clamp = (min, max, value) => {
    const clamped = Math.min(Math.max(value, min), max);
    return clamped;
};

const smoothScroll = () => {
    const maxScroll = wrapper.clientHeight - window.innerHeight;
    scroll.target = clamp(0, maxScroll, scroll.target);

    const { current, target } = scroll;

    const transition = lerp(current, target);
    scroll.current = transition;

    wrapper.style.transform = `translateY(-${scroll.current}px)`;
    window.requestAnimationFrame(smoothScroll);
};

smoothScroll();
```

> Demo 地址：https://codepen.io/airen/full/XWOOvdv

动画中任意属性的两状态之间值变化，都可以应用线性插值来计算。

## 动画中的三角函数

现代 CSS 引入了三角函数，解锁了许多以前不可能完成的任务：定位元素位置、绘制不同的几何图形、创意布局和协调动画动作等。

### 三角函数回顾

CSS 的三角函数主要包括 `sin()`、`cos()`、`tan()`、`asin()`、`acos()`、`atan()` 和 `atan2()`，其中 `sin()`、`cos()` 和 `tan()` 使用频率最大：

- **[正弦函数（sin(θ)）](https://en.wikipedia.org/wiki/Sine_and_cosine)**：定义为该角（`θ`）的对边（Opposite）与斜边（Hypotenuse）的比例，即 `sin(θ) = Opposite / Hypotenuse = 对边 / 斜边 = a / c`，返回一个介于 `-1` 和 `1` 之间的值。
- **[余弦函数（cos(θ)）](https://en.wikipedia.org/wiki/Sine_and_cosine)**：定义为该角（`θ`）的邻边（Adjacent）与斜边（Hypotenuse）的比例，即 `cos(θ) = Adjacent / Hypotenuse = 邻边 / 斜边 = b / c`，返回一个介于 `-1` 和 `1` 之间的值。
- **[正切函数（tan(θ)）](https://en.wikipedia.org/wiki/Trigonometric_functions)**：定义为该角（`θ`）的对边（Opposite）与邻边（Adjacent）的比例，即 `tan(θ) = Opposite / Adjacent = 对边 / 邻边 = a / b`，返回一个介于 `-∞` 和 `+∞` 之间的值。

正弦、余弦和正切等函数可以使用以下公式描述：

```
sin(θ) = Opposite ÷ Hypotenuse = 对边 ÷ 斜边 = BC ÷ AB = a ÷ c
cos(θ) = Adjacent ÷ Hypotenuse = 邻边 ÷ 斜边 = AC ÷ AB = b ÷ c
tan(θ) = Opposite ÷ Adjacent = 对边 ÷ 邻边 = BC ÷ AC = a ÷ b = sin(θ) ÷ cos(θ)
```

> 通常会用希腊字母 `θ` 表示角度。

反三角函数（`asin()`、`acos()` 和 `atan()`）与三角函数（`sin()`、`cos()` 和 `tan()`）存在对应关系：三角函数用于计算一个给定角度的正弦、余弦和正切值（例如 `sin(θ)` 表示角度 `θ` 的正弦值）；反三角函数用于计算给定正弦、余弦和正切值的角度（例如 `asin(x)` 表示正弦值为 `x` 的角度，`acos(x)` 表示余弦值为 `x` 的角度，`atan(x)` 表示正切值为 `x` 的角度）。它们是三角函数与角度之间的桥梁，可以在不同形式的表达之间转换。

在 CSS 中可以这样使用三角函数：

- `sin()` 函数可用于改变元素尺寸或控制动画时长；
- `cos()` 函数可用于保持旋转元素的尺寸不变；
- `tan()` 函数可用于绘制平行四边形；
- `asin()`、`acos()`、`atan()` 和 `atan2()` 函数可用于旋转元素。

三角函数在动画中的常见应用：

- **平滑运动和缓动效果**：特别是正弦（`sin()`）和余弦（`cos()`）函数，实现元素的平滑运动和缓动，避免突然的加速和减速。
- **周期性动画**：正弦和余弦函数是周期性的，常用于创建循环或重复动作的动画，例如水波纹或震荡效果。
- **旋转动画**：在正弦和余弦函数中使用时间变量，实现平滑的旋转效果。
- **路径动画**：利用周期性和平滑性定义对象沿复杂路径运动的动画。
- **振荡效果**：使用正弦函数模拟摆动或弹簧的弹性动画。
- **相位和频率调整**：调整相位和频率改变动画的速度和周期。

### 解锁摩天轮动画

以游乐场的摩天轮为例，探讨如何使用 CSS 完成类似的动画效果。这个效果中很多地方会用到三角函数，例如摩天轮上每个吊篮的位置。

摩天轮有八个吊篮，均匀分布在一个圆环上。假设每个吊篮是一个点，将这八个点相连刚好可以构建出一个正八边形，正八边形的每个顶点就是吊篮的位置。

正多边形每条边所对应的角（相邻两个顶点，即吊篮的夹角）为 `θ`，等于 `360` 度除以正多边形边数：

```
θ = 360 ÷ 正多边形边数
```

本例是正八边形，所以 `θ` 等于 `45deg`（`θ = 360 ÷ 8 = 45`）。有了这些参数之后，就可以使用三角函数计算出正八边形每个顶点（吊篮）的位置，即它的 `x` 和 `y` 坐标：

```
x = r * cos(θ)
y = r * sin(θ)
```

逐个重复此过程，每次增加 `θ` 度的角度，即可绘制任意数量边的顶点坐标。

构建摩天轮动画效果需要如下 HTML 结构：

```HTML
<div class="wheel">
    <!-- 摩天轮上半部分：圆环 + 吊篮 -->
    <div class="wheel__turntable">
        <!-- 摩天轮的圆环 -->
        <div class="wheel__circle"></div>
        
        <!-- 摩天轮圆环中心内装饰: 小圆 + 五角星 -->
```

使用 CSS 绘制摩天轮的外形（圆环、五角星、吊篮等）时也应用到了相关的几何知识。此处更关注的是摩天轮每个吊篮的位置和摩天轮的旋转动画效果。

首先用自定义属性描述摩天轮上吊篮的个数 `--count: 8`，并据此得出 `θ` 的值：

```
θ = 360deg ÷ var(--count)
```

同样可以用自定义属性描述 `θ`，例如 `--deg`：

```CSS
:root {
    --count: 8; /* 摩天轮吊篮的数量 */
    --deg: calc(360deg / var(--count)); /* 相邻两吊篮之间夹角 */
}
```

#### 计算吊篮的位置

暂不考虑动画，按常规方式使用 `translate` 将所有吊篮从圆环中心位置沿水平方向移动到圆环上：

```CSS
.basket {
    position: absolute;
    top: calc(50% - var(--radius-s));
    translate: calc(var(--radius) + var(--space) + var(--radius-s));
}
```

这样给每个吊篮定位不够也不够灵活。正确的方式是将 CSS 三角函数应用进来，通过正弦（`sin()`）和余弦（`cos()`）函数计算吊篮的位置：

> Demo 地址：https://codepen.io/airen/full/QWYovmb

通过下面公式计算出每个吊篮的 `x` 和 `y` 坐标，即 `translate` 的 `x` 和 `y` 偏移量：

```CSS
translateX = cos(θ) × Radius = cos(var(--deg)) × Radius
translateY = sin(θ) × Radius = sin(var(--deg)) × Radius
```

其中 Radius 是圆环的半径 `--radius` 加上边框 `--border` 和外延出去的距离 `--space`，用自定义属性 `--r` 表示：

```CSS
:root {
    --r: calc(var(--radius) + var(--border) + var(--space));
}
```

角度 `--deg` 和斜边 `--r` 的值都有了：

```CSS
:root {
    --count: 8;
    --deg: calc(360deg / var(--count));
    --r: calc(var(--radius) + var(--border) + var(--space));
}
```

将这些参数应用到 `translate` 的 `x` 和 `y` 上：

```CSS
:root {
    --count: 8;
    --deg: calc(360deg / var(--count));
    --r: calc(var(--radius) + var(--border) + var(--space));
    
    --x: calc(cos(var(--deg)) * var(--r));
    --y: calc(sin(var(--deg)) * var(--r));
}
```

将 `.basket` 的 `translate` 值用计算出来的 `--x` 和 `--y` 替代：

```CSS
.basket {
    position: absolute;
    top: calc(50% - var(--radius-s));
    translate: var(--x) var(--y);
}
```

此时吊篮的位置就是根据三角函数计算出来的。接下来只需根据 `--index`（每个吊篮的索引值）调整每个吊篮所对应的 `--deg` 值：

```CSS
:root {
    --count: 8;  
    --r: calc(var(--radius) + var(--border) + var(--space));
}

.basket {
    --deg: calc(360deg / var(--count) * var(--index));
    --x: calc(cos(var(--deg)) * var(--r));
    --y: calc(sin(var(--deg)) * var(--r));
    
    position: absolute;
    top: calc(50% - var(--radius-s));
    translate: var(--x) var(--y);
}
```

仅仅几行代码就实现了摩天轮的布局。

#### 添加旋转动画

使用 `@keyframes` 创作旋转动画：

```CSS
@keyframes rotation {
    to {
        rotate: -360deg;
    }
}

.wheel__turntable {
    animation: rotation 10s linear infinite;
}
```

摩天轮旋转了，但每个吊篮也跟着旋转了，这并不是期望的效果——直接旋转摩天轮会导致其子元素（吊篮）一起旋转。为避免这个现象，需要将摩天轮的旋转动画分成两部分：吊篮的旋转与圆环的旋转方向相反，并且旋转中心需要调整。在吊篮上应用同一个关键帧动画 `rotation`，将动画的播放方向（`animation-direction`）设置为反向播放（`reverse`）：

```CSS
@keyframes rotation {
    to {
      rotate: -360deg;
    }
}
  
.wheel__turntable {
    animation: rotation 10s linear infinite;
    
    .basket {
        transform-origin:  center var(--radius-s);
        animation: rotation 10s linear infinite reverse;
    }
}
```

> Demo 地址：https://codepen.io/airen/full/JjxzWgW

核心代码如下：

```CSS
@layer animation {
    @keyframes rotation {
        to {
            rotate: -360deg;
        }
    }

    .wheel__turntable {
        animation: rotation 10s linear infinite;
    
        :is(.basket, .wheel__center) {
            animation: rotation 10s linear infinite reverse;
        }
    }

    :root {
        --radius: 30vh;     /* 圆环半径 */
        --border: 1vh;      /* 圆环边框宽度 */
    
        --radius-s: 1vh;    /* 吊篮顶部圆点半径 */
        --space: 4vh;       /* 圆环上直线伸出圆环的距离 */
        --line-height: 1vh; /* 圆环上直线厚度 */
        --count: 8;         /* 吊篮个数 */
        --r: calc(var(--radius) + var(--border) + var(--space)); /* 三角形斜边长度 */
    }
    
    .basket {
        --deg: calc(360deg / var(--count) * var(--index));
        --x: calc(cos(var(--deg)) * var(--r));
        --y: calc(sin(var(--deg)) * var(--r));
        position: absolute;
        top: calc(50% - var(--radius-s));
        translate: var(--x) var(--y);
        transform-origin: center var(--radius-s);
    }
}
```

### 解锁 CSS 中的随机值

正弦（`sin()`）和余弦（`cos()`）函数还有两个重要特性：

- **有界性**：正弦和余弦函数的结果始终介于 `-1 ~ 1` 之间，无论传递多大或多小的值，结果始终在这个范围内。
- **连续性**：对正弦或余弦函数的输入进行微小更改将导致输出发生微小更改。这一特性可以在动画过程中实现值的逐渐变化，同时系统仍然表现出随机性。

#### 有界性与归一化

正弦和余弦的结果始终在 `-1 ~ 1` 之间，可以将值简单归一化到 `[0,1]` 范围；有了归一化的值，就可以用简单的线性映射表示任何值。例如：

```CSS
.element {
    --x: calc(0.5 + 0.5 * sin(var(--n) * 342.06184 + 23.434));

    background: rgb(calc(50 + var(--x) * 100), 0, 0);
}
```

代码中 `rgb()` 函数中的 `r` 值始终会在 `50 ~ 100` 范围内：使用正弦函数将其值映射到 `[-1,1]` 范围，再通过简单的代数变换映射到 `[0, 1]` 范围；从 `[0,1]` 范围获取值后，可以使用线性映射将其映射到任何其他所需的值。

#### 连续性与伪随机

连续性意味着对输入的微小更改产生输出的微小更改，因此可以在动画过程中实现值的逐渐变化，同时保持随机性的表现。利用这些特性可以生成伪随机值。例如使用 CSS 的正弦函数生成随机值，动画元素的颜色和宽度是随机产生的：

```CSS
div::before {
    --x: calc(0.5 + 0.5 * sin(4.284 * var(--n)));
    --y: calc(0.5 + 0.5 * sin(7.284 * var(--n)));
    --z: calc(0.5 + 0.5 * sin(4 * var(--n) + 2 * var(--t)));
    --w: calc(0.5 + 0.5 * sin((0.2 * cos(var(--t)/100) + 0.8) * 49.123 * var(--n) + var(--t)));
  
    background: rgb(
        calc(50 +  100 * var(--x))  /* R 通道 */
        calc(200 + 30 * var(--y))   /* G 通道 */
        calc(120 + 100 * var(--z))  /* B 通道 */
    );
    width: calc(50% + var(--w)*50%); /* 元素宽度 */
}
```

最后两个变量除了计数器 `--n`，还使用了时间变量 `--t`，通过一个逐渐改变该变量的动画获得：

```CSS
@property --t {
    syntax: '<number>'; 
    initial-value: 0;
    inherits: true;
}

    --t: 0;
}

@keyframes timeOn {
    50% {
        --t: 30
    }
}

    animation: 30s timeOn infinite linear;
}
```

通过相关的数学知识和概念可以创造出更加逼真、流畅和有趣的动画效果。数学不仅仅是一种工具，更是解锁创意和创新的关键——这方面的基础越扎实，能创造的优秀动画就越多。

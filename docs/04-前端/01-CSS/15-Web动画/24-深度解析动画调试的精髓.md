# 深度解析动画调试的精髓

## 概念说明

创建优雅、引人入胜的动画不是一蹴而就的，需要不断的调试和优化。动画调试在创建动画的过程中不仅有助于确保动画的正确性和流畅性，还直接决定动画最终的效果，并直接影响用户体验的品质。

动画调试的重要性体现在以下几个方面：

- **确保动画正确性和一致性**：调试是发现和解决潜在问题的关键步骤，可以帮助开发者发现动画中的错误（例如关键帧位置、缓动函数的选择等）。不同平台和浏览器对动画的支持存在差异，调试有助于确保动画在各种环境中表现一致，提高跨平台兼容性。
- **优化性能和流畅度**：过于复杂或执行效率低的动画可能导致页面性能下降。调试可以帮助识别和优化影响性能的部分，发现导致卡顿或延迟的问题，确保动画流畅运行、即时响应。
- **调整时序以提高用户体验**：时序和缓动函数对动画至关重要。调试可以精确控制动画时序，确保动画按设计预期呈现；合理选择缓动函数能提高用户对界面变化的感知和使用的舒适度。
- **交互引导和用户反馈**：动画通常用于传达交互状态、提供反馈和引导用户操作。调试可以确保动画引导关注点的效果良好，并让状态变化的传达清晰直观。
- **避免视觉干扰和不适**：错误的动画可能让用户感到不适。通过调试可以发现并修复可能导致眩晕、不协调或其他视觉不适的问题，使动画流畅自然、不分散注意力。
- **提高开发效率**：调试工具和技术能帮助开发者更快地发现和解决问题，缩短开发周期。
- **整体提升用户体验**：动画是用户界面的关键组成部分。经过调试确保精确性和效果的动画，能提升界面吸引力和用户与产品交互的愉悦感。

## 动画调试工具概览

Web 动画主要承载在浏览器中，预览和测试基本都在浏览器上进行，因此动画调试主要依赖浏览器的 Web 开发者工具，即"检查"（Inspect）功能。Chrome、Firefox、Safari 和 Edge 等现代浏览器都在代码检查器中提供了动画（Animations）标签选项。

不同浏览器的动画调试面板有所差异，但使用方式和功能基本相似。动画标签有两个主要用途：

- **检查动画**：放慢、重放或检查动画组的源代码
- **修改动画**：修改动画组的时间、延迟、时长或关键帧偏移（不支持修改关键帧和贝塞尔曲线）

该调试工具主要用于调试 CSS 过渡动画（`transition`）和关键帧动画（`animation`）。对于 JavaScript API 创建的动画（例如 `requestAnimationFrame` 动画），无法通过该工具调试，需要具备 JavaScript 调试方面的知识与技巧。

> 特别声明，以下内容以 macOS 系统 Chrome 浏览器的动画调试工具为主，写作时使用的 Chrome 版本号是 120.0.6099.129。

### 打开动画调试面板

可以通过以下两种方式打开动画（Animations）选项：

- 在开发者工具中，从"**自定义和控制开发者工具** > **更多工具** > **动画**"中打开
- 通过开发者工具的命令菜单打开：在开发者工具打开状态下，同时按下 `Command + Shift + P`（macOS，其它系统为 `Ctrl+Shift+P`），在弹出面板的 `run` 后输入 "Show Animations" 后回车

动画调试面板默认是空的；触发动画后面板会捕获相关动画。如果动画在网页加载时触发，需要在**动画**标签页打开时重新加载页面。

### 动画调试面板的功能区域

整个动画调试面板包含四个部分：

**① 控制措施**：清除所有捕获的动画组，或改选动画组的播放速度。播放速度选择在调试动画时非常有用：动画按正常速度（`100%`）播放时难以发现的问题，放慢四倍（`25%`）播放时更容易暴露，例如动画时序问题。"清除"按钮一般用在重新录制动画组的场景——录制效果不理想时先清除，再重新录制。

**② 概览**：一是预览功能，录制了多个动画组时，鼠标悬浮在缩略图上可查看对应的是哪个动画组；二是选择功能，选中某个动画组的预览图后，该动画组的相关信息会在"详细信息"窗格中显示。

**③ 时间轴**：控制动画组的启动和暂停，也可以拖动动画或跳转到特定点。

**④ 详细信息**：显示"概览"窗格中选中动画组的详细信息，可以在这里检查和修改所选的动画组，是动画调试面板中最重要的部分。

### 检查动画

Web 中没有真正的组动画概念，一组动画的连贯效果需要设计师和开发者组合并设定各个动画的时间。动画调试面板的详情窗格会根据开始时间（不包括延迟）预测相关动画，并将它们关联分组。

以下示例在一个元素上应用多个动画：

```HTML
<button class="transition">CSS Transition</button>
<button class="animation">CSS Animations</button>
```



```CSS
@layer transition {
    .transition {
        color: var(--btn-color, #000);
        background: #fff;
        transition: 0.6s cubic-bezier(0.77, 0, 0.175, 1);
    
        &::before {
            background: var(--btn-bg);
            scale: 0 1;
            transform-origin: right;
            transition: scale 0.6s cubic-bezier(0.77, 0, 0.175, 1);
        }
    
        &:hover {
            color: white;
            background: transparent;
    
            &::before {
                scale: 1 1;
                transform-origin: left;
            }
        }
    }
}

@layer animation {
    @keyframes bounce {
        from,
        20%,
        53%,
        to {
            animation-timing-function: cubic-bezier(0.215, 0.61, 0.355, 1);
            translate: 0 0 0;
        }
    
        40%,
        43% {
            animation-timing-function: cubic-bezier(0.755, 0.05, 0.855, 0.06);
            translate: 0 -20px 0;
            scale: 1 1.1;
        }
    
        70% {
            animation-timing-function: cubic-bezier(0.755, 0.05, 0.855, 0.06);
            translate: 0 -10px 0;
            scale: 1 1.05;
        }
    
        80% {
            transition-timing-function: cubic-bezier(0.215, 0.61, 0.355, 1);
            translate: 0 0 0;
            scale: 1 0.95;
        }
    
        90% {
            translate: 0 -4px 0;
            scale: 1 1.02;
        }
    }

    .animation {
        color: var(--btn-color, #000);
        background: var(--btn-bg);
        transform-origin: center bottom;
    
        &:hover {
            animation: bounce 1s cubic-bezier(0.77, 0, 0.175, 1);
        }
    }
}
```

打开动画调试面板，将鼠标悬浮到按钮上触发动画，面板会捕获应用于按钮上的动画组。在**概览**窗格中点击动画组缩略图，**详细信息**窗格中会显示该动画组的详情，每个动画独立一行：第一列呈现动画应用于哪个元素，第二列呈现相应元素应用的动画（由不同形状图形和动画名组成）。

当同一个动画组中有多个元素应用了不同动画时，在动画调试面板中将鼠标悬浮在相应的动画元素上，浏览器会在视口中突出显示该动画；点击动画，可在**元素**面板中将其选中。

> 测试案例：https://codepen.io/airen/full/poGMaeZ

在"详细信息"窗格中将鼠标悬浮在 `div.down` 上时，视窗中会突出该动画；点击它时，元素面板（Elements）中的 `<div class="down"></div>` 会高亮显示。

如果动画设置了无限循环播放（`animation-iteration-count: infinite`），动画调试面板会显示其定义和迭代：

```CSS
.down {
    animation: 
        fadeInDown 0.5s cubic-bezier(0.19, 1, 0.22, 1) 0.3s both,
        bounce 1s cubic-bezier(0.19, 1, 0.22, 1) 0.8s both infinite;
}
```



"详细信息"窗格中 `div.down` 所对应的 `bounce` 动画，最左侧高亮的草绿色部分表示该动画的定义，后面较淡的草绿色部分表示 `bounce` 动画的迭代。

如果多个元素应用了同一个动画，调试面板的"详细信息"窗格会为这些元素分配相同的颜色（颜色本身是随机的，没有含义）。例如 `div.playing`、`div.slogan`、`div.download` 和 `div.down` 都应用了 `fadeInDown`；`div.home`、`div.off` 和 `h1.logo` 都应用了 `fadeInUp`；`div.notes` 和 `div.qrcode` 都应用了 `fadeInRight`。

除了查看动画的详细信息，还可以通过动画调试面板以不同的方式重放动画：

- 第一种方式：在"控制措施"窗格中选择不同的播放速度，例如 `100%`、`25%`（放慢四倍）和 `10%`（放慢十倍）
- 第二种方式：在"概览"窗格中，将鼠标悬浮在已捕获的动画组缩略图上，预览对应动画的播放
- 第三种方式：在"时间轴"窗格中拖动进度条指针（红色竖线）以拖拽视口动画，或点击时间轴上的任意位置定位到特定点；动画若已在播放则继续播放，否则停止

### 修改动画

动画调试面板的另一个功能是修改动画。通常可以通过"详细信息"窗格修改动画的持续时间、延迟时间和关键帧时间。

以下示例给 `.animation` 元素同时应用了 `heartBeat` 和 `swing` 两个动画：

```CSS
@layer animation {
    @keyframes heartBeat {
        0% {
            scale: 1;
        }
    
        14% {
            scale: 1.3;
        }
    
        28% {
            scale: 1;
        }
    
        42% {
            scale: 1.3;
        }
    
        70% {
            scale: 1;
        }
    }
  
    @keyframes swing {
        20% {
           rotate:0 0 1 15deg;
        }
    
        40% {
            rotate:0 0 1 -10deg;
        }
    
        60% {
            rotate:0 0 1 5deg;
        }
    
        80% {
            rotate:0 0 1 -5deg;
        }
    
        to {
            rotate:0 0 1 0deg;
        }
    }

    .animation {
        transform-origin: top center;
        animation: heartBeat 1.3s ease-in-out,swing 1s ease-in-out;
    }
}
```



打开动画调试面板，可以看到应用于 `.animation` 元素的 `heartBeat` 和 `swing` 两个动画在"详细信息"窗格中的呈现效果：

> Demo 地址：https://codepen.io/airen/full/gOEavgQ

#### 调整持续时间

拖动动画最后一个圆圈可以调整该动画的持续时间。例如希望将 `heartBeat` 动画的持续时间调整到与 `swing` 动画一致，在"详细信息"窗格中拖动 `heartBeat` 动画的最后一个圆圈，拖到与 `swing` 动画的最后一个圆圈平齐即可。

操作完成后，调试工具的样式（Styles）面板中的样式规则会发生相应变化，调整后的样式会覆盖初始样式。如果调整后的效果符合预期，可以将最新样式从开发者工具中复制出来，粘贴到样式表中覆盖之前的样式。

也可以拖动动画的第一个圆圈来调整持续时间，但这种方式会为动画添加一个延迟时间。因此，若只想调整持续时间，应拖动动画的最后一个圆圈。

#### 调整延迟时间

在"详细信息"窗格中修改延迟时间的方法与修改持续时间类似，区别在于拖动的是动画的第一个圆圈。例如希望 `heartBeat` 延迟 `.5s` 后开始播放，则拖动 `div.animation` 对应的 `heartBeat` 动画的第一个圆圈到时间轴的 `.5s` 处。

另一种方式是直接拖动动画本身，使动画的第一个圆圈到达指定位置。

无论哪种方式，动画之前都会增加一段虚线，虚线长度就是该动画的延迟时间；同时样式（Styles）面板中会在对应的样式中新增动画延迟时间。注意：拖动第一个圆圈或拖动整个动画不会缩短动画的持续时间。如果希望在新增延迟时间的同时相应减少持续时间，需要再次拖动动画的最后一个圆圈，减少与新增延迟相同的长度。

将调整持续时间和延迟时间两个功能结合，可以对动画序列进行编排，效果等同于通过 CSS 自定义属性构建的动画时间轴（参见《深入了解 CSS 动画的持续时间和延迟时间》）：

```CSS
@layer animation {
    @keyframes fadeInUp {
        from {
            translate: 0 100px;
            opacity: 0;
        }
        to {
            translate: 0 0;
            opacity: 1;
        }
    }
        
    @keyframes zoomIn {
        from {
            scale: .7;
            opacity: 0;
        }
        to {
            scale: 1;
            opacity: 1;
        }
    }
  
    :root {
        /* 持续时间 */
        --heading-duration: 1.1s;
        --subheading-duration: .9s;
        --button-duration: .9s;
        
        /* 延迟时间 */
        --heading-delay: 0s;
        --subheading-delay: calc(var(--heading-delay) + var(--heading-duration));
        --button-delay: calc(var(--subheading-delay) + var(--subheading-duration));
    }
  
    header {
        & h1 {
            animation: fadeInUp var(--heading-duration) cubic-bezier(.19,1,.22,1) var(--heading-delay) both;
        }
        
        & h4 {
            animation: fadeInUp var(--subheading-duration) cubic-bezier(.19,1,.22,1) var(--subheading-delay) both ;
        }
        
        & button {
            animation: zoomIn var(--button-duration) cubic-bezier(.19,1,.22,1) var(--button-delay) both;
        }
    }
}
```



> Demo 地址：https://codepen.io/airen/full/YzBLObZ

当动画之间的衔接不够协调时，可以通过动画调试面板调整动画的持续时间或延迟时间，直到效果满意为止。例如上述示例中各元素依次出现：`h1` 最早出现，其动画执行完后 `h4` 才出现，随后 `button` 出现。若希望每个元素的动画即将结束时下一个元素的动画就开始执行，可以在调试工具中调整它们的延迟时间。

调整后，在调试工具的样式面板中会得到调整后的持续时间和延迟时间：

```CSS
h4 {
    animation-duration: 900ms;
    animation-delay: 1003.4862518310547ms;
}

button {
    animation-duration: 900ms;
    animation-delay: 1797.7178382873535ms;
}
```



对比[左侧修改前的效果](https://codepen.io/airen/full/YzBLObZ)与[右侧修改后的效果](https://codepen.io/airen/full/RwdWMaX)。

::: warning 调整注意事项
上述展示的只是调整方式，具体调整应根据实际需求进行。调整过程通常需要不断反复，尤其在较复杂的情境中，只有反复调整才能达到最终效果。
:::

以上是 CSS 关键帧动画的持续时间和延迟时间的调试，CSS 过渡动画的持续时间和延迟时间也可以按相似的方法调整。

#### 调整关键帧时间

在"详细信息"窗格中，除了修改持续时间和延迟时间之外，还可以修改关键帧的时间。例如元素上应用了以下关键帧动画：

```CSS
@keyframes heartBeat {
    0% {
        scale: 1;
    }

    14% {
        scale: 1.3;
    }

    28% {
        scale: 1;
    }

    42% {
        scale: 1.3;
    }

    70% {
        scale: 1;
    }
}

.animation {
    animation: heartBeat 1s ease-in-out;
}
```



> Demo 地址：https://codepen.io/airen/full/oNVjqJv

CSS 关键帧动画与过渡动画的最大差异之一是关键帧动画由 `@keyframes` 定义。在动画调试面板的"详细信息"窗格中，如果动画定义了关键帧，这些规则会以白色内圈表示；关键帧的 `0%`（或 `from`）和 `100%`（`to`）以实心圆点表示。

`@keyframes` 中的百分比选择器相对于动画持续时间计算，因此也相对于动画调试面板中的"时间轴"计算。在"详细信息"窗格中拖动动画中的白色内圈，即可改变关键帧的时间。

::: warning 关键帧时间修改的局限
在动画调试面板修改关键帧时间后，样式面板（Styles）中对应的 `@keyframes` 百分比选择器并不会同步更新。该修改目前实用性有限，调整结果仍需手动写回样式表。
:::

## 浏览器插件调试工具

除了浏览器自带的调试工具，还可以借助浏览器插件调试动画。[Motion DevTools](https://chromewebstore.google.com/detail/motion-devtools/) 是由 [@motiondotdev](https://twitter.com/motiondotdev) 提供的 Chrome 浏览器插件：

> Motion DevTools：https://motion.dev/

安装该插件后，Chrome 的 Web 开发者工具会新增一个 "Motion" 选项，类似于动画调试（Animations）工具：可以录制元素的动画，调整动画的持续时间、延迟时间等。此外，Motion 调试工具还可以调整 `@keyframes` 中的缓动函数和相应属性的值，并支持将调整后的 CSS 代码导出——这几方面比 Chrome 自带的动画调试工具更强。

经常开发 Web 动画的场景下，Motion 调试工具能显著提升调试效率并获得调试后的代码。[Motion 官网](https://motion.dev/)提供了详细的操作文档。

## 其它动画的调试

现代 CSS 中除了 `transition` 和 `animation`，还提供了 `scroll()`、`view()`、`scroll-timeline`、`view-timeline` 等特性制作滚动驱动动效，以及 `::view-transition`、`::view-transition-group`、`::view-transition-old` 和 `::view-transition-new` 等特性制作视图过渡动效。这两类动画的调试方式有所不同。

### 调试视图过渡

视图过渡基于 CSS 动画构建，因此 Chrome 开发者工具的动画调试面板（Animations）适合用来调试 CSS 视图过渡动画：

> 测试案例：https://codepen.io/airen/full/MWLRWxG

使用动画面板可以暂停下一个动画，然后前后拖动动画；在此期间可以在"元素"面板中找到过渡伪元素：

> 视频来源：https://developer.chrome.com/static/docs/web-platform/view-transitions/video/CZmpGM8Eo1dFe0KNhEO9SGO8Ok23/DMH7qPqMszyVbTYOA2zd.mp4

目前使用动画调试面板调试视图过渡仍有不便之处：例如视图过渡动画即使停止播放，依旧会重新播放，这对查看 CSS 视图过渡中的伪元素造成一定困难，需要等待工具进一步优化。

### 调试滚动驱动动效

浏览器的动画调试面板目前无法调试滚动驱动动效。需要使用 [@bramus](https://twitter.com/bramus?ref_src=twsrc%5Etfw%7Ctwcamp%5Etweetembed%7Ctwterm%5E1701576910621311043%7Ctwgr%5E55f91c25c85d433f22255feadd126682b498cb63%7Ctwcon%5Es1_&ref_url=https%3A%2F%2Fwww.bram.us%2F2023%2F09%2F12%2Fscroll-driven-animations-debugger%2F) 提供的浏览器扩展插件 **[Scroll-Driven Animations Debugger](https://chromewebstore.google.com/detail/ojihehfngalmpghicjgbfdmloiifhoce)**。该插件会在 Chrome 开发者工具的元素面板（Elements）中添加一个名为 "Scroll-Driven Animations" 的新窗格。

使用方式：像通常一样检查一个元素，并选择 "Scroll-Driven Animations" 窗格。选中后将看到被检查元素上添加的滚动驱动动效的可视化效果——它是滚动器、动画元素的实时表示，使用 ViewTimeline 时还会追踪主体；文档滚动时可视化效果同步更新。

滚动进度时间轴动画的测试案例：

> 测试案例：https://codepen.io/airen/full/PoVgGbm

视图进度时间轴动画的测试案例：

> 测试案例：https://codepen.io/airen/full/jOdRxEa

顶部工具栏可在多个动画之间切换（如果有多个），或设置可视化效果的缩放因子。通常不需要设置缩放因子，可视化效果会自动适应可用空间。顶部工具栏还包括指示当前滚动时间轴类型的指示器，以及一些进度数字：总滚动进度、效果进度、实际滚动偏移量（以像素为单位）。

使用底部的 "Edit Values" 切换按钮可以打开范围编辑器。编辑器显示后，可视化效果还会显示开始和结束范围的指示器：ScrollTimeline 情况下是滚动器内容上的两条线：

> 测试案例：https://codepen.io/airen/full/BaMExoW

ViewTimeline 情况下是表示动画范围值的两个框。使用下拉菜单和（或）输入更改值。注意输入框不会实时更新（目前不支持）；更改后需点击输入框外的某处以更新值。

> 测试案例：https://codepen.io/airen/full/YzBMgQB

该工具的更多详细信息可[查看 Chrome Web Store 页面上的视频](https://youtu.be/r0sE2EtKV-c)。注意：无法通过 `iframes` 访问此工具，若想在 CodePen 中测试，必须在调试模式下进行。

有了该插件，滚动驱动动效的调试会容易得多。未来浏览器开发者工具有望内置该功能，从而消除插件的一些限制。

## 调整动画的缓动函数

缓动函数是 Web 动画的灵魂之一，应用是否妥当直接影响动画的最终效果。除了使用 cubic-bezier.com 等可视化工具创建所需的缓动函数外，浏览器开发者工具的样式面板（Styles）中也可以调整动画的缓动函数：

> URL：[cubic-bezier.com/](https://cubic-bezier.com/)

在样式面板中可以选择预置的缓动函数，也可以像 [cubic-bezier.com](https://cubic-bezier.com/) 一样可视化调整 `cubic-bezier()` 函数。

选择 `linear()` 函数时，通过点击曲线并在曲线上拖动即可轻松更新曲线：左键单击添加额外的点，双击移除；左侧还提供了一些预设值。

该调试功能对微调动画、找到合适的效果非常有用。

## 动画性能调试

除了调试动画的效果（持续时间、延迟时间、关键帧时间和缓动函数等），另一重要环节是通过开发者工具优化动画性能，使动画更流畅。动画的性能对动画的流畅度至关重要，现代浏览器的开发者工具提供了多种识别动画性能问题的工具。

### FPS 计量器

优化动画性能首先要启用 FPS 计量器。在浏览器开发者工具中，按下 `Command+Shift+P`（macOS）或 `Control+Shift+P`（Windows、Linux）打开命令菜单，输入 "Rendering" 并选择 "Show Rendering"，再勾选 FPS（Frame Rendering Stats）计量器复选框。

启用后，页面左上角会显示页面运行时 FPS 的实时估算。开发机器上动画可能以 `60FPS` 的流畅度运行，但性能较弱的设备上表现可能完全不同。

### 性能面板

Web 性能的调试和优化基本都在浏览器开发者工具的性能（Performance）窗格中进行。性能窗格可以模拟低端设备，例如选择六倍减速的 CPU，开发者工具会将 CPU 减慢到比平常慢六倍。

::: tip 测量建议
根据设备不同，六倍减速可能仍然很快，可以自定义减速倍数以确保对目标设备造成压力。测量性能时，请在隐身模式或访客模式下打开 Chrome——这些模式确保 Chrome 在干净状态下运行；已安装的扩展程序可能在性能测量中产生噪音。
:::

如果帧率较低或不流畅，性能面板可以帮助识别瓶颈。在性能面板中按 `Command+Shift+E` 开始分析并重新加载页面。

识别性能瓶颈的方法：在性能面板的 Timeline 视图中查找长时间任务，它们用红旗标记，单击后会在 Summary 选项卡中显示更多详细信息。

动画性能可能受 JavaScript 影响，因为样式、布局和绘制都发生在浏览器的主线程上，与 JavaScript 执行竞争。如果主线程忙于运行 JavaScript，动画可能变得缓慢和不流畅。与动画性能相关的任务显示为紫色（样式和布局）和绿色（绘制和合成）。

### 绘制闪烁

Chrome 开发者工具配备了可视化绘制过程的功能，帮助调试动画问题。先打开一个空白页（地址栏输入 `about:blank`），然后在开发者工具中启用 "Paint Flashing"（绘制闪烁）选项。

启用绘制闪烁后，页面加载时整个屏幕会闪烁为绿色，因为浏览器必须对所有内容进行绘制。页面渲染完毕后，页面内容的变化仍会触发绘制——每次绿色闪烁都表示浏览器需要在屏幕上重新绘制的区域。

> 测试地址：https://mihajlija.github.io/look/

布局和重新绘制在性能方面开销较大，可能导致页面变慢。如果启用了绘制闪烁后看到整个屏幕持续闪烁为绿色，或屏幕上出现了不应该被绘制的区域，就需要进一步排查。

### 图层面板

在图层（Layers）面板中可以以 3D 形式查看页面的图层。

可以缩放、旋转和拖动图层模型以探索其内容；悬停在图层上会显示其在页面上的当前位置；选中图层时，详情（Details）面板会显示其内存消耗和被提升为图层（合成）的原因。应保持图层数量相对较低，并关注内存消耗较大的图层。

关于运行时性能更详细的介绍，可阅读 Chrome 团队的博客《[分析运行时性能](https://developer.chrome.com/docs/devtools/performance)》。

## 小结

确保动画效果良好远不止于创建它。动画调试贯穿编辑、优化和反复调整的过程，是项目从简单的运动变成精心设计且性能良好的作品的关键环节。掌握浏览器动画调试面板的检查与修改能力、配套插件工具以及性能分析手段（FPS 计量器、性能面板、绘制闪烁、图层面板），可以更高效地处理和调试复杂动画，提升最终的用户体验。

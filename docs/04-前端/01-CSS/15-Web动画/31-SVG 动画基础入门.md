# SVG 动画基础入门

## 概念说明

数字时代设备种类繁多。面对不同和多样的屏幕尺寸、宽高比、分辨率和颜色设置时，最难实现的往往是在各个设备上获得一致的内容体验。实现一致性的解决方案之一是利用可缩放矢量图形（SVG）。具有 `.svg` 文件格式的图像尽管存在一些限制，却带来诸多优势，比如在不增加加载时间负担的同时为 Web 应用或网站创建视觉上引人入胜的外观。

SVG 在 Web 开发中已是重要组成部分：它具有矢量属性，放大或缩小时不损失质量；基于 XML 格式，可以压缩和优化；还可以轻松进行编辑、样式化、动画化和以编程方式更改。

SVG 本质上是一种标记语言。正如 CSS 和 JavaScript 可用于增强 HTML，它们同样可用于 SVG——为图形元素添加特色和装饰、添加交互，塑造令人愉悦和难忘的用户体验。可以使用 CSS 或 JavaScript 对 SVG 进行动画处理，在不依赖外部库的情况下创建动画效果。

## 什么是 SVG

SVG 是可缩放矢量图形（Scalable Vector Graphics）的缩写，是一种用于描述二维矢量图形的 XML（可扩展标记语言）标准，工作方式类似于 HTML。SVG 定义了不同的元素，用于表示可以在 XML 文本文件中组合的几何形状，从而生成二维图形。与位图图像（如 JPEG、PNG、GIF 等）不同，SVG 图形基于矢量，可以无损地缩放到任意大小而不失真。SVG 图形通常由图形元素（例如 `<polygon>`、`<ellipse>`、`<circle>`、`<rect>` 和 `<path>` 等）、文本（`<text>`）和其他可视化效果组成，可以通过文本编辑器进行创建和编辑。

SVG 的关键特点：

- **可缩放性**：基于矢量，SVG 图形可以无损地缩放到任意大小而不失真。
- **文本格式**：使用 XML 格式，纯文本、易于创建、编辑和理解，可嵌入到 HTML 文档中。
- **可编辑性**：可以通过文本编辑器或专业的图形编辑软件修改和编辑。
- **支持文本和图形混合**：允许在图形中嵌入文本，适合数据可视化、图表等场景。
- **图形元素丰富**：提供线条、圆形、矩形、路径等丰富元素，可创建各种复杂图形。
- **支持动画**：可通过 CSS 或 JavaScript 添加动画效果，使图形呈现生动的交互效果。
- **与 CSS 和 JavaScript 的集成**：可用 CSS 样式化，也可通过 JavaScript 实现更高级的交互和动态效果。
- **支持事件处理**：允许通过 JavaScript 添加事件处理器，实现与用户交互的功能。
- **广泛浏览器支持**：大多数现代浏览器都支持 SVG。
- **广泛用途**：常用于创建图标、图表、地图、动画等，特别是在响应式设计和可缩放图形场景中。

## 如何获取 SVG

Web 开发者可以通过几种不同方式获得 SVG，取决于需求和使用场景。

### 手动创建

最硬核的方式：使用文本编辑器手动创建 SVG 代码，编写或复制现有代码后保存为 `.svg` 格式文件。前提是对 SVG 知识有足够了解。可以使用 SVG 元素创建基本形状：

- `<circle>`：创建一个圆
- `<ellipse>`：创建一个椭圆
- `<line>`：创建一条直线
- `<polyline>`：创建一系列连接的直线
- `<polygon>`：创建一个多边形
- `<path>`：创建任意形状的路径

例如使用 `<ellipse>` 绘制一个椭圆：

```SVG
<ellipse cx="400" cy="300" rx="250" ry="150" />
```

`<path>` 是最多才多艺的 SVG 元素，可用于绘制任何可能的线条和形状，包括直线、连接线、曲线、多边形、矩形、圆形和椭圆形等。每个基本形状（`<circle>`、`<ellipse>`、`<rect>`、`<line>`、`<polyline>`、`<polygon>`）都可以用 `<path>` 元素来描述；更重要的是，有许多形状只能用 `<path>` 创建而无法用其他任何 SVG 元素创建，例如上面的心形。

`<path>` 包含很多命令，如三次贝塞尔曲线 `C`、移动 `M`、直线 `L`、二次贝塞尔曲线 `Q` 和弧线 `A` 等。可以通过 [@nandafyi 编写的在线工具](https://www.nan.fyi/svg-paths)进一步理解 `<path>` 元素上的各种命令：

> Tools URL：https://www.nan.fyi/svg-paths

通过命令绘制复杂图形对大多数 Web 开发者来说并不容易：除需要了解所有命令外，还涉及大量数学计算，成本高且容易出错。更好的方式是通过图形编辑软件（如 Sketch、Figma、Adobe Illustrator、Inkscape 等）中的钢笔工具或矢量工具绘制。

SVG 元素与 HTML 元素类似，可以添加很多属性，例如：

- `fill`：设置图形填充色
- `fill-opacity`：设置图形填充物的透明度
- `stroke`：设置图形轮廓的颜色
- `stroke-dasharray`：控制描边点划线的图案范式
- `stroke-dashoffset`：指定 `dash` 模式到路径开始的距离

### 优化 SVG 代码

SVG 元素可以像任何其他标记语言一样进行优化：缩小代码体积、删除不必要的格式和元素数据、删除不必要的属性和不可见元素等。这些优化可以根据技术栈自动完成。[SVGO](https://github.com/svg/svgo) 是最流行的 SVG 优化工具，可[轻松集成到几乎任何技术栈中](https://github.com/svg/svgo#other-ways-to-use-svgo)；若不想在工程环境中配置 SVGO，也可以使用 [@Jake Archibald 的 SVGOMG](https://jakearchibald.github.io/svgomg/) 对 SVG 代码进行在线优化。

> SVGOMG：https://jakearchibald.github.io/svgomg/

## SVG 动画

### 动画方式概览

SVG 动画涉及对 SVG 元素的不同方面进行动画处理，如形状、描边、填充和变换等。通过随时间操作这些属性，可以实现从简单过渡到复杂运动图形的各种效果。在 Web 中给 SVG 添加动画，常见方式主要有三种：

- **SMIL 动画**：利用 SVG 动画标准和 SMIL 动画语言，使用 `<animate>` 和 `<animateTransform>` 元素创建动画。
- **CSS 动画**：使用 CSS 的 `@keyframes` 和 `animation` 或 `transition` 属性动画化 SVG 的属性，如描边（`stroke`）、填充（`fill`）和变换（`transform`）等，这是同时兼容 HTML 和 SVG 元素的前沿方法。
- **WAAPI 动画**：类似于 CSS 动画，但通过 WAAPI 提供的相关 JavaScript API 来动画化 SVG 的属性。

[SVG 动画标准](https://www.w3.org/TR/SVG11/animate.html)和 [SMIL 动画语言](https://www.w3.org/TR/SMIL3/)提供了一种强大的方法赋予 SVG 元素生命：使用 `<animate>` 元素及 SMIL 语法定义动画属性及其值，允许精确控制时间和缓动函数，产生平滑而无缝的动画。但需要注意，SMIL 动画正在逐渐被淘汰，可能无法在所有浏览器中得到广泛支持。

CSS 动画（`transition` 和 `animation`）因对 SVG 元素的动画效果而广受欢迎，提供更灵活且广泛支持的方法：使用关键帧和各种 CSS 属性为 SVG 属性添加动画，更易与现有 CSS 集成，对动画效果的控制广泛，且可与 HTML 和 SVG 元素无缝配合。

WAAPI 提供了丰富的 API 来动画化 SVG 元素的属性，与 CSS 动画化 SVG 属性非常相似；不同之处在于 WAAPI 提供了更多控制动画的 API，且这些 API 源于浏览器动画引擎，在性能方面具有先天优势。

选择技术时了解各自优劣非常重要：

| 方式 | 优势 | 劣势 |
|---|---|---|
| SMIL | 提供精确的控制 | 浏览器支持有限 |
| CSS | 兼容性更广泛 | 控制动画播放方式有一定缺陷 |
| WAAPI | 更多制作和控制动画的 API，性能好 | 需要一定的 JavaScript 知识 |

SVG 动画特别适用于传达信息、说明概念或引导用户使用 Web 应用，例子包括形状之间的变形、通过动画路径创建复杂插图或信息图表、模拟弹跳或脉动元素，以及带动画按钮或交互元素的交互式界面。其优势还包括：

- **无限缩放不失真**：SVG 图形是矢量的，无论放大或缩小多少都能保持清晰，动画图形在任何设备上都表现良好。
- **文件小**：与其他图像格式相比 SVG 文件通常较小，加载更快，可以在不牺牲速度的情况下拥有酷炫的动画。
- **定制灵活**：可调整颜色、大小、时间和物体移动方式，创建独特的动画。
- **可访问性好**：与辅助技术配合良好；通过添加文本描述并正确管理焦点，SVG 动画使 Web 更具包容性。

### 使用 transition 进行动画

CSS 的 `transition` 可以对各种可动画化的属性创建动态视觉效果。通过 `transform`、`opacity` 和 `color` 等属性，可以将静态 SVG 转换为具有动态效果的 SVG。

以常见的"汉堡菜单图标"为例：这是一个微妙但有价值的动画，引起用户注意、提示该图标可用于关闭菜单。下面用 SVG 和 CSS `transition` 制作类似效果——用户鼠标悬浮（或点击）图标时，转变为关闭图标。

先从 SVG 结构开始，使用三个 SVG 的 `<rect>` 元素绘制"汉堡菜单图标"：第一个表示顶部条，第二个表示中间条，最后一个表示底部条：

```SVG

    <rect class="hamburger__middle"  x="0" y="20"  rx="4" ry="4" width="100%" height="8" />
    <rect class="hamburger__bottom"  x="0" y="40"  rx="4" ry="4" width="100%" height="8" />
</svg>
```

`viewBox` 属性建立坐标系统，提供默认的 `x`、`y`、`width` 和 `height`；设置 `width` 和 `height` 属性实现尺寸灵活性、解决 FOUC（无样式内容闪烁）；使用 `x` 和 `y` 坐标定位条形，`rx` 和 `ry` 给 `<rect>` 绘制圆角；条形使用 `100%` 宽度，并通过等间距的 `y` 坐标有策略地堆叠。

CSS 部分先定义自定义属性（图标大小和条形高度）：

```CSS
:root {
    --icon-size: 48;
    --icon-bar-size: 8;
}
```

正方形 SVG 的边长为 `64px`。关闭图标动画需将变换原点设置为顶部和底部条的中心，以避免对角线长度导致的故障。沿 `y` 轴平移条形以保持居中，确定所需的 `y` 轴平移距离并设置过渡持续时间：

```CSS
:root {
    --icon-size: 48;
    --icon-bar-size: 8;
    --icon-translation-size: calc((var(--icon-size) - var(--icon-bar-size)) / 2);
    --icon-transition-duration: 300ms;
  }
```

接下来配置过渡并将 `ease-in-out` 作为过渡函数应用于菜单条，以增强从内到外的过渡。变换原点设置为中心至关重要——需要为顶部和底部条的悬停状态设置 `transform-origin` 属性的值为 `center`：

```CSS
.icon--hamburger {
    rect {
        transition: all var(--icon-transition-duration) ease-in-out; 
    }
    
    &:hover {
        :is(.hamburger__top, .hamburger__bottom) {
            transform-origin: center; 
        }
    }
}
```

将顶部条（`.hamburger__top`）顺时针旋转 `45deg`，底部条（`.hamburger__bottom`）逆时针旋转 `45deg`；动画期间通过将中间条（`.hamburger__middle`）的不透明度（`opacity`）设为 `0` 隐藏它。这些变换可应用于 SVG 形状的悬停状态或可切换的类，简单起见使用悬停伪类：

```CSS
.icon--hamburger {
    &:hover {
        .hamburger__top {
            transform: rotate(45deg) translate(0, calc(var(--icon-translation-size) * 1px));
        }
        
        .hamburger__bottom {
            transform: rotate(-45deg) translate(0, calc(var(--icon-translation-size) * -1px));;
        }
        
        .hamburger__middle {
            opacity: 0;
        }
    }
}
```

在此基础上，还可以对 `<rect>` 元素的 `fill` 属性进行动画化：

```CSS
:root {
    --icon-color: #747d8c;
    --icon-active-color: #2ed573;
}

.icon--hamburger {
    color: var(--icon-color);
    
    rect {
        fill: currentColor
    }

    &:hover {
        rect {
            fill: var(--icon-active-color);
        }
    }
}
```

### 使用 animation 进行动画

除 `transition` 外，还可以使用 CSS 的 `@keyframes` 规则定义一系列关键帧，将 SVG 元素转换为引人入胜的动画。例如加载动画，用 SVG 和 CSS 一起创建相当简单。

使用 SVG 的 `<circle>` 元素绘制一个带透明填充和 `4px` 描边的圆，用 `cx` 和 `cy` 属性将其定位在 SVG 中心，并根据描边宽度（`stroke-width`）调整半径 `r`：

```SVG
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 48 48" width="64" height="64" class="spinner">
    <circle cx="24" cy="24" r="22" fill="transparent" stroke-width="4" />
</svg>
```

使用 CSS 关键帧将动画从 `0deg` 旋转到 `360deg`，创建完整旋转；应用线性缓动和无限循环，持续一秒：

```CSS
:root {
    --spinner-animation-speed: 1s;
}

@keyframes spin {
    from {
        rotate:0deg;
    }
    to {
      rotate:360deg;
    }
}

.spinner {
    animation: spin var(--spinner-animation-speed) linear infinite;
}
```

为增强动画效果，可使用 SVG 的 `linearGradient` 和 `stop` 元素引入渐变。在 `linearGradient` 元素中调整 `x1`、`x2`、`y1`、`y2`、`stop-color` 和 `stop-opacity` 等值，可以创建各种加载旋转器变体：

```SVG
<svg xmlns="http://www.w3.org/2000/svg" width="64" height="64" viewBox="0 0 48 48" class="spinner">
    <defs>
        <linearGradient id="gradientFade" x1="20%" x2="50%" y1="60%" y2="100%">
            <stop offset="0%" class="spinner-gradient-stop" />
            <stop offset="25%" stop-opacity="75%" class="spinner-gradient-stop" />
            <stop offset="50%" stop-opacity="50%" class="spinner-gradient-stop" />
            <stop offset="75%" stop-opacity="25%" class="spinner-gradient-stop" />
            <stop offset="100%" stop-opacity="5%" class="spinner-gradient-stop" />
        </linearGradient>
    </defs>
    <g>
        <circle cx="24" cy="24" r="22" fill="transparent" stroke="url(#gradientFade)" stroke-width="4" />
    </g>
</svg>
```

为每个 `<stop>` 元素设置一个类（如 `.spinner-gradient-stop`），以便 CSS 设置样式，例如覆盖 `<stop>` 元素的 `stop-color` 属性值。最终效果的 CSS 代码如下：

```CSS
@layer demo {
    :root {
        --spinner-animation-speed: 1s;
        --spinner-color: #8854d0;
    }

    @keyframes spin {
        from {
            rotate: 0deg;
        }
        to {
            rotate: 360deg;
        }
    }

  .spinner {
      fill: currentColor;

      animation: spin var(--spinner-animation-speed) linear infinite;

      .spinner-gradient-stop {
          stop-color: var(--spinner-color);
      } 
    }
}
```

### 使用 SMIL 进行动画

除 CSS 和 WAAPI 外，还可以使用 SMIL 对 SVG 进行动画处理，这也是创建动态和交互图形的绝佳方式之一。使用 SMIL 进行 SVG 动画时需要记住以下几点：

- SMIL 是 W3C 的推荐标准，允许 Web 开发者指定和控制 SVG 动画的精确时序。
- SVG 集成了 SMIL 动画规范中定义的动画特性。
- SMIL 允许对 SVG 元素的各种属性进行动画处理，如数字属性（`x` 和 `y` 等）、变换属性（`translate` 或 `rotate`）和颜色属性。
- 可以创建沿着运动路径或在 SVG 中定义的特定路径的动画。
- 使用 SMIL 进行 SVG 动画提供了可伸缩性、交互性和可访问性等多个优势。

使用 SMIL 的基本流程：定义 SVG 元素和属性，添加动画元素和属性以指定动画行为，设置动画的时间和持续时间，然后预览和测试。以下是几个使用 SMIL 对 SVG 元素进行动画处理的示例。

连续旋转的矩形（`<animateTransform>`）：

```SVG
<svg width="300" height="100">
    <rect x="0" y="0" width="300" height="100" stroke="black" stroke-width="1" />
    <rect x="0" y="50" width="15" height="34" fill="blue" stroke="black" stroke-width="1">
        <animateTransform attributeName="transform" begin="0s" dur="20s" type="rotate" from="0 60 60" to="360 100 60" repeatCount="indefinite" />
    </rect>
</svg>
```

第二个矩形元素被动画处理以连续旋转 `20` 秒。

循环变色的圆（`<animate>` 的 `values`）：

```SVG
<svg width="100" height="100">
    <circle cx="50" cy="50" r="40" fill="red">
        <animate attributeName="fill" values="red;blue;green;yellow;red" dur="5s" repeatCount="indefinite" />
    </circle>
</svg>
```

圆的填充颜色从红色变为蓝色、绿色、黄色，然后再次变为红色，整个过程持续 `5s`。

沿路径移动的矩形（`<animateMotion>` + `<mpath>`）：

```SVG
<svg width="300" height="300">
    <path id="path" d="M 50 50 L 250 50 L 250 250 L 50 250 L 50 50" stroke="black" fill="none" />
    <rect x="50" y="50" width="50" height="50" fill="blue">
        <animateMotion dur="5s" repeatCount="indefinite">
            <mpath xlink:href="#path" />
        </animateMotion>
    </rect>
</svg>
```

矩形沿着由 `<path>` 元素定义的路径移动，整个过程持续 `5s`。

不断变形的多边形（`<animate>` 的 `points`）：

```SVG
<svg width="100" height="100">
    <polygon points="50,10 70,90 10,40" fill="red">
        <animate attributeName="points" dur="5s" repeatCount="indefinite" values="50,10 70,90 10,40; 10,10 90,10 50,90; 50,10 70,90 10,40" />
    </polygon>
</svg>
```

多边形在不断变换三角形形状，整个过程持续 `5s`。

以上仅是 SMIL 动画最基础的部分。动画 SVG 元素时会用到 `<animate>`、`<animateMotion>` 和 `<animateTransform>` 等元素。以 `<animate>` 元素为例，使用时需注意：

- `<animate>` 元素可以在一定时间内逐渐动画化特定的 SVG 属性。
- 使用 `attributeName` 属性指定要动画化的属性，例如动画化圆的位置使用 `attributeName="cx"` 和 `attributeName="cy"`。
- `values` 属性定义动画期间属性的值，例如将矩形填充颜色从红色动画到蓝色再到绿色使用 `values="red;blue;green"`。
- `dur` 属性确定动画的持续时间，例如 `5s` 的动画使用 `dur="5s"`。
- `repeatCount` 属性决定动画重复的次数，无限重复使用 `repeatCount="indefinite"`。

例如使用 `<animate>` 元素动画圆的位置，圆在两个位置之间来回移动：

```SVG
<svg width="400" height="400" class="animated">
    <circle cx="200" cy="200" r="40" fill="oklch(0.77 0.24 152.51)">
        <animate attributeName="cx" values="200;300;200" dur="2s" repeatCount="indefinite" />
        <animate attributeName="cy" values="200;100;200" dur="2s" repeatCount="indefinite" />
  </circle>
</svg>
```

> Demo 地址：https://codepen.io/airen/full/abMPNEz

在使用 `<animate>` 元素为 SVG 元素添加动画时，时序属性在控制动画行为方面发挥着至关重要的作用：

- **`begin`**：确定动画何时开始，可指定特定时间、几秒钟或事件触发器。例如 `begin="0s"` 立即启动动画，`begin="click"` 在用户点击 SVG 元素时开始。
- **`dur`**：设置动画的持续时间，可使用秒或毫秒。例如 `dur="5s"` 表示动画持续 `5s`。
- **`repeatCount`**：控制动画播放的重复次数，可指定具体数字或 `"indefinite"`（无限重复）。例如 `repeatCount="3"` 表示重复三次。
- **`repeatDur`**：确定动画的总持续时间（包括所有重复），可使用秒或毫秒。例如 `repeatDur="20s"` 表示包括重复在内持续 `20s`。
- **`end`**：设置动画的结束时间，可使用特定时间、几秒钟或事件触发器。例如 `end="10s"` 表示 `10` 秒后结束动画。

通过尝试不同的时序值，可以创建独特而引人入胜的动画。

## 小结

SVG（Scalable Vector Graphics）动画的基础在于一种基于 XML 的图形格式，具有可伸缩性和灵活性。学习 SVG 动画首先需要熟悉 SVG 基础知识，包括 `<rect>`、`<circle>`、`<line>` 和 `<path>` 等常见元素；SVG 元素通过文本编辑器或图形编辑软件创建，形成二维图形和图形应用。

动画可以通过 CSS 和 JavaScript 实现：CSS 动画利用 `@keyframes` 规则和 `animation` 属性定义动画序列，过渡效果通过 `transition` 属性实现平滑属性值变化；JavaScript 动画使用 WAAPI 相关 API 或 SVG 的 DOM API，通过修改属性值实现更灵活的动画逻辑。SMIL 则提供了一种声明性的动画方法，允许使用 XML 语法定义动画，对时间和同步性具有精确控制，产生平滑而同步的动画效果。

优化 SVG 动画时，可以选择合适的动画类型，避免过多或不必要的动画效果，并使用 SVGO 等工具优化 SVG 文件。SVG 动画可应用于网页图形、数据可视化和用户界面等场景，为在 Web 上创建引人入胜的图形提供了全新的可能性。

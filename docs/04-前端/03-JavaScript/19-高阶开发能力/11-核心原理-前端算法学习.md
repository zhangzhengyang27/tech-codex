# 数据结构的存储方式

## 概念说明

算法题目是技术面试中的常见题目，但很多开发者由于工作繁忙没有时间刷题，或因知识点太多而无从下手；非计算机专业出身的前端开发者也可能没有系统学习过数据结构与算法，不清楚哪些需要掌握。本文的目标是提供一条数据结构与算法学习的思路：先理解数据结构的存储方式、用 JavaScript 实现常见数据结构，再总结算法题的通用解题方法，提升学习效率。

## 数据结构的存储方式

**数据结构的存储方式只有两种：数组（顺序存储）和链表（链式存储）**。根据这两种分类，可以分别考察几个数据结构的 JavaScript 代码描述方式。

### 顺序存储

栈是比较典型的顺序存储方式，用 JS 实现的代码如下：

```javascript
class Stack {
  constructor() {
    this.items = []
  }
  
  push(element) {
    this.items.push(element)
  }
  pop() {
    return this.items.pop()
  }
  get size() {
    return this.items.length
  }
  get isEmpty() {
    return !this.items.length
  }
  clear() {
    this.items = []
  }
  print() {
    console.log(this.items.toString())
  }
}
// 初始化一个栈
var s = new Stack()
s.push(1)
s.push(2)
s.push(3)
s.push(4)
console.log(s)
console.log(s.isEmpty)
console.log(s.size)
```

通过 ES6 的 `class` 语法描述非常简洁、容易理解。类似的队列用 JavaScript 描述如下：

```javascript
class Queue {
  constructor() {
    this.items = []
  }
  enqueue(element) {
    this.items.push(element)
  }
  shift() {
    return this.items.shift()
  }
  get size() {
    return this.items.length
  }
  get isEmpty() {
    return !this.items.length
  }
  clear() {
    this.items = []
  }
  print() {
    console.log(this.items.toString())
  }
}
// 初始化一个队列
var s = new Queue()
s.enqueue(1)
s.enqueue(2)
s.enqueue(3)
s.enqueue(4)
console.log(s)
console.log(s.isEmpty)
console.log(s.size)
```

从这两种数据结构的实现方式可以看出：队列和栈都是顺序存储结构，用数组来模拟实现，两者唯一的区别在于一个是先进后出，另一个是先进先出。

这两个数据结构模拟起来都比较简单。较为复杂的链式存储，以及二叉树和链表等，则是另一种描述方式。

### 链式存储

链表是链式存储最典型的例子，其最基本的 JS 实现逻辑如下：

```javascript
class Node {
  constructor(element) {
    this.element = element
    this.next = null
  }
}
class LinkedList {
  constructor() {
    this.head = null
    this.length = 0
  }
  append(element) {
    const node = new Node(element)
    let current = null
    if (this.head == null) {
      this.head = node
    } else {
      current = this.head
      while (current.next) {
        current = current.next
      }
      current.next = node
    }
    this.length++
  }
  insert(position, element) {
    if (position < 0 || position > this.length) {
       return false
    } else {
      const node = new Node(element)
      let current = this.head
      let previous = null
      let index = 0
      if (position === 0) {
        this.head = node
        node.next = current
      } else {
        while (index++ < position) {
          previous = current
          current = current.next
        }
        node.next = current
        previous.next = node
      }
      this.length++
      return true
    }
  }
  
  removeAt(position) {
    if (position < 0 || position > this.length) {
      return false
    } else {
      let current = this.head
      let previous = null
      let index = 0
      if (position === 0) {
        this.head = current.next
      } else {
        while (index++ < position) {
          previous = current
          current = current.next
        }
        previous.next = current.next
      }
      this.length--
      return true
    }
  }
  findIndex(element) {
    let current = this.head
    let index = -1
    while (current) {
      if (current.element === element) {
        return index + 1
      }
      index++
      current = current.next
    }
    return -1
  }
  remove(element) {
    const index = this.findIndex(element)
    return this.removeAt(index)
  }
  get size() {
    return this.length
  }
  get isEmpty() {
    return !this.length
  }
  toString() {
    let current = this.head
    let slink = ''
    while (current) {
      slink += `${current.element}-`
      current = current.next
    }
    return slink
  }
}
// 初始化一个链表
var s = new LinkedList()
s.append(1)
s.append(2)
s.append(3)
s.append(4)
console.log(s)
console.log(s.isEmpty)
console.log(s.size)
```

这段代码用 ES6 简明的语法实现了链表的数据结构；基本了解链表的思路后，理解这段代码并不困难。

再来看稍微复杂一些的二叉树的 JS 代码描述：

```javascript
class Node {
  constructor(element) {
    this.element = element
    this.left = null
    this.right = null
  }
}
class BinarySearchTree {
  constructor() {
    this.root = null
  }
  insert(element) {
    const temp = new Node(element)
    var insertNode = function(root, node) {
      if (node.element > root.element) {
        if (root.right === null) {
          root.right = node
        } else {
          insertNode(root.right, node)
        }
      } else {
        if (root.left === null) {
          root.left = node
        } else {
          insertNode(root.left, node)
        }
      }
    }
    if (!this.root) {
      this.root = temp
    } else {
      insertNode(this.root, temp)
    }
  }
  // 中序遍历
  inOrderTraverse(callback) {
    const inOrderTraverseNode = (node, callback) => {
      if (node !== null) {
        inOrderTraverseNode(node.left, callback)
        callback(node.element)
        inOrderTraverseNode(node.right, callback)
      }
    }
    inOrderTraverseNode(this.root, callback)
  }
  // 前序遍历
  preOrderTraverse(callback) {
    const preOrderTraverseNode = (node, callback) => {
      if (node !== null) {
        callback(node.element)
        preOrderTraverseNode(node.left, callback)
        preOrderTraverseNode(node.right, callback)
      }
    }
    preOrderTraverseNode(this.root, callback)
  }
  // 后序遍历
  postOrderTraverse(callback) {
    const postOrderTraverseNode = (node, callback) => {
      if (node !== null) {
        postOrderTraverseNode(node.left, callback)
        postOrderTraverseNode(node.right, callback)
        callback(node.element)
      }
    }
    postOrderTraverseNode(this.root, callback)
  }
  min() {
    const minNode = node => {
      return node ? (node.left ? minNode(node.left) : node) : null
    }
    return minNode(this.root)
  }
  max() {
    const maxNode = node => {
      return node ? (node.right ? maxNode(node.right) : node) : null
    }
    return maxNode(this.root)
  }
  search(key) {
    const searchNode = (node, key) => {
      if (node === null) return
      if (node.element === key) {
        console.log(node)
        return node
      } else {
        return searchNode((key < node.element) ? node.left : node.right, key)
      }
    }
    searchNode(this.root, key)
  }
}
// 初始化一个BST
const tree = new BinarySearchTree()
tree.insert(11)
tree.insert(7)
tree.insert(5)
tree.insert(3)
tree.insert(9)
tree.insert(8)
tree.insert(10)
tree.insert(13)
tree.insert(12)
tree.insert(14)
tree.insert(20)
tree.insert(18)
tree.insert(25)
console.log(tree)
// 调用二叉树对应地获取最大最小，以及搜索的方法
var m = tree.min()
console.log(m.element)
var max = tree.max()
console.log(max)
var r = tree.search(12)
console.log(r)
```

二叉树比栈、队列以及链表要复杂一些。但仔细看二叉树的核心实现逻辑会发现：不管是前、中、后序遍历，还是获取最值以及查找，本质上都依赖算法中一个重要的思想——递归。递归通过调用自身的方法不断地往下遍历，这是二叉树相关题目比较重要的一个思路，掌握它有助于轻松解决一系列二叉树相关的算法题目。

## 算法刷题指南

首先要明确的是：数据结构是工具，**算法是通过合适的工具解决特定问题的方法**。学习算法之前，最起码得了解常用的数据结构，知道它们的特性和缺陷。

关于如何在 LeetCode 刷题：在熟悉基本数据结构、并能轻松用 JS 实现常见数据结构之后，就可以开始刷题。LeetCode 刷题也有套路——在数据结构基本了解并能实现的基础上，可以先直接刷二叉树相关的题目，因为这块比较容易抽象出通用的思路（见下文的递归解题模板）。

总结下来，算法刷题的核心是找到这几类题目的解题思路：

- If-else, switch（branch）
- for，while loop（Iteration）
- 递归 Recursion（Divide, Backtrace）
- 搜索 Search：深度优先搜索（Depth first search）、广度优先搜索（Breadth first search）、A* 等
- 动态规划（Dynamic Programming）
- 二分查找（Binary Search）
- 贪心算法（Greedy）
- 数学（Math）& 位运算等

上面提到的二叉树相关的实现思路以及相关题目，属于第三类递归的思路；把递归的思路掌握好，二叉树相关的题目就会得心应手。动态规划也类似，核心思路是动态递推：从最小的开始计算，一步一步推导累加到第 n 次之后的结果。

## 二叉树类题目的递归解题模板

在看二叉树相关题目之前，需要对前文的 JS 实现二叉树的代码非常了解，尤其是前、中、后序遍历的过程，以及递归找二叉树最值的思路。有了这些基础之后，可以通过 LeetCode 的几个例子看看如何用递归思路解决二叉树的一系列问题，类似的题目如下：

- 94 题：二叉树的中序遍历
- 102 题：二叉树的层序遍历
- 103 题：二叉树的锯齿形层序遍历
- 104 题：二叉树的最大深度
- 144 题：二叉树的前序遍历
- 199 题：二叉树的右视图

类似题目还有很多，下面以这六道题为例说明如何击破。

把这六道题目抽象起来，形成的思路以及代码模板大致如下：

```javascript
// root为传入的二叉树
var XXXTraversal = function(root) {
    // 定义一个返回的遍历结果的组数
    let res = []
    // 定义一个内部需要不断递归的函数
    function traverse(r) {
        if(!r) return;
        traverse(r.left);  // 递归遍历左子树
        res.push(r.val);    // 将根节点push进待返回的数组
        traverse(r.right);  // 递归遍历右子树
    }
    traverse(root);    // 循环遍历
    return res;      // 最后返回
};
```

根据这个基本模板，可以衍生出上述几道题的答案：只需调整第 8、9、10 行代码的位置，二叉树的前、中、后序遍历的题目就迎刃而解。对于层序遍历，只需稍加改造即可通过 LeetCode 的编译：

```javascript
var levelOrder = function(root) {
    let arr =[];
    function traverse(root, depth) {
        if(root === null) return [];
        if(arr[depth] === undefined) { // 改造外面定义的待返回的数组变成二维
            arr[depth] = [];
        }
        arr[depth].push(root.val);    // 最先把根节点 push 进去
        traverse(root.left, depth + 1);  // 层数+1对应arr里的二维数组的序号 
        traverse(root.right, depth + 1); // 同上
    }
    traverse(root, 0);
    return arr;
};
/*
  通过测试得到的返回结果是一个二维数组：[[3],[9,20],[15,7]] 
*/
```

第 102 道题的答案由此得出。再看第 199 题，如何用递归实现二叉树的右视图？这道题是前序遍历的变形：先访问根节点，再递归右子树、最后递归左子树，并在"层数等于结果数组长度"时才存入节点——这样每层最先被访问到的恰好是最右侧的节点。

基于层序遍历改造之后，实现第 199 题的代码逻辑如下：

```javascript
var rightSideView = function(root) {
    var arr = [];
    function traverse(root, depth) {
        if(root === null) return;
        if(depth === arr.length) {  // 这加了逻辑拦截，只能push一个右节点
            arr.push(root.val);
        }
        depth++;    // 和层序遍历每进入一层 depth 加一逻辑基本一致
        traverse(root.right, depth);  // 先进入右子树遍历，上面的if拦截
        traverse(root.left, depth);  // 遍历的时候左子树已经存不进arr数组了
    }
    traverse(root, 0);
    return arr;
};
```

通过上面几道二叉树遍历的题目，可以总结出这一系列题目的解题思路：其核心都是用递归的思路解决二叉树的遍历问题，只不过通过调整遍历的顺序以及存储数据的方式，把最后遍历的节点数字存储到对应的返回数组中，最终通过代码变化得到想要的效果。

类似的题目也就能迎刃而解。二叉树是应用递归思路最多的例子；除此之外，动态规划的刷题思路也类似——找到一两道动态规划比较典型的题目，总结和抽象出通用的解题思路，之后就可以更容易地解决类似的题目。

## 小结

- 数据结构的存储方式只有两种：数组（顺序存储）和链表（链式存储）；栈、队列、链表、二叉树都可以用这两种方式以 JavaScript 实现。
- 数据结构是工具，算法是通过合适的工具解决特定问题的方法；学习算法前应先掌握常用数据结构的特性与缺陷。
- 算法刷题的核心是按题型（分支、迭代、递归、搜索、动态规划、二分查找、贪心、数学与位运算）抽象出通用解题思路，而不是逐题死记。
- 二叉树类题目是练习递归思想的最佳入口：掌握遍历模板后，通过调整遍历顺序和结果存储方式即可解决前/中/后序遍历、层序遍历、右视图等一系列题目。

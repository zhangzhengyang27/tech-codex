# TypeScript 发展历史

目前在一线公司和一些高级团队中都开始采用 Vue + TS 或 React + TS 的开发形式，这也逐渐成为趋势。

## 版本演进脉络

| 时间 | 事件 |
| --- | --- |
| 2010 年 | 在微软公司内部开始使用 |
| 2012 年 10 月 | 对外公开发布首个预览版 TypeScript 0.8 |
| 2013 年 6 月 | 发布 TypeScript 0.9（预览阶段） |
| 2014 年 4 月 | TS 1.0.0 正式上线 |
| 2016 年 9 月 | 发布 TS 2.0.0 |
| 2018 年 7 月 | 发布 TS 3.0.0 |
| 2020 年 8 月 | 发布 TS 4.0.0 |
| 2023 年 3 月 | 发布 TS 5.0.0 |

## 演进特点

在这些大版本发布的过程中，并没有太大革命性的改进，基本都是不断优化与升级。这也是 TypeScript 本身语言特点导致的——知识点比较零散，语法之间并没有太多联系。

实践上从 TS 4 开始使用即可，不用太关心之前版本的情况。截至 2026 年 9 月，TypeScript 稳定版已迭代至 5.9.x，新项目直接采用 5.x 即可。

## 对 JavaScript 的影响

TypeScript 已经成为目前前端开发中首选的语言之一。TS 团队已经向 ECMA 组织发出修改意见，希望 JS 中能够支持静态类型检查，并且已经到了提案阶段。

未来的趋势是 JavaScript 越来越趋近于 TypeScript，TS 的影响力将继续扩大。关于 TypeScript 与 ECMAScript 的关系、TC39 提案流程，详见 [TypeScript 与 ECMAScript](../06-高级专题/01-TypeScript%20与%20ECMAScript.md)。

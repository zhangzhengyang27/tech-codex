# 组合多选框组件

## 概念说明

组合多选框 Checkbox 是一个基础表单组件，可以集成在数据校验组件 Form 内并应用其校验规则。组件由 CheckboxGroup 与 Checkbox 两部分组成，覆盖"单独使用"与"组合使用"两种场景。

## 组件概览

多选框组件由两个组件组成：CheckboxGroup 和 Checkbox。单独使用时只需要一个 Checkbox，组合使用时两者都要用到。效果如下图所示：


![](https://user-gold-cdn.xitu.io/2018/11/2/166d39853b7facd8?w=562&h=334&f=png&s=29035)

单独使用常见的场景是注册时勾选以同意注册条款：只有一个独立的 Checkbox 组件，并且绑定一个布尔值，示例如下：

```html
<template>
  <i-checkbox v-model="single">单独选项</i-checkbox>
</template>
<script>
  export default {
    data () {
      return {
        single: false
      }
    }
  }
</script>
```

组合使用的场景更多，填写表单时经常用到，其结构如下：

```html
<template>
  <i-checkbox-group v-model="multiple">
    <i-checkbox label="option1">选项 1</i-checkbox>
    <i-checkbox label="option2">选项 2</i-checkbox>
    <i-checkbox label="option3">选项 3</i-checkbox>
    <i-checkbox label="option4">选项 4</i-checkbox>
  </i-checkbox-group>
</template>
<script>
  export default {
    data () {
      return {
        multiple: ['option1', 'option3']
      }
    }
  }
</script>
```

`v-model` 用在了 CheckboxGroup 上，绑定的值为一个数组，数组的值就是内部 Checkbox 绑定的 label。

用法看起来比 Form 简单，但有两个技术难点：

- Checkbox 要同时支持单独使用和组合使用的场景；
- CheckboxGroup 和 Checkbox 内可能嵌套其它的布局组件。

对于第一点，要在 Checkbox 初始化时判断父级是否有 CheckboxGroup：有则为组合使用，否则为单独使用。第二点属于跨层级组件通信问题，借助 `findComponentUpward` / `findComponentsDownward` 这类通信方法即可解决。

两个组件并行开发容易理不清逻辑，因此先开发独立的 Checkbox 组件。

## 单独使用的 Checkbox

### API 设计

组件设计从它的 3 个 API 入手：prop、event、slot。

由于要在 Checkbox 组件上直接使用 `v-model` 双向绑定数据，必不可少的 prop 是 `value`，对应的 event 是 `input`——v-model 本质上是一个语法糖（参见 [Vue.js 文档的表单输入绑定](https://cn.vuejs.org/v2/guide/forms.html)）。

理论上只需将 `value` 限定为布尔值即可，也就是 true / false；不过为了扩展性，额外定义两个 props：`trueValue` 和 `falseValue`，允许使用者指定 `value` 用什么值来判断是否选中。实际开发中，数据库往往不直接保存 true / false，而是 1 / 0 或其它字符串，如果强制使用 Boolean，使用者就要额外转换一次，这样的 API 设计不太友好。

除此之外，还需要一个 `disabled` 属性来表示是否禁用。

自定义事件有两个：`input` 用于实现 v-model 语法糖；`on-change` 在选中 / 取消选中时触发，用于通知父级状态发生了变化。

slot 使用默认插槽，用于显示辅助文本。

### 实现 v-model

理清 API 后，先实现基础的 `v-model` 功能，这在大部分组件中都类似。

在 `src/components` 下新建目录 `checkbox`，并新建两个文件 `checkbox.vue` 和 `checkbox-group.vue`。先看 Checkbox：

```html
<!-- checkbox.vue -->
<template>
  <label>
    <span>
      <input
             type="checkbox"
             :disabled="disabled"
             :checked="currentValue"
             @change="change">
    </span>
    <slot></slot>
  </label>
</template>
<script>
  export default {
    name: 'iCheckbox',
    props: {
      disabled: {
        type: Boolean,
        default: false
      },
      value: {
        type: [String, Number, Boolean],
        default: false
      },
      trueValue: {
        type: [String, Number, Boolean],
        default: true
      },
      falseValue: {
        type: [String, Number, Boolean],
        default: false
      }
    },
    data () {
      return {
        currentValue: this.value
      };
    },
    methods: {
      change (event) {
        if (this.disabled) {
          return false;
        }

        const checked = event.target.checked;
        this.currentValue = checked;

        const value = checked ? this.trueValue : this.falseValue;
        this.$emit('input', value);
        this.$emit('on-change', value);
      }
    }
  }
</script>
```

因为 `value` 被定义为 prop，它只能由父级修改，组件本身不能修改它；`<input>` 触发 change 事件（即点击选择）时，Checkbox 不能直接修改 value。因此在 data 里定义了一个 `currentValue`，并把它绑定在 `<input :checked="currentValue">` 上，这样 Checkbox 内部就可以修改 `currentValue`。这是自定义组件使用 `v-model` 的惯用手法。

代码不复杂，但有三个细节需要额外说明：

1. 选中的控件直接使用了 `<input type="checkbox">`，而没有用 div + css 来自行实现选择的逻辑和样式。好处是：使用 input 元素，自定义组件仍然是 HTML 内置的基础组件，可以使用浏览器默认的行为和快捷键——浏览器知道这是一个选择框；换成 div + css，浏览器则无法识别。原生 input 的样式可以用 CSS 美化，但这不属于实现要点。
2. `<input>`、`<slot>` 都包裹在一个 `<label>` 元素内。好处是点击 `<slot>` 里的文字时，`<input>` 选框也会被触发；否则只有点击选框本身才会触发，不容易选中，影响用户体验。
3. `currentValue` 仍然是布尔值（true / false），因为它是组件 Checkbox 内部使用的，使用者无需关心；而 value 可以是 String、Number 或 Boolean，取决于 `trueValue` 和 `falseValue` 的定义。

### 由外向内的同步

目前实现的 `v-model` 只是"由内而外"的：通过点击 `<input>` 选择，会通知到使用者；但使用者手动修改 prop `value` 时，Checkbox 没有做响应。继续补充代码：

```html
<!-- checkbox.vue，部分代码省略 -->
<script>
  export default {
    watch: {
      value (val) {
        if (val === this.trueValue || val === this.falseValue) {
          this.updateModel();
        } else {
          throw 'Value should be trueValue or falseValue.';
        }
      }
    },
    methods: {
      updateModel () {
        this.currentValue = this.value === this.trueValue;
      }
    }
  }
</script>
```

这里对 prop `value` 使用 watch 进行了监听：父级修改它时，会调用 `updateModel` 方法，同步修改内部的 `currentValue`。不过父级并非能修改为任意值，所以用 if 条件判断父级修改的值是否符合 trueValue / falseValue 所设置的，否则抛错。

Checkbox 也是基础的表单类组件，完全可以集成到 Form 里。因此在 change 事件触发时，通过 Emitter 向 Form 派发一个事件，从而配合 Form 组件完成数据校验：

```html
<!-- checkbox.vue，部分代码省略 -->
<script>
  import Emitter from '../../mixins/emitter.js';

  export default {
    mixins: [ Emitter ],
    methods: {
      change (event) {
        // ... 
        this.$emit('input', value);
        this.$emit('on-change', value);
        this.dispatch('iFormItem', 'on-form-change', value);
      }
    },
  }
</script>
```

至此，Checkbox 已经可以单独使用，并支持 Form 的数据校验。下面来看组合使用。

### 组合使用的 CheckboxGroup

> 友情提示：请先阅读 Vue.js 文档的 [https://cn.vuejs.org/v2/guide/forms.html#复选框](https://cn.vuejs.org/v2/guide/forms.html#复选框) 内容。

CheckboxGroup 的 API 很简单：

- props：`value`，与 Checkbox 的类似，用于 v-model 双向绑定数据，格式为数组；
- events：`on-change`，同 Checkbox；
- slots：默认，用于放置 Checkbox。

使用了 CheckboxGroup 就代表组合使用多选框，而非单独使用；两种模式只能用其一，判断的依据就是是否用了 CheckboxGroup 组件。所以在 Checkbox 组件内，用 `findComponentUpward` 方法判断父组件是否有 `CheckboxGroup`：

```html
<!-- checkbox.vue，部分代码省略 -->
<template>
  <label>
    <span>
      <input
             v-if="group"
             type="checkbox"
             :disabled="disabled"
             :value="label"
             v-model="model"
             @change="change">
      <input
             v-else
             type="checkbox"
             :disabled="disabled"
             :checked="currentValue"
             @change="change">
    </span>
    <slot></slot>
  </label>
</template>
<script>
  import { findComponentUpward } from '../../utils/assist.js';

  export default {
    name: 'iCheckbox',
    props: {
      label: {
        type: [String, Number, Boolean]
      }
    },
    data () {
      return {
        model: [],
        group: false,
        parent: null
      };
    },
    mounted () {
      this.parent = findComponentUpward(this, 'iCheckboxGroup');

      if (this.parent) {
        this.group = true;
      }

      if (this.group) {
        this.parent.updateModel(true);
      } else {
        this.updateModel();
      }
    },
  }
</script>
```

在 mounted 时，通过 findComponentUpward 方法判断父级是否有 CheckboxGroup 组件：如果有，就将 `group` 置为 true，并触发 CheckboxGroup 的 `updateModel` 方法（作用见下文）。

在 template 里写了两个 `<input>` 来区分是否是 group 模式。Checkbox 的 data 里新增的 `model` 数据，其实就是父级 CheckboxGroup 的 `value`，会在下文的 `updateModel` 方法里赋给 Checkbox。

Checkbox 新增的 prop `label` 只会在组合使用时有效，结合 `model` 来使用，用法已在 Vue.js 文档中介绍：[https://cn.vuejs.org/v2/guide/forms.html#复选框](https://cn.vuejs.org/v2/guide/forms.html#复选框)。

在组合模式下，Checkbox 选中时不再对 Form 派发事件，而应改在 CheckboxGroup 中派发。对 Checkbox 做最后的修改：

```html
<!-- checkbox.vue，部分代码省略 -->
<script>
  export default {
    methods: {
      change (event) {
        if (this.disabled) {
          return false;
        }

        const checked = event.target.checked;
        this.currentValue = checked;

        const value = checked ? this.trueValue : this.falseValue;
        this.$emit('input', value);

        if (this.group) {
          this.parent.change(this.model);
        } else {
          this.$emit('on-change', value);
          this.dispatch('iFormItem', 'on-form-change', value);
        }
      },
      updateModel () {
        this.currentValue = this.value === this.trueValue;
      },
    },
  }
</script>
```

剩余的工作就是完成 checkbox-group.vue 文件：

```html
<!-- checkbox-group.vue -->
<template>
  <div>
    <slot></slot>
  </div>
</template>
<script>
  import { findComponentsDownward } from '../../utils/assist.js';
  import Emitter from '../../mixins/emitter.js';

  export default {
    name: 'iCheckboxGroup',
    mixins: [ Emitter ],
    props: {
      value: {
        type: Array,
        default () {
          return [];
        }
      }
    },
    data () {
      return {
        currentValue: this.value,
        childrens: []
      };
    },
    methods: {
      updateModel (update) {
        this.childrens = findComponentsDownward(this, 'iCheckbox');
        if (this.childrens) {
          const { value } = this;
          this.childrens.forEach(child => {
            child.model = value;

            if (update) {
              child.currentValue = value.indexOf(child.label) >= 0;
              child.group = true;
            }
          });
        }
      },
      change (data) {
        this.currentValue = data;
        this.$emit('input', data);
        this.$emit('on-change', data);
        this.dispatch('iFormItem', 'on-form-change', data);
      }
    },
    mounted () {
      this.updateModel(true);
    },
    watch: {
      value () {
        this.updateModel(true);
      }
    }
  };
</script>

```

### updateModel 的调用链

代码容易理解，需要介绍的是 `updateModel` 方法。一共有 3 处调用了 `updateModel`：两处是 CheckboxGroup 的 mounted 初始化和 watch 监听 value 变化时调用；另一处是在 Checkbox 的 mounted 初始化时调用。这个方法的作用是在 CheckboxGroup 里通过 `findComponentsDownward` 方法找到所有的 Checkbox，然后把 CheckboxGroup 的 `value` 赋值给 Checkbox 的 `model`，并根据 Checkbox 的 `label` 设置一次当前 Checkbox 的选中状态。这样无论是由内而外选择，还是由外向内修改数据，都是双向绑定的，而且支持动态增加 Checkbox 的数量。

## 实践要点

- 自定义组件实现 `v-model` 时，prop `value` 不可在组件内直接修改，应在 `data` 中维护 `currentValue`，并用 watch 监听 prop 同步。
- 组合 / 单独两种模式的判定放在子组件 mounted 阶段完成，对使用者保持 API 透明。
- 延伸练习一：将 CheckboxGroup 和 Checkbox 组件集成在 Form 里，完成一个数据校验的示例。
- 延伸练习二：参考本文代码，实现一个单选组件 Radio 和 RadioGroup。

## 小结

组合多选框组件由 Checkbox 与 CheckboxGroup 两个组件构成。核心机制：Checkbox 在 mounted 阶段通过 `findComponentUpward` 判断父级是否存在 CheckboxGroup，从而区分单独 / 组合两种模式；组合模式下由 CheckboxGroup 通过数组 `value` 统一收集选中项，并经 `updateModel` 向下同步；单独模式下 Checkbox 通过 Emitter 向 Form 派发校验事件。该设计保证了两种使用方式下双向绑定的一致性，并支持动态增减子项。

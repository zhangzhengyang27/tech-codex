# 自研组件库导览

> 本目录是**独立实战课程**:以一个 Vue3 + Element-Plus 后台项目为载体,从需求规划一路做到自研组件库拆分、构建发布与桌面端交付,共 155 篇。
> 本篇是全目录的定位声明与总索引,正文 155 篇保持原课程体,不拆分、不改写。

## 一、课程定位

- **课程性质**:组件库实战课程(项目驱动)。目标不是罗列 API,而是沿着真实项目的演进过程,沉淀出一套可复用的后台组件与工程化交付能力。
- **与 Vue3 核心文档的关系**:`../01-vue3文档/` 讲 Vue3 本身的核心概念、组合式 API、原理与生态;本目录讲**如何用这套技术栈做出一套组件库**,二者互补——先掌握核心文档,再来本目录做实战。
- **与《Vue3 源码内参》的关系**:`../02-Vue3源码内参/` 从源码层面解释框架为什么这样设计;本目录从业务层面消费框架能力,视角是"造轮子上层应用"。
- **与《通用组件库》(TDD)的分工**:`../01-vue3文档/12-通用组件库/` 共 7 篇,是**TDD 教学向**的迷你组件库(测试驱动开发单个组件的方法论);本目录 155 篇是**实战课程向**的完整组件库工程。想学"怎么用测试驱动写组件"去 12-,想学"怎么在真实项目里把组件库做出来并发布"看本目录。
- **适读人群**:已了解 Vue3 基础(建议先读 `../01-vue3文档/01-核心基础/`),要做后台管理系统或想沉淀团队组件库的前端开发者。

::: tip 组件库内容分工(12-通用组件库 vs 03-自研组件库)
`../01-vue3文档/12-通用组件库/` 共 7 篇,定位是 **TDD 教学**:用测试驱动开发的方式逐个实现弹窗、表单、树形、表格等组件,重在方法论与测试实践;
本目录(03-自研组件库)共 155 篇,定位是 **实战课程**:在真实后台项目中把组件做进产品、再把组件库抽离出来构建发布,重在工程闭环。
两者主题相近、视角不同,按需取用即可。
:::

## 二、学习路径总览

课程按「设计理念 → 基础组件 → 进阶组件 → 工程化 → 发布」五个阶段推进:

| 阶段 | 目录 | 篇数 | 主线 |
| --- | --- | ---: | --- |
| 第一阶段·设计理念与项目启动 | 01-项目规划与工程启动 | 3 | 从 0 规划一个组件库/后台项目:想清楚再做。 |
| 第二阶段·基础组件 | 02-图标体系、03-通用功能组件、04-国际化方案、05-通知中心、06-后台布局与导航 | 37 | 图标、国际化、通知、主题、布局导航等后台地基能力。 |
| 第三阶段·进阶组件 | 07-认证与登录流程、08-表格与数据展示、09-表单与数据录入、10-指令与交互增强、11-图表与可视化、12-富文本与内容编排、13-音视频与媒体编排 | 53 | 表格、表单、指令、图表、富文本、音视频等复杂业务组件。 |
| 第四阶段·工程化 | 14-构建发布与工程交付 | 32 | 把业务项目沉淀成可发布、可复用的组件库工程。 |
| 第五阶段·发布与跨端交付 | 15-桌面端与跨平台应用 | 30 | 同一套 Vue3 技术栈延伸到桌面端,完成打包、签名、上架与自动更新。 |
| **合计** | **15 个专题目录** | **155** | 项目规划 → 组件沉淀 → 工程发布 → 桌面端交付 |

建议按阶段顺序学习;每个阶段内的目录编号即推荐阅读顺序(06/08/13/14/15 目录内部还有编号子专题)。

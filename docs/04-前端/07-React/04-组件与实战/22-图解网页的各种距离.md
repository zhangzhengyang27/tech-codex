# 图解网页的各种距离

## 鼠标位置：pageY、clientY、offsetY、screenY

浏览器里计算位置、宽高、判断一些交互，都需要用到距离、宽高的属性。鼠标相关的四个属性都挂在 `MouseEvent` 上，区别是参照的原点不同：

- **e.pageY**：鼠标距离**文档**顶部的距离，包含已经滚出去的部分。页面没有滚动条时它和 clientY 相等。
- **e.clientY**：鼠标距离**可视区域**（视口）顶部的距离，不包含滚动距离。
- **e.offsetY**：鼠标距离**触发事件的那个元素**顶部（其内边距边缘）的距离，是相对元素自己的坐标。
- **e.screenY**：鼠标距离**屏幕**（显示器）顶部的距离，和浏览器窗口在屏幕上的位置有关。

用一句话概括参照系：screenY 以屏幕为原点，pageY 以整个文档为原点，clientY 以视口为原点，offsetY 以目标元素为原点。

```js
function handleMouseMove(e) {
  console.log('距文档顶部（含滚动）：', e.pageY);
  console.log('距可视区域顶部：', e.clientY);
  console.log('距触发事件元素顶部：', e.offsetY);
  console.log('距屏幕顶部：', e.screenY);
}
```

## 滚动距离：scrollY 与 scrollTop

- **window.scrollY**：页面滚动的距离，也叫 `window.pageYOffset`，等同于 `document.documentElement.scrollTop`（现代浏览器下严格相等）。
- **element.scrollTop**：某个元素内部滚动的距离。它是可读可写的，给 `scrollTop` 赋值可以让元素滚动到指定位置，这是「回到顶部」按钮的实现原理。

```js
window.addEventListener('scroll', () => {
  console.log(window.scrollY === window.pageYOffset);                          // true
  console.log(window.scrollY === document.documentElement.scrollTop);          // true
});

// 回到顶部
button.addEventListener('click', () => {
  window.scrollTo({ top: 0, behavior: 'smooth' });
});
```

## 元素偏移：offsetTop、offsetParent、clientTop

- **element.offsetTop**：元素相对最近的**定位父元素**（offsetParent）顶部内边缘的距离。
- **element.offsetParent**：最近的定位祖先元素，没有定位祖先时一般是 body。
- **element.clientTop**：元素**上边框**的宽度。

offsetTop 只相对 offsetParent，想知道元素距离文档顶部多远，需要沿着 offsetParent 一层层递归累加，并且每层要加上该层的 clientTop（边框）：

```js
function getDistanceToDocumentTop(el) {
  let distance = 0;
  let current = el;
  while (current) {
    distance += current.offsetTop + current.clientTop;
    current = current.offsetParent;
  }
  return distance;
}
```

## 元素尺寸：clientHeight、offsetHeight、scrollHeight、innerHeight

- **clientHeight**：内容高度 + padding，**不包括边框**，也不包括滚动条。
- **offsetHeight**：内容高度 + padding + **边框**。
- **scrollHeight**：滚动区域的总高度（包含因溢出而不可见的部分），**不包括边框**。`scrollHeight - clientHeight` 就是还能滚动的距离。
- **window.innerHeight**：浏览器**视口**的高度，和任何元素无关。

对「能否触底加载更多」这类判断，就是 `scrollTop + clientHeight >= scrollHeight` 的组合应用：

```js
list.addEventListener('scroll', () => {
  const el = list;
  if (el.scrollTop + el.clientHeight >= el.scrollHeight - 10) {
    loadMore();
  }
});
```

## getBoundingClientRect：视口坐标与包围盒

`element.getBoundingClientRect()` 返回一个 DOMRect，常用的属性：

- **top、left**：元素距离**可视区域**上、左边的距离（即时计算，滚动时会变）。
- **width、height**：元素的宽高。绝大多数情况下等同 offsetHeight、offsetWidth，但元素经过 `transform` **旋转**之后就不一样了——拿到的是旋转后**包围盒**的宽高，而 offsetHeight 仍是布局尺寸。

```js
const rect = el.getBoundingClientRect();
console.log(rect.top, rect.left, rect.width, rect.height);
// 判断元素是否进入视口（懒加载的底层原理）
const visible = rect.top < window.innerHeight && rect.bottom > 0;
```

## 速查表

| 属性 | 含义 | 参照系 |
| --- | --- | --- |
| e.pageY | 鼠标距文档顶部 | 整个文档 |
| e.clientY | 鼠标距可视区域顶部 | 视口 |
| e.offsetY | 鼠标距触发事件元素顶部 | 目标元素 |
| e.screenY | 鼠标距屏幕顶部 | 屏幕 |
| window.scrollY | 页面滚动距离（= pageYOffset = documentElement.scrollTop） | 文档 |
| element.scrollTop | 元素滚动距离，可写 | 元素 |
| element.clientTop | 上边框高度 | 元素 |
| element.offsetTop | 相对最近定位父元素（offsetParent）的距离，递归累加 + clientTop 可算到文档顶部 | offsetParent |
| clientHeight | 内容高度，不包括边框 | 元素 |
| offsetHeight | 包含边框的高度 | 元素 |
| scrollHeight | 滚动区域总高度，不包括边框 | 元素 |
| window.innerHeight | 视口高度 | 视口 |
| getBoundingClientRect().top/left | 元素距可视区域上/左边的距离 | 视口 |

## 注意：React 合成事件没有 offsetY

其中，还要注意 react 的合成事件没有 offsetY 属性，可以自己算，react-use 的 useMouse 的 hook 就是自己算的，也可以用 `e.nativeEvent.offsetY` 来拿到原生事件上的值。

## 总结

浏览器里计算位置、宽高、判断一些交互，都需要用到距离、宽高的属性。

这类属性比较多，核心是分清**参照系**：鼠标四兄弟分别以文档、视口、目标元素、屏幕为原点；滚动看 scrollY / scrollTop；元素自身的偏移看 offsetTop（相对 offsetParent）；尺寸三兄弟 clientHeight、offsetHeight、scrollHeight 的区别在于是否算边框、是否算溢出内容；getBoundingClientRect 拿的是实时的视口坐标和包围盒。

掌握这些宽高、距离属性，就足够处理各种需要计算位置、宽高的需求了。

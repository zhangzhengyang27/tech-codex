## return 后面代码还是在执行

项目中写了一个函数：判断数组，如果有不符合的地方，就 return，结束函数；否则继续进行后续处理。

```javascript
function a() {
  $("input[name='a[]']").each(function () {
    var vid = $(this).val();
    if (vid == null || vid == "") {
      alert("流量必须填写");
      return false;
    }
  });
  // 后续处理。
}
```

但是，我发现，这样写的话，就算数组return了以后，后续代码还是会继续执行

each 回调内的 return false，只是类似 break 结束本次遍历，并不是外层函数的返回。所以，要想达到中断效果，还是要加上一个 flag 之类的

```javascript
function a() {
  var checkoutFlag = true;
  $("input[name='a[]']").each(function () {
    var vid = $(this).val();
    if (vid == null || vid == "") {
      alert("流量必须填写");
      checkoutFlag = false;
      return false;
    }
  });
  if (checkoutFlag == true) {
    // 后续处理。。
  }
}
```

## vue UI 可视化窗口修改为中文

vue UI 是根据浏览器语言来显示对应的语言的，只要更改浏览器默认语言就可以，以谷歌浏览器为例

![img](https://zhangzhengyang.oss-cn-beijing.aliyuncs.com/images/202403060212795.png)打开浏览器设置，搜索语言，将中文移至最上方，重新打开页面即可显示中文

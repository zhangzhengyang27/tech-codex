# Taro 导览

本模块收录 Taro 多端统一开发教程共 24 篇，从背景趋势、React 语法基础，到 Taro 设计思想、运行时机制，再到多端电商平台完整实战。

## 版本说明

> **本系列基于 Taro 1.x/2.x 时代的内容整理，正文未重写。目前 Taro 4.x 已发布，API 与编译机制已有重大变化，全部篇目仅作架构与思路参考。**

- 每篇正文开头均带有「版本提示」告示，阅读时请先留意该提示；
- 本系列的价值在于：多端统一开发的**背景与思路**、Taro **架构演进的逻辑**（编译时 → 运行时）、小程序/H5/RN 三端**适配的设计思想**，以及电商实战的**业务拆解方法**；
- 具体 API（组件、 hooks、配置项、编译配置）请以 [Taro 官方文档](https://docs.taro.zone/) 当前版本为准，1.x/2.x 时代的 `Taro.xxx` 组件用法、编译细节等不要直接照搬；
- 若需上手 Taro 4.x 新项目，建议从官方 `npm i -g @tarojs/cli` 初始化模板开始，再回读本系列理解其设计取舍。

### 版本时间线速览

| 版本 | 关键特征 | 与本系列的关系 |
| --- | --- | --- |
| Taro 1.x | 以编译时方案为主，静态编译 JSX 到各端模板 | 本系列 01-13 的写作背景 |
| Taro 2.x | 编译时与运行时结合，工程链路升级 | 本系列 14-24 实战篇的写作背景 |
| Taro 3.x | 转向运行时方案，支持 React/Vue/Preact 多框架 | 架构思想与 08-13 篇的演进方向一致 |
| Taro 4.x | 构建体系与插件机制重构，API 全面更新 | 当前主流版本，请以官方文档为准 |

## 阅读建议

1. 01-03 补齐多端开发背景与小程序基础，已有 React 经验者可略读 02；
2. 08-13 是本系列含金量最高的原理部分，理解「编译时方案为何转向运行时方案」对理解所有跨端框架（Taro/RN/Flutter/uni-app）都有帮助；
3. 14-24 电商实战按业务模块拆解，重点看思路与踩坑，不必复现旧版本代码；
4. 需要当前版本 API 时，始终以 Taro 官方文档为准。

# 架构设计 导航

本目录是**架构设计系列合集**,收录三个子系列共 91 篇:许式伟的架构课(52 篇)、中台架构(18 篇)、软件架构场景实战 22 讲(21 篇)。与 01/10/11 三个架构目录的分工见文末声明。本页是合集的权威入口。

## 一、定位声明:本目录是什么、不是什么

- **本目录(02-架构设计)= 系列合集**:按"思想与体系 → 方法论 → 实战案例"收录三个成体系的系列,保留各系列自身的叙事顺序。
- 它**不是**按质量维度组织的方案手册(见 [01-整体架构设计](../01-整体架构设计/00-导航.md)),也**不是**面试题库(见 [10-架构设计面试精讲](../10-架构设计面试精讲/00-导航.md))或入门教程(见 [11-从0开始学架构](../11-从0开始学架构/00-导航.md))。
- 其中 **04-许式伟架构课** 是本目录的主体分册:从编程语言、存储、桌面/Web 到服务端与架构师成长的完整架构观,适合作为"第二遍"深读材料。

三个子系列的互补关系:

- 许式伟架构课给**思想与体系**——"架构是什么、怎么想";
- 场景实战 22 讲给**工程现场**——"真实场景里怎么决策";
- 中台架构给**组织与平台视角**——"企业级能力复用怎么做"。

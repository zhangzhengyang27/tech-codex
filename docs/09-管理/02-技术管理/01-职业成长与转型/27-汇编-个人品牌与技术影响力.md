# 汇编 | 个人品牌与技术影响力

对技术人而言，个人品牌是"职业生涯中的第二个自我"——它体现了你在别人心目中的价值与能力，也能把别人对你的看法变成机会。本篇汇编两位嘉宾从不同角度给出的完整方法论：一位用 beego、GoCN、Gopher China 的多年坚持示范"品牌靠积累"，一位从媒体与社区运营者的视角拆解"认知升级与经验落地"的路径。

## 谢孟军：技术人如何建立自己的个人品牌（三步走）

原篇：《大咖对话-谢孟军：技术人如何建立自己的个人品牌》（嘉宾为积梦智能创始人兼CEO，Gopher China 创始人，beego 框架作者）

- **第一步：打造核心技能。** "一定要发现并聚焦到自己最擅长的领域……以 Go 语言为例……你需要聚焦到更小的技术方向上，比如专攻 Go 中的 API 这一技术点，然后不断的学习、不断的深挖。"
- **核心技能之外要开阔眼界。** "如果专注在一个领域或平台太久，你会发现自己的思路、格局都会受到限制……吸收其中的精华，再找到自己的差距。回来后，再快速地聚焦专注到自己的主攻方向……内外兼攻。"
- **第二步：打造独特性标签。** "独特性，一般由核心技能之外的多样化技能构成，比如你程序员里最会演讲的、最会写文章的、最会做 PPT 的……被打上的标签越独特，就越能让人记住。"
- **第三步：找平台 + 建立圈子。** 分享的三大好处：其一"很多东西你以为已经弄明白了，其实不然，出来分享，有助于你把自己正在做的事情真正理清楚、讲清楚"；其二"分享之后，别人才能给你反馈……你才可能意识到自己之前走入的一些误区"；其三"通过分享，别人才有可能认识你"。
- **品牌 = 坚持 × 时间。** "写一篇文章爆红，是眼球不是品牌；写一百篇文章篇篇有人看，是积累也不是品牌；但是每年写一百篇文章，坚持了七年，提起某个领域大家首先想到的就是你，这才是品牌。"
- **开源与业务可以相辅相成。** beego "是从业务中诞生的"——把业务中共性问题提炼开源；业余时间投入开源，工作时间把开源中有价值的部分应用到业务中。他写《Go Web 编程》时儿子刚出生，"从 10 点开始写文章，一直写到 12 点睡觉，这样的生活坚持了大概一年多"。

## 霍泰稳：认知升级与个人品牌的落地路径

原篇：《大咖问答-打造自己的个人品牌，你也可以》（嘉宾为极客邦科技创始人兼CEO）

- **认知升级三法。** 一是"始终想着业务"——"为什么有些大公司出来的同学，就是给人感觉视野很开阔……主要原因是他们参与解决了很多实际的有挑战的问题"；二是"进入圈子协作"——"人的认知是存在盲点的，自己看不到，了解自己的人却能看的很清楚"；三是"跨界学习"——"要学会'跨界'……不囿于当下的工作，多参加一些跨界的活动或者学习"。
- **学习要讲"次第"。** "如果现在公司网络业务的并发量是以万级计算，你听千万级并发量的课程，对自己能有多大的帮助？这时候可能倒不如听一个不是那么有名气的同学，来分享他们的业务是如何从万级并发到十万百万并发的。"
- **经验落地三原则。** "冷静一周再实施"——学习后"先让自己冷静一下……挑选团队里的个别小伙伴征询意见"；"MVP 法则"——"先挑个小团队去试运行，看看效果。如果效果好，适合自己的团队，则推而广之，否则，就偃旗息鼓"；落地前先回答五个问题（团队痛点是什么、新方法能否真正解决问题、会遇到什么挑战、有没有更好的方法、实施的目的目标步骤是什么）。
- **个人品牌的定义与四条路径。** "一个人带给别人的印象，以及所影响的人的范围……他在某一方面有专长，有权威，另外就是他还影响和帮助了很多人。"路径包括：通过社交媒体多发表观点；多参与有品质的会议并演讲或写博客/公众号；出书（最有效的方法）。
- **社交媒体的克制礼仪。** "过于活跃可能给人留下没有专注于本职工作的印象……多发表有见地和有理有据的内容"；"不要一个内容到处讲……至少每次讲的内容要有 30% 的更新。"

# 汇编 | 合伙人与创业团队

"合伙人内斗其实是很多公司死亡的主要原因"——选对合伙人、搭好班子、让投资人看见一支优秀团队，是技术创业从 0 到 1 的组织前提。本篇汇编三位嘉宾（含同一嘉宾的两篇对话）关于合伙人选择、团队结构与投资逻辑的核心观点。

## 王鹏云：技术人创业该如何选择合伙人

原篇：《大咖对话-王鹏云：技术人创业该如何选择合伙人》（嘉宾为前多盟联合创始人、前蓝标移动广告集团CTO）

- **合伙创业比结婚还难。** "因为这个团队所经历的事情要比家庭复杂得多。合伙人内斗其实是很多公司死亡的主要原因。"
- **技术人创业的三大误区。** 误区一"以技术为先考虑问题"——"如今绝大部分创业公司都不是真正以技术为核心驱动，多数情况下核心技术门槛没有那么高——你能做，很多公司也能做"；误区二"过度技术化"——"技术化应该有一个节点选择——在合适的时间、合适的环境和条件下做技术化"；误区三"过度理性"——"创业本来就是九死一生……创业需要狂热、突围、狂奔，需要对商业和行业有洞察和直觉。"
- **合伙人选择五要素。** 契约精神（"承诺就要尽最大努力兑现"）；有主有从（"不能因哥们义气齐头并进，'商量着办事'的企业发展到最后瓶颈都非常明显"）；能力互补（"几个人都是技术或都是商务的团队短板非常明显"）；奇数人数（"三个是相对比较好的数字"）；前同事优先（"了解能力、短板、做事风格……能撕破脸皮——朋友创业最大的问题是出问题时撕不下脸"）。
- **创业团队稳定三要素。** 契约精神（"困难时共赴难关"）；互相理解（"即使不同意他的做法，也理解他做事的合理性"）；良好默契（"私下彼此信任，产生工作中达成一致的更多可能"）。
- **规避误区的方法。** "一定要压制自己的技术人思维……即使你的技术确实很强"；"开阔眼界，了解技术之外的东西……当你了解了社会与行业，再来反推公司的商业价值，就相当于了解全局再跳回来审视局部。"

## 王鹏云：管理方式的差异是为了更好地实现企业商业价值

原篇：《大咖对话-王鹏云：管理方式的差异是为了更好地实现企业商业价值》（同上嘉宾，基于互联网公司与传统企业的双重经历）

- **管理方式服务于商业价值。** "所谓的传统企业与互联网企业的技术管理方式差异，最终都是为了服务于你所要实现的商业价值。""互联网公司以产品和技术为主，蓝标以业务和客户价值为先导，反推需要什么样的技术工具和数据支撑。"
- **CTO 没有标准模板。** "没有一个CTO能够完备地做到所有特质要求，只有'合适'的CTO。所谓'合适'，就是如何用产品、技术、平台、工具等作为支撑，帮助企业商业价值在最好的时间和场景下落地。"
- **CTO 该不该写代码不能一刀切。** "不能单看是与非，需要考虑CTO的工作中需不需要他写代码。如果CTO负责的是公司最核心的技术驱动，那写代码是必须的；如果在相对成熟、比较传统的业务中，CTO需要做的是优化工具、支撑业务、设计最合适的支撑体系。"
- **创业要顺势而为。** "有些大势是显性的，有些是隐性的。乔布斯发明苹果是满足了隐性的大势——当时市场满足不了用户对智能手机的需求，但需求已经真实存在。""创业不要想颠覆平台，而是多想想怎么利用平台在平台上做好事……基于大平台延伸到别的领域做事情的机会并不少。"
- **商业价值是双向的。** "创业的核心一定是实现商业价值，并达成双向收益——给用户贡献价值，同时把钱收回来，缺一不可。只收钱不提供价值是骗子公司，只贡献价值收不回钱难以维持。"

## 童剑：用合伙人管理结构打造完美团队

原篇：《大咖对话-童剑：用合伙人管理结构打造完美团队》（嘉宾为白山云科技联合创始人兼CTO，曾任职新浪16年）

- **联合舰队模式。** "白山创立之初就组建了一个13人规模的合伙人团队，其理念不是打造巨轮而是编成联合舰队，每个合伙人都是舰船的掌舵人，大家一起带着业务、带着公司往前发展，效果可能比CEO一个人指挥的巨轮更好。"
- **个人强化长板，团队补齐短板。** "从个人发展角度来说，应该不断强化自己的优势……但从团队发展角度出发，应该尽量找到合适的人，与自己互补的人，让团队没有短板。"白山合伙人"平均有着17年的从业时间，不论是经验还是资源都很丰富"。
- **乐高式松耦合架构。** "希望所有的技术都是松耦合架构的。当一个客户需求提过来时……把功能模块开发出来之后，直接接入到架构里就能运行了，像搭积木一般灵活自如。""过去软件行业对客户的需求都是以月为单位进行实施和交付，而通过'乐高式松耦合'的架构，能够做到以周、甚至以天为单位进行快速开发、快速交付。"
- **在公司内部争取机会。** 童剑在新浪从技术开发转做安全、再带团队建统一技术平台的经历说明：安全管理"一定程度是治标不治本——安全最大的问题是和不完善的技术体系的斗争"；"通过在公司内部的努力，争取自己感兴趣的工作机会——不必通过跳槽来换岗位、换环境。要有服务意识。"

## 顾旻曼：投资时我们更多地是在找优秀的团队

原篇：《大咖对话-顾旻曼：投资时我们更多地是在找优秀的团队》（嘉宾为真格基金董事总经理、华东区负责人）

- **找团队而非追风口。** "真格会比较偏向于选择优质的、专业的团队进行早期投资。很少追风口——客观上来讲，风口起来了价格也偏高。""更多的是在找优秀的团队。"
- **papi酱案例：罕见的人才组合。** "在这个行业里要找到一支高素质的从业者队伍非常难，而papi酱团队中的三个人是中戏同学，各自的经历也非常丰富……这样的组合非常罕见。"
- **依图案例：积累的势能。** "真格当时之所以选择依图，是因为看中了创始人朱珑、林晨曦组建的团队——朱珑在加州大学洛杉矶分校获博士学位、曾在麻省理工学院从事研究……林晨曦在阿里巴巴搭建了国内最大的拥有自主知识产权的飞天分布式云计算操作系统。"
- **创业者要有充分积累。** "创业是对过去积累的势能的一次变现——创业者要清晰地知道自己为何而来，并且不会因为一时的市场起伏、资本的追捧或是冷落就有任何变化。"
- **投资人的自我要求。** "心态摆正——不能要求创业者一帆风顺，在他做得很好的时候就高捧，在遇到困难和挣扎时就贬到一文不值"；自身持续成长；坚守核心投资理念——"一直以来关心的核心都没有发生过变化——技术怎么样改变这个世界。"
- **不要用性别给自己打标签。** "用性别给自己打标签，要不就是偷懒，要不就是自我限制……只有发挥出很大的能量，才会影响雇主的'偏见'。"

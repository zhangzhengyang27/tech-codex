# 数据的二进制表示：原码、反码、补码与溢出

计算机内部一切数据都以二进制存储。本文整理整数的原码、反码、补码三种表示法，补码的优势，以及加法溢出与判断方法，作为理解 CPU 运算器的基础。

## 一、为什么用二进制

- 电子元件天然只有"通/断"两种稳定状态，对应 0/1，可靠性最高。
- 二值逻辑与布尔代数一一对应，硬件实现简单（与门、或门、非门）。
- 抗干扰强：只需区分高低电平，容错性好。
- 因此计算机以 2 为基数表示所有数值。

一个二进制数从右往左第 \(i\) 位（从 0 计）的权值为 \(2^i\)。例如：

\[
(1011)_2 = 1\times2^3 + 0\times2^2 + 1\times2^1 + 1\times2^0 = 11
\]

## 二、机器数与真值

- **真值**：带符号的十进制/二进制数值，如 \(+5\)、\(-5\)。
- **机器数**：符号也用二进制位表示的存储形式。通常用最高位作符号位：0 表示正，1 表示负。

一个 \(n\) 位机器数能表示的无符号整数范围为 \(0 \sim 2^n-1\)。但数值有正负，需要用特定编码表示符号。

## 三、三种表示法

以 8 位（\(n=8\)）为例，真值 \(x\) 的三种表示：

### 原码（Sign-Magnitude）

符号位 + 数值绝对值。最高位为符号，其余为绝对值二进制。

| 真值 | 原码 |
| --- | --- |
| +5 | 0000 0101 |
| -5 | 1000 0101 |

- 优点：直观，与真值对应关系清楚。
- 缺点：**0 有两种表示**（+0 = 0000 0000，-0 = 1000 0000）；加减法需先判断符号，电路复杂。

### 反码（One's Complement）

正数反码同原码；负数反码 = 原码除符号位外逐位取反。

| 真值 | 原码 | 反码 |
| --- | --- | --- |
| +5 | 0000 0101 | 0000 0101 |
| -5 | 1000 0101 | 1111 1010 |

- 0 仍有两种表示。
- 反码主要作为补码的中间过渡，很少单独使用。

### 补码（Two's Complement）

正数补码同原码；负数补码 = 反码 + 1。

| 真值 | 原码 | 补码 |
| --- | --- | --- |
| +5 | 0000 0101 | 0000 0101 |
| -5 | 1000 0101 | 1111 1011 |

**补码的核心优势**：将减法统一为加法。对任意 \(a\)、\(b\)：

\[
a - b = a + (-b)_{\text{补}}
\]

CPU 只需一个加法器即可同时完成加减法，无需判断符号，硬件大幅简化。

**0 唯一表示**：\(+0\) 与 \(-0\) 的补码都是 `0000 0000`，消除了歧义。

## 四、补码的数值范围

对 \(n\) 位补码：
- 正数范围：\(0 \sim 2^{n-1}-1\)（最高位为 0）。
- 负数范围：\(-2^{n-1} \sim -1\)（最高位为 1）。

8 位补码范围为 **-128 ~ +127**。注意 `1000 0000` 表示 -128，是补码多表示出的一个数（原码/反码没有 -128）。

**求负数补码的速记**：对负数的原码，从右往左找到第一个 1，该位及右边不变，左边（符号位除外）全部取反。例如 -5 的原码为 `1000 0101`，从右第一个 1 是第 0 位，左边取反（符号位不变）得 `1111 1011`，即补码；等价地，对绝对值 `0000 0101` 逐位取反再加 1 结果相同。

## 五、补码的运算

### 补码加减统一为加法

```
5 + (-3) 补码运算：
+5 = 0000 0101
-3 = 1111 1101
相加： 0000 0101 + 1111 1101 = 1 0000 0010（丢弃最高进位）
结果 = 0000 0010 = +2 ✓
```

**关键**：结果溢出丢弃最高位进位，得到正确补码。

### 溢出判断

溢出指运算结果超出机器数可表示范围。判断方法：

1. **符号位判断**（两同号数相加）：两个正数相加结果为负，或两个负数相加结果为正，即溢出。
   - `0111 1111`(127) + `0000 0001`(1) = `1000 0000`(-128) ❌ 溢出（正+正得负）
2. **最高位进位与符号位进位不同**：设符号位进位 \(C_n\)、最高数值位进位 \(C_{n-1}\)，若 \(C_n \ne C_{n-1}\) 则溢出。

### 溢出与进位的区别

- **进位**（Carry）：最高位有进位，结果丢弃，数值仍正确（无符号角度看）。
- **溢出**（Overflow）：结果超出符号数范围，数值错误。进位不一定溢出，溢出也不一定有进位。

## 六、定点数与无符号扩展

- **定点数**：小数点在固定位置的数。纯整数（小数点在最低位后）与纯小数是两种特例。
- **符号扩展**：将短整数扩展为长整数时，补码需**按符号位扩展**（正数补 0、负数补 1），以保持数值不变。
  - 8 位 `1111 1011`(-5) → 16 位应为 `1111 1111 1111 1011`，而非补 0。
- **零扩展**：无符号整数扩展位宽时，高位直接补 0。

## 小结

- 机器数用最高位表示符号，常见三种编码：原码直观、反码过渡、补码将减法统一为加法且 0 唯一。
- 补码是 CPU 加减运算的事实标准，n 位补码范围 \(-2^{n-1} \sim 2^{n-1}-1\)。
- 运算时需区分进位与溢出；带符号数扩展按符号位扩展保持数值不变。

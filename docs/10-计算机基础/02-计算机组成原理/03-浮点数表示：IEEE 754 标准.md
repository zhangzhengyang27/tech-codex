# 浮点数表示：IEEE 754 标准

整数用补码表示，但实数范围极大且小数位可变，需用"科学计数法"式的浮点表示。本文整理 IEEE 754 标准下单精度/双精度浮点的组成、转换、特殊值与精度问题。

## 一、为什么需要浮点数

定点数（小数点位置固定）无法同时表示极大与极小的数，且精度固定。浮点数借鉴科学计数法，用**指数**调节小数点位置，以有限的位表示跨度极大的数值范围。

科学计数法形式：

\[
N = \pm M \times 2^E
\]

- **M（尾数/有效数字，Mantissa）**：决定精度。
- **E（阶码/指数，Exponent）**：决定范围。

## 二、IEEE 754 的组成

IEEE 754 是浮点数的行业标准，常见两种：

| 类型 | 总位宽 | 符号位 S | 阶码 E | 尾数 M | 数值范围（约）| 精度 |
| --- | --- | --- | --- | --- | --- | --- |
| 单精度 float | 32 | 1 | 8 | 23 | \(\pm3.4\times10^{38}\) | 约 7 位十进制 |
| 双精度 double | 64 | 1 | 11 | 52 | \(\pm1.8\times10^{308}\) | 约 15-16 位十进制 |

**关键设计**：
- **隐含整数位（hidden bit）**：标准要求尾数规范化后最高位恒为 1，故不显式存储，实际有效位为 \(M+1\) 位。例如单精度实际精度 24 位。
- **阶码用移码（偏置）存储**：阶码有正有负，无法直接用补码比较大小。IEEE 754 用**偏置（Bias）**：单精度偏置 127，双精度偏置 1023。
  - 实际存储的阶码 = 真阶 + 偏置。
  - 例如真阶 0 → 存 127（单精度）。

## 三、浮点数的转换

### 十进制 → 二进制浮点

例：\(6.5\) 转单精度。

1. 转二进制：\(6.5 = 110.1_2\)。
2. 规范化：\(110.1 = 1.101 \times 2^{2}\)。
   - 尾数 M = 101（去掉隐含 1），不足 23 位右补 0。
   - 真阶 E = 2。
3. 存储阶码 = \(2 + 127 = 129 = 10000001_2\)。
4. 符号位 0。
5. 拼接：`0 10000001 10100000000000000000000`。

### 二进制浮点 → 十进制

`0 10000001 10100000000000000000000`：
- 符号 0 = 正。
- 阶码 129 → 真阶 \(129-127=2\)。
- 尾数 101 → 数值 \(1.101_2\)。
- 结果 \(1.101 \times 2^2 = 110.1_2 = 6.5\)。

## 四、特殊值

IEEE 754 用阶码全 0 / 全 1 表示特殊值：

| 阶码 | 尾数 | 含义 |
| --- | --- | --- |
| 全 0 | 全 0 | \(\pm0\) |
| 全 0 | 非 0 | **非规格化数**（denormal，最小精度以下）|
| 全 1 | 全 0 | \(\pm\infty\)（无穷大）|
| 全 1 | 非 0 | **NaN**（Not a Number，如 0/0）|

- 除以 0 得到 \(\infty\)；0/0、\(\infty-\infty\) 得到 NaN。
- 浮点数支持 `-0`，且 `-0 == +0` 为 true，但 1/-0 = -∞。

## 五、精度与经典陷阱

### 二进制无法精确表示十进制小数

十进制的 0.1 转二进制是无限循环小数（\(0.0001100110011\cdots\)），存储时被截断，产生舍入误差。

```python
0.1 + 0.2  # 输出 0.30000000000000004
```

这是浮点数的**固有局限**，不是 bug。理解此点对工程至关重要。

### 避免浮点比较陷阱

- 不要直接用 `==` 比较浮点数，应比较差的绝对值是否小于阈值：
  ```python
  abs(a - b) < 1e-9
  ```
- 需要精确计算的场景（金额、金融）使用**定点数/十进制类型**（如 `Decimal`），或用整数表示最小单位（分）。
- 大数相加时，先加小数避免精度损失；累加大量小数时误差会累积。

### 大数吞小数

`16777216.0 + 1.0` 在 float 下等于 `16777216.0`，因为 24 位有效位无法表示 +1 的增量。大数与极小数的加法可能被"吞掉"。

## 六、数值范围与阶码上下溢

- **上溢（Overflow）**：数值超过最大可表示范围 → \(\infty\)。
- **下溢（Underflow）**：数值小于最小非规格化数 → 0 或非规格化数。

## 小结

- IEEE 754 用"符号 + 移码阶码 + 规范化尾数"表示浮点数，隐含整数位提升精度。
- 单精度偏置 127、双精度偏置 1023；阶码全 0/全 1 对应 0、非规格化、∞、NaN。
- 十进制小数转二进制多不精确，应避免直接相等比较，精确场景用定点数/Decimal。

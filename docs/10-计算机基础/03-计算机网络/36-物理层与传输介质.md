# 物理层与传输介质

物理层是 OSI 模型的底层，负责在物理介质上传输**原始的比特流**。本文整理物理层的功能、信号编码、传输介质（双绞线/光纤/无线），以及复用技术与网络设备。

## 一、物理层的职责

物理层关注"如何把 0/1 比特变成物理信号并通过介质传输"，不关心数据含义。核心：

- **定义电气/机械/功能特性**：电压、速率、接口形状、引脚。
- **信号编码**：把比特映射为电/光/无线信号。
- **传输介质**：决定用什么载体传输。
- **物理拓扑**：总线、星型、环型等连接结构。

物理层错误无法在此层纠正，交给上层（链路层 CRC 检错）。

## 二、信号与编码

- **模拟信号**：连续变化的波形（电话语音）。
- **数字信号**：离散的电压脉冲（计算机）。

**编码（Encoding）**：将比特流转为信号。

- **不归零（NRZ）**：电平直接表示 0/1，简单但难以同步（连续相同位无法区分）。
- **曼彻斯特编码（Manchester）**：每个比特中间有跳变，跳变同时作时钟与数据（IEEE 802.3 约定：低→高表示 1，高→低表示 0；文献中亦有相反约定），自带同步，用于 10M 以太网。
- **差分曼彻斯特**：比特起始处有跳变表示 0，无跳变表示 1。

**同步方式**：接收方需与发送方同步时钟。可用**同步传输**（带时钟）或**异步传输**（起始/停止位）。

## 三、传输介质

### 双绞线（Twisted Pair）

- 两两绞合以抵消电磁干扰。
- 分**屏蔽（STP）**与**非屏蔽（UTP）**。
- 分类：Cat5e（千兆）、Cat6、Cat6a 等。
- 最常用的局域网介质，接口为 RJ-45。

### 同轴电缆

- 中心导体 + 屏蔽层，抗干扰强，曾用于有线电视与早期以太网。

### 光纤

- 用**光信号**传输，分：
  - **单模光纤（SMF）**：激光，芯径细，损耗小，传输远（几十公里），用于主干网。
  - **多模光纤（MMF）**：LED，芯径粗，传输近（几百米），用于楼宇内。
- 优点：带宽高、损耗低、抗电磁干扰、保密性好。

### 无线介质

- **无线电波**：Wi-Fi、蜂窝网络，穿透性强、易受干扰。
- **微波**：点对点视距传输。
- **红外**：短距离视距。

## 四、多路复用技术

共享同一条物理信道传输多路信号，即**多路复用（Multiplexing）**：

- **频分复用（FDM）**：不同信号用不同频率段，同时传输（模拟电视、光纤波分复用 WDM）。
- **时分复用（TDM）**：不同信号分时占用信道（数字通信）。
- **波分复用（WDM）**：光纤中用不同波长的光（本质是 FDM 在光频段）。
- **码分复用（CDM/CDMA）**：不同信号用正交码叠加，同频同时，接收端按码分离（3G 移动通信）。

## 五、常见网络设备（按 OSI 分层）

| 设备 | 工作层次 | 转发依据 |
| --- | --- | --- |
| 中继器（Repeater）/集线器（Hub）| 物理层 | 放大/转发信号，不识别地址 |
| 交换机（Switch）| 数据链路层 | MAC 地址 |
| 路由器（Router）| 网络层 | IP 地址 |
| 网卡 | 物理+链路层 | - |

- **集线器**是物理层设备，所有端口共享带宽、同一冲突域，已被交换机取代。
- 中继器放大信号以延长传输距离，不能识别数据含义。

## 六、物理层与现代网络

- 现代以太网物理层用**双绞线（1000BASE-T）**与**光纤（1000BASE-SX/LX）**。
- 光模块（SFP/QSFP）实现电-光转换，是数据中心互联的关键。
- 物理层的速率定义（10/100/1000M、10G、25G、100G）决定了网络带宽的基础。

## 小结

- 物理层负责比特到信号的传输，涉及电气特性、编码、介质与拓扑。
- 常用介质有双绞线、光纤、无线；编码需解决同步问题（曼彻斯特编码自带时钟）。
- 多路复用（FDM/TDM/WDM/CDMA）让多路信号共享信道。
- 中继器/集线器工作在物理层，交换机在链路层，路由器在网络层。

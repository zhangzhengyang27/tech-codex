# 设计模式

设计模式（Design Pattern）是对软件设计中反复出现的问题的通用解决方案。它们是解决特定问题的模板，描述了在特定场景下组织类与对象关系的通用策略，而非可以直接转化为代码的成品。

本分类将 GoF 23 种设计模式按**每模式一文件**组织，每个文件内含**语言中立的概念**与 **TypeScript / Java / Python 三种语言的实现**，方便横向对比同一模式在不同语言下的实现差异。

## 学习建议

设计模式的**理论（23 种模式的意图、结构、适用场景）是语言无关的**，而**实现代码才是语言相关的**。建议先读总览建立整体认知，再逐个模式阅读，重点对比同一模式在不同语言（TypeScript / Java / Python）下的实现差异，最后通过重构练习和框架源码分析来加深理解。

# Git log 选项
## Git log 选项

### 1. -p, --patch

**配置**: 显示提交的差异

**说明**: 此选项用于显示提交的差异。这对于查看提交更改了哪些文件和代码行非常有用

```bash
git log -p -2
```

### 2. -2, -3, ..., -n

**配置**: 显示最近的 n 次提交

**说明**: 此选项用于显示最近的 n 次提交。默认情况下，`git log` 命令将显示所有提交

```bash
git log -3
```

### 3. --since , --after 

**配置**: 显示自指定日期以来的提交

**说明**: 此选项用于显示自指定日期以来的提交。日期可以是绝对日期，例如 "2023-11-15"，也可以是相对日期，例如 "1 week ago"

```bash
git log --since="2023-11-15"
```

### 4. --until , --before 

**配置**: 显示在指定日期之前的提交。

**说明**: 此选项用于显示在指定日期之前的提交。日期可以是绝对日期，例如 "2023-11-15"，也可以是相对日期，例如 "1 week ago"

```bash
git log --until="2023-11-15"
```

### 5. --author 

**配置**: 显示指定作者的提交

**说明**: 此选项用于显示指定作者的提交。作者可以是用户名或电子邮件地址

```bash
git log --author="John Doe"
```

### 6. --grep 

**配置**: 显示包含指定模式的提交

**说明**: 此选项用于显示包含指定模式的提交。模式可以是正则表达式或字符串

```bash
git log --grep="fix bug"
```

### 7. --oneline

**配置**: 显示每行一个提交的摘要。

**说明**: 此选项用于显示每行一个提交的摘要。这对于快速浏览提交历史非常有用

```bash
git log --oneline
```

### 8. --graph

**配置**: 显示提交历史的图形化视图。

**说明**: 此选项用于显示提交历史的图形化视图。这对于可视化提交历史非常有用

```bash
git log --graph
```

### 9. --pretty 

**配置**: 使用指定的格式显示提交信息

**说明**: 此选项用于使用指定的格式显示提交信息。格式可以是 `oneline`、`short`、`full`、`fuller` 或自定义格式

```bash
git log --pretty=format:"%h %an %s"
```

### 10. --stat

**配置**: 显示每个提交的统计信息

**说明**: 此选项用于显示每个提交的统计信息，包括添加、删除和修改的文件数量以及代码行的增减数量

```bash
git log --stat
```

### 11. --summary

**配置**: 显示扩展属性变更的摘要

**说明**: 此选项输出每个提交中文件级扩展属性的变化摘要（如新建、删除、重命名文件、权限变化等），常与 `--diff-filter` 配合使用。注意它显示的不是提交消息

```bash
git log --summary
```

### 12. --name-only

**配置**: 仅显示每个提交更改的文件名

**说明**: 此选项用于仅显示每个提交更改的文件名。这对于快速查看哪些文件被更改非常有用。

```bash
git log --name-only
```

### 13. --date-order

**配置**: 按提交时间戳顺序显示提交

**说明**: 此选项在遍历多条分支历史时，按提交时间戳的先后交叉显示提交（与按拓扑结构遍历的 `--topo-order` 相对）

```bash
git log --date-order
```



### 14. --reverse

**配置**: 反向显示提交

**说明**: 此选项用于反向显示提交。默认情况下，`git log` 命令按时间顺序显示提交

```bash
git log --reverse
```

### 15. --merges

**配置**: 仅显示合并提交

**说明**: 此选项用于仅显示合并提交。合并提交是将两个或多个分支合并在一起的提交

```bash
git log --merges
```

### 16. --no-merges

**配置**: 仅显示非合并提交

**说明**: 此选项用于仅显示非合并提交。非合并提交是普通提交，不是合并提交

```bash
git log --no-merges
```

### 17. --first-parent

**配置**: 仅显示每个提交的第一个父提交

**说明**: 此选项用于仅显示每个提交的第一个父提交。这对于查看线性提交历史非常有用

```bash
git log --first-parent
```

### 18. --all

**配置**: 以所有引用为起点显示提交历史

**说明**: 此选项相当于把仓库中所有引用（本地分支、远程追踪分支、标签等）都作为遍历起点；默认的 `git log` 只从当前 HEAD 开始遍历

```bash
git log --all --oneline
```

### 19. --remotes

**配置**: 显示远程仓库的提交。

**说明**: 此选项用于显示远程仓库的提交。这对于查看远程仓库的提交历史非常有用

```bash
git log --remotes
```

### 20. --tags

**配置**: 显示带有标签的提交

**说明**: 此选项用于显示带有标签的提交。这对于查看带有标签的提交历史非常有用

```bash
git log --tags
```

### 21. --cherry-pick

**配置**: 省略对称差集中与另一侧重复的提交

**说明**: 此选项需与 `A...B` 对称差范围配合使用，省略与另一侧引入相同改动（patch 等价）的提交，常用于分析两个分支合并前后哪些提交是重复的

```bash
git log --cherry-pick --oneline main...feature
```

### 22. --notes

**配置**: 显示带有注释的提交

**说明**: 此选项用于显示带有注释的提交。注释是添加到提交的额外信息

```bash
git log --notes
```

### 23. --follow

**配置**: 跟踪重命名和移动的文件

**说明**: 此选项用于跟踪文件重命名前后的完整历史，需要与具体文件路径配合使用

```bash
git log --follow -- src/main.py
```

### 24. --color

**配置**: 使用颜色突出显示提交信息

**说明**: 此选项用于使用颜色突出显示提交信息。这对于快速查看提交信息非常有用

```bash
git log --color
```

### 25. --no-color

**配置**: 不使用颜色突出显示提交信息

**说明**: 此选项用于不使用颜色突出显示提交信息。这对于在不支持颜色的终端上使用 `git log` 命令非常有用

```bash
git log --no-color
```

## 一些额外的技巧

- 使用 `git config` 命令配置默认的 `git log` 选项
- 使用 `git log -h` 命令查看所有可用选项
- 使用 `git log --help` 命令查看特定选项的帮助信息

# 17 · 附录：全工具速查矩阵

> **一句话摘要**：142 个工具的全量清单——id、名称、布局、是否有专属测试，按 9 分类分组；布局与测试列可直接用于统计与排期。
> **目标读者**：全体 ｜ **关联文档**：[00 总纲](00-总纲与阅读指南.md) · [03 登记体系](03-工具登记体系与扩展SOP.md) · [04 布局体系](04-布局体系与页面骨架.md)

**口径说明**：id 与 layout 摘自 `src/config/tools/catalog.ts`（唯一真源）；「测试 ✓」= `src/views/tools/` 下存在该页面的专属 `*.dom.test.ts`（全部 11 个，见文末清单），未标注者仅被全页巡检 `allToolPages.dom.test.ts` 覆盖。注意**页面文件名 ≠ id 的机械映射**（如 text-base64-encode → `text/Base64Page.vue`、encrypt-jwt → `encrypt/JwtToolPage.vue`、encrypt-data-mask → `generate/MaskGeneratorPage.vue`）——这正是 `toolComponents.ts` 必须手工登记的原因（03 §2.1）。

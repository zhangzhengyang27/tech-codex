# 00 项目总览

> 项目：html5-dataviz ｜ 版本：v1.0 ｜ 生成日期：2026-10-05 ｜ 依据：源码分析

## 1. 项目定位与目标用户

html5-dataviz（站点品牌名 **DevCanvas Dataviz**，见 `src/components/layout/AppHeader.vue` 中的品牌文案与 `package.json` 的 `name` 字段）是一个**纯前端、无后端依赖的数据可视化案例合集站点**。它把两类可视化资产整合在同一个 Vue 3 单页应用里：

1. **图表/三维示例库**：收录 Apache ECharts（348 条）、AntV G2Plot（351 条）、Three.js（989 条）共计 **1688 个可交互示例**，每个示例都可在站点内实时渲染、查看源码、下载 `.vue` 文件；
2. **数据大屏模板库**：收录 **22 个开箱即用的数据大屏**（`src/config/bigscreenData.ts` 的 `bigscreenList`），覆盖政务、工业、公安、金融、消防、农业、物流、生态、物联网、3D 可视化等行业场景。

项目 README.md 将其概括为"数据可视化站点（纯前端静态版）：大屏模板集 + ECharts/AntV 图表示例库"。从源码痕迹看（`src/api/chart-examples.ts` 注释"语义对齐原后端"、`scripts/slim-chart-json.mjs` 注释"编辑能力移除后，SFC 是唯一真源"），本项目此前依赖一个配套后端（server）提供图表示例数据，2026-10 完成了"去后端化"改造：所有元数据固化为 `src/data/charts/*.json` 三个静态 JSON，所有示例固化为 `src/chart-examples/` 下的本地 `.vue` 单文件组件，站点可整体托管在任意静态服务器或内网环境（smoke 脚本 `scripts/smoke.mjs` 甚至把"运行时零外链请求"作为硬性断言）。

**目标用户**：

- 需要快速查找图表实现参考的前端工程师（图表库按分类/关键词检索，示例可直接下载源码）；
- 需要搭建数据大屏的业务开发者（22 个大屏模板按行业分类，可直接复用 `src/components/datav/` 组件族）；
- 内网/离线环境的交付团队（全量资产本地化：ECharts 数据集、GeoJSON、Three.js 模型纹理、字体图标均随仓库分发）。

## 5. 核心概念一分钟速览

- **图表渲染双链路**：详情页 `src/views/ChartExampleDetailPage.vue` 先查 `LOCAL_LIBRARY_MANIFESTS`（`src/chart-examples/manifest.ts`）命中本地 SFC 则用 `import.meta.glob` 异步直挂（方案 B，1617 条走此链路）；未命中则回退 `src/api/chart-examples.ts` 读 JSON 元数据，交给 `src/components/chart-examples/ChartExampleRenderer.vue` 按 `loaderKind` 分派（option/api-async → ECharts 求值；antv-config → G2Plot 实例化；component → `VueSfcRenderer` 运行时编译）。
- **库白名单**：`src/config/chartLibraries.ts` 是唯一真源，导航下拉与图表库页自动联动；apexcharts/chartjs/d3 已于 2026-10 删除。
- **大屏注册**：新增大屏需同时改 `src/config/bigscreenData.ts`（清单）与 `src/config/bigscreenComponents.ts`（组件映射），`src/config/__tests__/bigscreenComponents.test.ts` 锁定两者不漂移。
- **主题**：`src/composables/useTheme.ts` 提供暗/亮/跟随系统三态，写入 localStorage（键 `devcanvas-theme`），通过 `documentElement` 的 `.dark/.light` class 驱动 `src/assets/main.css` 中的 RGB 变量令牌。

## 6. 快速上手

```bash
# 环境要求：Node 22（CI 使用 node-version: 22）、pnpm 10（CI 使用 pnpm/action-setup@4 version 10）
pnpm install           # 安装依赖
pnpm dev               # 开发服务器 http://localhost:5566
pnpm typecheck         # vue-tsc 类型检查（CI 阻塞项）
pnpm lint              # ESLint
pnpm test              # Vitest 单元测试（19 个测试文件）
pnpm build             # 生产构建（NODE_OPTIONS --max-old-space-size=8192）
pnpm preview           # 预览构建产物
pnpm test:smoke        # Playwright 冒烟（需先 pnpm dev 或 pnpm preview；BASE_URL 可指定地址）
```

首次启动建议访问顺序：`/`（首页）→ `/charts/echarts`（图表库，感受分类侧栏与分页）→ 任一示例详情页（打开"查看源代码"弹窗）→ `/bigscreen`（大屏列表）→ 任一大屏（验证 1920×1080 自适应缩放与 canvas 渲染）。

健康的启动信号有三条：其一，浏览器控制台不应出现 `myChart.xxx 实例尚未就绪` 告警（该告警来自 `src/chart-examples/EChartDemo.vue` 的延迟代理，偶发于极慢设备，持续出现则说明图表 chunk 加载受阻）；其二，`/charts/echarts` 列表应显示 348 个示例、37 个分类（与 `src/data/charts/echarts.json` 一致）；其三，Network 面板中 echarts/three/antv 的 vendor chunk 与库级 JSON chunk 应为按需加载——首次停留在首页时不应看到任何图表库代码被下载，这是懒加载架构生效的直接证据。若需要验证内网部署可用性，跑一遍 `pnpm test:smoke` 并确认输出"冒烟全部通过"，其中外链零请求断言是最容易在改依赖后被破坏的一条。
